## 4. 开发机工作包与依赖

### 4.1 主模型收口与素材盘点

首先将已训练资产转为可复用的正式输入清单。全量核验主模型、下游、预处理和样本角色的来源散列；每种模型加载路径及下游类型至少抽查一个训练/内部验证单元，记录重放差异与预定容差。已有收据检查不能替代此项。

导出训练更新、所选检查点、分阶段时间、失败尝试与继承关系。主表完成量必须同时覆盖模型单元、表示路线和实际可用任务；不把补充下游的缺失或失败静默删除。同步状态页与产物索引，保留原失败现场。

### 4.2 核心机制和消融矩阵冻结

先读取既有协议和配置，再形成逐单元机器矩阵。记录数据角色、完整配置、基准与消融差异、监督路线、种子、预算、输出与验收条件。种子沿用 17/29/43；需要训练的消融独立训练，不能用推理时关闭模块替代训练消融。

连续演化、物理残差、独立配对、显式时移、单流旁路等逐项核对适用性。无物理残差仍保留观测锚定；仅对基准实际开启的组件进行消融。质量门、扩展缺失增强等条件项必须记录采用与否及依据。已有必做项须明确完成或不适用，不能以赶工为由从矩阵中消失。

参数敏感性只使用开发角色，选取与第三、四章实际实现直接相关的少量参数，例如已存在的时滞尺度配置或物理项权重。精确参数值、点数和预算在实跑前固定；不临时增加不存在的模型能力。该矩阵的完成项、待定项及配置差异由复核文件登记，不能将本计划视作已冻结的参数网格。

核心机制完整模型、消融模型以及用于形成敏感性判断的配置选择均在外层结果开启前确定。确认仿真实例按既有协议在相关模型冻结后生成；旧仿真生成数和新配置以实际清单核验，不从历史表格直接继承完成量。

### 4.3 外层评价接续与验证

接续入口读取本批冻结模型和已拟合下游，覆盖公开五折三种子、鼎新单记录三种子及所有已声明表示路线。不得直接用旧六方法确认入口宣称覆盖全部近期模型。

优先复用已有冻结加载与导出能力，补足正式清单消费和结果归档。只提供窗口末端向量的模型进入对应共同线性下游；具备真实序列的表示按既定规则进入 MiniROCKET 时序卷积特征补充评价。模型、归一化、阈值、下游参数均不根据留出结果更新。

接续验收至少覆盖角色泄漏拒绝、来源变更拒绝、不同表示形态、缺失目标、全量样本保留、失败停止、独立进程恢复和重复导出一致性。先在训练/内部验证数据上跑通；完整主模型、核心模型及评价接口冻结并通过检查后，才打开外层目标。未知失败保留现场，修复另记版本和受影响单元。

### 4.4 机制、缺失与成本实跑

机制评价分开报告时钟偏移幅值、有符号时钟偏移与生理响应时延；未来扰动测试改变截止时刻之后的观测，比较相同历史查询的表示，保留全部失败。无因果掩码作为开发诊断，不将其外层结果用于模型选择。

缺失评价保持同一冻结模型和同一组样本配对，固定扰动类型、强度、随机种子和干净参照。导出平均性能、尾部误差、最大五窗口平方误差占比、无观测覆盖与非有限值状态，失败场景进入完整交付。

成本测量区分训练、适配、导出、下游拟合与预测。推理计时固定设备、输入长度和批量，分别测单窗口延迟与批量吞吐；预热、设备同步、重复次数、计时边界和峰值显存重置在运行前声明。保存原始重复计时及中位数、第 95 百分位；区分模型计算和端到端预处理/预测。失败、恢复和继承成本防止重复计数，缺失历史计时保留下界标记。

正式神经网络实跑使用统一计算设备架构（CUDA）环境和现有显卡，遵守既有设备锁，不抢占其他任务。性能优化仅在实测瓶颈影响交付时安排；任何改变执行路径的优化都需数值与恢复验证，不重新搜索模型配置。

## 5. 详细数据与统计交付约定

**数据需支持从汇总图回溯至统计单位和原始预测。** 下列文件名是新交付包的约定，可按数据域分文件；列名允许复用已有字段，但数据字典必须提供中文含义、单位、粒度和唯一键。

| 文件 | 一行的含义与必要内容 |
| --- | --- |
| `inventory.csv` | 一项素材：章节、数据域、任务、用途、状态、来源版本、输入、脚本、输出及缺口原因 |
| `protocol.json` | 固定划分、目标公式、模型配置引用、监督/外部预训练条件、消费者、统计和样本保留规则 |
| `sample_manifest.csv` | 一个样本角色记录：稳定样本标识、分组标识、折、角色、历史与目标区间、有效掩码引用；留出内容按冻结门开放 |
| `predictions/*.csv` | 一个样本—任务—字段—方法—路线—折—种子预测：真值、预测、有效性、失败状态及来源标识 |
| `group_metrics.csv` | 一个受试者/独立轨迹/鼎新时间块的指标：有效数、缺失数、指标值及单位 |
| `setting_metrics.csv` | 一个方法—任务—路线—下游—折—种子的汇总及聚合说明 |
| `summary.csv` | 一个绘图汇总：中心值、误差条上下界、误差类型、统计单位、组数、聚合规则 |
| `paired_differences.csv` | 相同分组和条件下方法与固定参照的差异，保留配对键、方向与区间 |
| `mechanism/*.csv`、`robustness/*.csv` | 一个查询点或扰动配对：时间、真值、差异、条件、容差、覆盖及失败 |
| `cases/*.csv` | 一个示例片段的绘图序列：相对时间、观测/目标/预测、事件标记、掩码、来源 |
| `cost_units.csv`、`inference_timings.csv` | 训练单元分阶段成本，以及每次推理重复的耗时与配置 |
| `figure_inputs/*.csv` | 每张图实际消费的全部数值、曲线点、混淆计数、误差条、布局需要的预计算量 |

公开指标先按受试者计算再按冻结口径汇总，仿真按独立轨迹或档案配对；折和种子不是额外独立受试者。种子间波动与受试者不确定性分列，描述性标准差与置信区间不得混用；区间计算和重采样参数在外层开启前固定。鼎新只作单记录描述性评价。

分类主指标为宏平均 F1 分数；回归主指标为均方根误差，各字段保留原生单位，不能把不同量纲的误差直接平均。鼎新保留持久性预测参照和相应技能值；参照误差为零等未定义情况显式标记。主线性与时序补充、自监督与任务引导、外部预训练方法分层展示。

所有未定义指标须附原因和有效样本数，不用零代替；所有失败与不适用路线进入覆盖清单。只导出最好种子、只保留有利字段或只展示最佳片段均不满足验收。案例按预定规则选择，保留典型收益、无明显收益和失败片段的可用数据。

详细数值表和绘图所需裁剪序列优先用逗号分隔值（CSV）与 JavaScript 对象表示法（JSON）开放格式，并采用 UTF-8 编码。稳定化的受试者标识即可支撑分组；不导出凭据、原始身份信息或无关大数据。预测规模较大时按域/任务分文件，不能让图形依赖服务器上的隐藏文件。

```text
verify.py                 独立文件/字段/一致性检查，不执行训练
figures/                  高清位图与矢量图
revisions/                独立修订数据及变更说明
validation.json           独立环境重绘与人工图像检查记录
```

绘图只读取指定数据版本和样式，进行排版与渲染，不加载模型、不连接数据库或网络、不导入 `chronaris`、不重新拟合或计算实验指标。均值、区间、曲线汇总、直方图计数和箱线图所需统计量由开发机先算好并导出。文件检查可校验随包数据关系，但不在绘图入口偷偷修正统计值。

依赖以 Python 标准库和 Matplotlib 绘图库为起点。路径相对脚本自身解析，兼容含空格目录，从其他工作目录调用也可运行；本地重绘无需显卡或开发机的 conda 环境。中文字体在样式中可配置，记录实际测试字体和缺失字体的处理办法；若随包分发字体，需同时保留许可。

下列为待实现包应支持的运行形式，参数沿用已有绘图包习惯；本计划提交不代表新脚本已存在：

```bash
python -m pip install -r requirements.txt
python verify.py
python plot.py
python plot.py --data-dir revisions/2026-10-18/data --style style.json --output-dir revised_figures
```

默认读取 `data/` 原始快照；样式可直接修改。数值修订复制为 `revisions/<日期>/data/`，记录文件、行键、原值、新值和理由，并显式选用该版本。若修正底层值，需要一并提供相符的汇总/误差条，不能仅改图上显示数字；若需重新统计则在开发机导出新版本，绘图脚本保持纯渲染。原冻结实验与原始导出均保留。

输出默认提供至少 300 点每英寸的便携式网络图形（PNG）和可缩放矢量图形（SVG）；SVG 尽量保留可编辑文字，并说明接收端字体需求。每张图的数值、误差条、标签、样式、脚本与输出全部纳入 Git 版本控制。图号由论文侧最终确定，素材使用稳定文件标识，不以内部模型代号作为图题。
