## 5. 修订后的方法与评价合同

**首选方案是在统一历史表示接口上建立强分支，再检验有增量的时间交互。** 现有单流实现已使用带 `causal=True` 的 ContiFormer，并输入观测值、有效性和观测龄，可复用接口与训练基础；当前完整方法使用另一骨干。候选骨干以现有强单流为起点，而不是预先认定替换即可胜出。

保留一条候选主线：独立强分支 → 同骨干双流拼接／简单融合 → 历史受限的可收缩交互。先固定骨干只学融合，以分离读出组合和编码更新；再在完整预算下比较是否需要联合训练。模态自身任务辅助与原联合目标分开控制。事件语义、物理残差和时间排序按适用条件逐项加入，不同时更改所有组件。

旁路包含单流信息不构成总体泛化保证。保留旁路的联合训练仍可能损害分支表示；缩小交互或门控也不能保证严格超过单流。零交互、单流、简单拼接与完整候选均须报告。同维度、参数量、有效标签曝光和优化预算的差异进入来源表。

历史掩码中的“因果”指信息可见范围；飞行事件引发生理变化的统计因果关系需要另外的识别设计。当前事件摘要来自潜态变化与历史聚合，应按其计算定义验证，不将其等同于专家标注的机动类别。原有梯度冲突与近均匀注意力继续作为诊断线索，单种子的局部消融收益也不升格为普遍机制结论。

主比较拟采用两个公开分类任务、统一冻结表示读出和一种预登记主要学习路线；第二种路线作为学习策略对照，回归按任务有效性决定地位。仿真承担时间机制、物理与序列结构验证，鼎新承担真实输入与应用案例。该范围是提案，在确认前继续保留原主矩阵作为验收依据。

导师要求的判据分开登记：每个确定的主任务都应超过全部适用简单参照、强单流与强传统融合；至少预定的一部分任务应优于适配合理的大模型比较方法。全部候选与不利比较保留。跨受试者配对差异与区间、逐人和逐折结果、重复种子均报告；描述性标准差不冒充置信区间，三种子不冒充三个独立受试者。原先“至少两折及受试者多数改善”可作开发筛选，不能代替统计确证。

TimeCMA 语言增强预测、Chronos-2 时序基础模型和 SensorLLM 传感器语言模型现有适配结果保留；SensorLLM 的语言骨干替换继续明确标注。下一步先核对适用任务、原版权重、官方训练方式与可承担预算，再登记最终比较集合。共同表示读出与原生任务适配分别报告；不宣称本轮已重新检索并确认截至当日的最先进排名。

## 7. 分支决策与止损

**每轮只能回答一个足以改变下一步的研究问题。** 若目标审查不过，先修任务定义；若强骨干单流不能超过简单参照，先处理输入、任务与训练，不进入复杂融合。若简单融合存在收益而当前完整表示退化，优先优化表示保留与交互；若有界训练仍无融合增益，则停止追加交互模块，评估模态互补性与题目贡献是否需调整。

若新方法在公开主任务上领先而物理项缺少作用，第三章应以实际验证的连续查询或时间对齐为主，并调整物理约束在章名与贡献中的地位。若统一表示无改善而专用头明显领先，应将研究对象明确调整为任务模型，同时改第一、二、四章，不能只替换第五章结果。若连续时间与历史交互均无可复核增益，应向导师明确提出缩小或变更方法贡献；已有工程完成量不能补偿这一研究缺口。

如果导师坚持原四任务、两路线、所有既定强基线均须胜出，当前证据不足以支持按期达到这一要求。Chronaris 的工程基础可复用，当前完整模型和现有标签是否足以实现该目标仍待验证；这两点应分别判断。
