# 夜间条件单元二：历史中间时刻的五秒前瞻监督

2026-10-19 01:46（北京时间）。依据[夜间授权](../overnight-research-20261019/AUTHORIZATION.md)预登记。只有当前[选模一致性单元](../readout-selection-20261019/PLAN.md)未通过主门/配对门时才执行；若通过，优先单独登记稳定性复核，不执行本单元。

## 假设与唯一变化

此前任务训练只对窗口最后一个查询监督，其他历史时刻的表示只通过注意力间接学习。连续表示可能因此没有充分学习短期变化规律。本单元固定保形输入、原处理输入、同容量飞机对照及共同读出选模，在全部三个版本上同步加入训练窗口内的五秒前瞻目标，检查更密集的历史监督能否提高泛化，并产生真正的生理条件增量。

每窗96查询间隔0.3125秒。仅使用第16至80查询（相对窗首5至25秒）的输出，预测16个查询之后的过去5秒绩效均值。以a[j]表示严格截至查询j的过去5秒绩效，则修正目标为(a[j+16]-a[j])/训练残差尺度。网络在j处只有截至j的输入，a[j+16]仅作为训练标签，绝不拼入该时刻输入或表示。该辅助区间为[q,q+5)，主任务的(q,q+5]边界保持原定义；不混称完全相同标签。

总损失为原末端人员等权均方误差，加0.5倍历史有效查询的逐窗平均人员等权均方误差。权重0.5固定，不调网格；同窗有效查询数先归一，避免缺失较少的窗口获得更大权重。原末端目标、训练/选模/评分人员、拟合与选择范围均不变。选模仍只看原末端主任务的共同岭读出；历史辅助损失不参与选模打分。

## 标签资格与因果门

旧缓存的历史均值缺失时填零，不能直接作为标签。全部5951窗在5秒以后有206个零值；逐一回读3份原始绩效文件，206项全部是缺失占位，并无真实零值。以旧提取器“只有失败写零”的已冻结规则确认其余非零项有效，额外解析全部歧义零值；不把未回读的非零项冒称本轮重新逐项读源。

通过[audit收据](../overnight-research-20261019/history_anchor_qualification.json)绑定原缓存和可用性掩码；同时要求a[j]和a[j+16]有效。共386505个有效历史监督对，每窗25至65个。输入资格复用保形单元的原生/历史检查；训练前必须验证缓存散列、样本顺序、掩码身份。修改/删除未来不改变历史输出，容差仍1e-5；梯度只来自拟合人员，选模与评分人员不参与辅助训练。

## 有界训练与验收

两折种子17、三个版本共六个主拟合；架构、输入、初始化、学习率0.001、AdamW权重衰减0.0001、批32、梯度裁剪1、共同读出网格不变。最多100轮、至少20轮、耐心15轮，每模型60分钟、单元4小时。全部模型及读出锁定后评分；同容量和原处理两个控制也接受辅助监督，避免只给候选额外训练信息。

主门与配对门沿用[原执行合同](../shape-mult-20261019/PLAN.md)：两折共同读出对最强适用控制至少降低2%均方根误差、逐人改善及平均绝对误差门；三种固定异记录配对干预平均恶化至少2%，真实配对不弱于置中心。保留此前所有强冻结成绩，不能只战胜较弱新控制。仅在主门和配对门均通过后，执行最多两项同输入/同监督的ContiFormer公平复核，不扩整个论文矩阵。

如果只提高飞机和双流共同成绩、但没有超过同容量飞机或没有配对依赖，则结论是历史监督帮助时序预测，不是生理融合优势。若仍失败，本单元停止并保留，后续只能另登记不同且有数据依据的假设。模型达到预算或数值/身份/历史门失败，按已有规则保存现场，不修改门槛。
