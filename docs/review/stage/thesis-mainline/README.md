## 新发现

CogPilot 事件响应原实现直接对皮肤电阻均值作差。225 个冻结事件中，原标签范围为 −25,347 至 4,876，两个窗口含非正电阻，最坏后窗含 6,207 个非物理点。只读复核将正电阻换算为皮肤电导并使用前后窗中位数差后，225 个事件全部可用，范围为 −1.231 至 1.183 微西门子。

CogPilot 与 CLARE 原实现还从观测窗前后各读取 2 秒心电图（ECG）信号，并用全窗分位阈值派生心率。该做法使历史心率点依赖后续信号，违反未来信息隔离。推荐的数据修订是保留原始 ECG 及其原生时间戳，不再使用该非因果派生特征。

上述两项已合并为一次“原生生理预处理完整性修订”。用户明确确认后，数据结构定义（schema）、缓存来源链（lineage）、协议版本和验收证据已同步升级；修订发生在任何公开外层结果打开前。
