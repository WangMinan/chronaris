# CLARE标准分类的频率与缺测检查

**完整窗口频谱方案未通过输入资格，分类训练保持未启动。** 14名登记人员共2950个合法标签窗口中，2322窗满足全部字段的连续支持条件；1544、1717、1953、1981及开发人员1629没有达到预定的逐人完整覆盖门。本单元没有逻辑回归拟合、编码器更新或外层评分，不把数据准备失败称为模型性能失败。

**主要问题是缺测支持，而非有效时间戳排序错误。** 全量窗口的进一步逐字段检查未发现有效观测时间重复或回退；520个窗口外围信号支持不足，67个窗口脑电支持不足，两类可重叠。原资格拒绝338窗来自间隙，236窗来自不足观测，54窗缺源文件。完整覆盖要求因而不能代表既有带缺测掩码模型的全部可用范围，但本方案不放宽阈值或填造观测来启动训练。

下表按实际原生有限观测统计各字段的风险，支持后续分别处理缺测和频率，不将这些统计当作负荷分类成绩。表中是字段窗口计数，多个字段可能来自同一窗口。

| 信号字段 | 少于20点 | 存在超过0.25秒间隙且不属少点 |
|---|---:|---:|
| 心电校准通道 | 153 | 345 |
| 皮电电导通道 | 177 | 40 |
| 脑电各通道（四通道相同计数） | 29 | 38 |

**原生频率值得保留，但高频能量不等于有用的标签信息。** 在2322个完整窗口、四个脑电通道中，0.4–45Hz功率里高于4.8Hz的占比中位数为51.78%；原生脑电、皮电、心电采样率中位数分别为256、128、512Hz。现有10秒96点查询的频率分辨边界约4.8Hz，直接查询原波形存在混叠风险。该检查只支持进一步验证保留频率内容的输入，不证明这些频率能够改善分类。

**后续应优先明确缺测片段的表示，再设计一个统一输入的分类单元。** 可核查按有效片段提取原生频率特征、保留缺测掩码和观测龄的方案，并让全部基线使用相同观测支持；不能把整窗完整方案的失败改写成通过，也不能凭高频能量直接训练大矩阵。标签固定按评分至少5，旧至少7结果保留；标签与脑电首时刻的窗口假设及缺乏独立提示音锚点继续披露。原标准任务来源见[CLARE论文](https://arxiv.org/html/2404.17098v2)。
