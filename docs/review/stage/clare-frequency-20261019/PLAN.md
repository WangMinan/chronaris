# CLARE标准分类的原生频率与任务资格检查

2026-10-19，夜间自主研究的只读准备单元。飞行误差回归多轮尚未显示生理增量，扩展拟合试验仍在运行；本单元回到已同意保留的CLARE生理负荷标准分类，先核验输入频率、标签与跨人可预测性，不提前启动新编码器训练。

标准标签固定为原主观评分至少5，不搜索阈值。沿用脑电记录首时刻加标签行号乘10秒的窗口假设；原文件没有独立提示音锚点，因此只作这一公开适配口径下的负荷分类，不能作为精确生理时差真值。原至少7的任务与所有冻结成绩保留。原文依据：[CLARE论文](https://arxiv.org/html/2404.17098v2)，其中模型评价与信号处理是本任务口径的来源，不照搬其全受试者归一化。

只读取原确认第一折训练人员1337、1419、1544、1688、1717、1892、1929、1933、1953、1981，以及既有开发人员1390、1624、1629、1674。原确认验证1026、1106及正式留出1175、1194、1818不进入新增读取。所有数据角色单列：第一折以原10人及1674拟合，1390选模，1624/1629评分；第二折以原10人及1629拟合，1624选模，1390/1674评分。本准备阶段仅拟合和选模，不读取评分结果。1674标准低类只有3个原开发窗，后续任何外层结果必须披露稀疏类别，不能宣称稳健独立确认。

每窗严格使用10秒区间内原生脑电、皮电、心电有限观测。逐字段有限时间必须严格递增，不排序去重；记录来源前后散列、采样间隔和覆盖，完整保留不合格窗。每字段首尾缺口和内部间隙不得超过0.25秒，脑电采样率至少100Hz、心电至少100Hz、皮电至少20Hz，每人至少100窗且至少80%原合法标签窗合格；固定人员任一未通过则不训练。

频率检查以原生Welch功率谱量化脑电0.4–45Hz中高于96点/10秒查询奈奎斯特频率4.8Hz的能量比例，排除60Hz电源频率，不将高频能量直接当成有效任务信息。脑电静态诊断取四通道五个预定频带0.4–4、4–8、8–12、12–31、31–45Hz的相对功率与总对数功率；外围取两通道均值、标准差、四分位距、均方根、线性斜率及因果带通后均方根。数值保留原导出单位，跨字段标准化仅在拟合人群完成，不猜绝对电压单位。

使用相同人员等权和类别平衡的逻辑回归，正则倒数0.01/0.1/1/10/100，仅选模人员选择。比较脑电、外围、拼接与训练多数类，宏平均F1及平衡准确率逐人报告。只回答合格输入和任务可学性，不要求线性拼接已获融合优势才允许神经模型；若两折均无任一观测模型超过多数类至少0.02宏平均F1，则保留无资格支持结果，不追加本单元训练。所有神经比较必须另行登记模型、对照和门槛。
