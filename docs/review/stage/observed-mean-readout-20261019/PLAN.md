# 冻结模型的公共历史均值读出核验

2026-10-19。合格拟合扩展的六个模型已全部完成并重放。源代码显示，专用预测头使用“历史五秒均值＋所学修正”，共同岭读出则直接从64维表示预测未来均值，没有显式获得这项精确历史均值。原同路线模型比较仍保留；本单元只核查读出信息接口，不修改任何编码器权重、窗口、角色或旧成绩。

对两个折、同容量飞机／原处理MulT／保形MulT六个已选检查点，固定三种读出：64维表示直接预测原目标的双精度重拟合，作为数值口径控制；64维表示加公共历史均值的65维读出；64维表示预测相对历史均值的残差，再将该均值加回。历史均值沿用原专用头实际使用的float32观测值，不引入未来标签输入。后两者是任务读出形式，不将其称作64维表示本身改进。

三种读出都用双精度计算，拟合人员等权，岭正则固定0.1/1/10/100/1000，仅选模人员选择。十八个读出选择单元全部锁定后才生成本轮外层预测；所有原输入、标签、已选检查点及停止规则不变。对应18×5次岭拟合，编码器优化更新为零。原64维表示导出保持不变，额外均值只在任务读出侧使用。

每条读出路线分别比较，不在两折之间拼凑最优路线。候选仍需在两折相对全部适用非候选控制降低至少2%逐人等权均方根误差、平均绝对误差不恶化2%、第一折至少2/3及第二折2/2评分人员改善。该同一候选原专用头和原共同读出作为同模型的其他输出形式报告，不伪装成独立对照；所有飞机、原MulT、统计及既有强方法保留。通过性能门的路线再做同三种同人异记录替换与置训练中心，配对门仍为平均恶化至少2%、真实配对不弱于置中心。

新特征缓存、读出、选择记录和预测单独保存；原岭读出在新缓存上重放必须满足原1e-5阈值。独立核对角色、参数选择和误差计算，重放评分特征；不通过则保存失败。即使新读出改善，也只证明当前冻结表征与任务接口的性质；按一致信息协议重新选模、模型比较和正式确认仍须另行登记。资源最多20分钟，且不超过夜间09:30总截止，不展开编码器训练或完整矩阵。
