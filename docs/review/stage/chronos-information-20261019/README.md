# 时序预训练基底的信息增量诊断结果

**Chronos-2时序预训练模型没有带来稳定生理增量，本单元不接受它为新方法基底。** 两折联合编码均弱于同路线飞机编码，也弱于此前多模态变换器MulT的强参照。历史自监督适配未改变这一判断；没有触发条件性的生理替换诊断。完整结果与失败保留，不据此否定该预训练模型在其他任务中的能力。

**结果可复现，求解精度不是主要原因。** 六次历史适配完成18021步更新，编码与导出耗时2738.40秒；16个共同读出全部锁定。167960条主表预测与200项逐人指标独立复算，最大差异4.44×10⁻¹⁶；新进程12条特征路线逐值重放差异为零，16条预测路线差异不超过8.89×10⁻¹⁶。1978份保护来源保持不变。固定原已选正则值的双精度核查另存16个线性模型，最大相对误差变化约0.00212%，没有路线达到预登记1%的精度敏感门。

**当前证据支持扩大训练覆盖检查，尚不支持“大模型更弱”或“生理一定无用”的普遍结论。** 本单元每折只有3或4名拟合人员，完整表示维数9244至24648；保留原生全部维数避免事后挑投影，但小人群、高维读出的跨人泛化可能受限。该单元也没有使用主任务标签更新预训练编码器。下一项按独立合同核查追加原训练角色中的合格人员，保留所有小规模强参照；原正式确认验证和留出人员仍不进入新训练。
