# 夜间时序预训练基底的信息增量诊断

2026-10-19。此前保形输入、共同读出选模、历史监督三个MulT（跨模态Transformer）单元均未证明生理增量，且飞机单流已成为更强参照。本单元按[夜间授权](../overnight-research-20261019/AUTHORIZATION.md)更换表示基底，回答预训练能否提取到当前浅层统计和从头训练没有利用的信息，并补充先进模型对照准备。不是把Chronos-2改名为本文方法，也不提前宣称达到导师目标。

## 固定来源与输入

使用本地已登记的Amazon Chronos-2时序预训练模型，权重版本`29ec3766d36d6f73f0696f85560a422f50e8498c`，官方源码版本`4dbf163c2734c089cdf7da2b86fde48862ff9c6f`，现有77项资产与依赖已验证。模型约1.2亿参数，支持多变量时序编码，来源见[官方仓库](https://github.com/amazon-science/chronos-forecasting)。不下载或更新权重、依赖、旧适配检查点。

复用5951窗、两个折内保形生理输入、飞机12字段、人员划分和未来5秒绩效目标，全部原生资格与数据角色不变。使用当前折拟合人员的既有尺度化，不增加新观测或未来协变量。

三种输入视图：飞机12字段；生理16字段加公共历史绩效4字段，共20字段；完整双流28字段。每窗一个独立多变量组，禁止跨窗口/人员注意力。公共历史绩效始终可用，生理视图不因缺少持久性可用信息而被人为削弱。

## 表示与适配

窗口结束时提取官方encoder的REG状态，不使用预测输出token或未来预测作为表示。另保留官方embed返回的各通道loc/scale，以及最后查询的四项已观测历史绩效。旧适配器只提取REG的旧成绩不覆盖；本单元明确标为“REG与观测尺度完整表示”，避免实例归一化后丢失绝对水平。它是窗口结束表示，不冒充每个历史时刻的连续潜态或直接时间对齐验证。

每折三视图分别报告外部预训练冻结路线和仅历史适配路线；另以生理/飞机独立编码的表示拼接作为控制，不额外训练编码器。单独适配后拼接使用两个适配器，参数总量高于联合编码，完整披露。

历史适配仅预测拟合窗口内部最后16个查询点，输入为前80个查询点；没有使用主任务未来标签。复用现有Chronos-2原生分位数损失与short_fit训练器，FP32、AdamW学习率1e-6、梯度裁剪1、种子17，每视图完整遍历一次拟合窗口。顺序先按种子17打乱，三视图使用相同顺序；自监督阶段按窗口更新，读出按人员等权。每250更新保存完整优化器和随机状态，可精确接续；技术失败或夜间时间到达则保留检查点，不把预算截断当成性能失败。

## 比较与进入判断

共同岭读出使用训练拟合、选模选择，alpha固定0.1/1/10/100/1000/10000/100000/1000000，以适应高维预训练表示；不按外层成绩调整。保留全部原生维数和参数数目，不用事后挑投影维度削弱参照。先冻结全部编码器/读出，再统一外层评分。外部预训练、历史自监督与此前MulT主任务监督属于不同训练来源，分层标注。

主诊断为同一路线联合编码相对飞机编码及独立拼接是否在两折均降低至少2%逐人等权均方根误差，平均绝对误差不恶化超过2%，第一折至少2/3、第二折2/2评分人员改善；同时与今晚全部强MulT参照比较。冻结和适配两路线分别报告，不能混取两折最优。

如果联合编码通过基本性能门，再对该路线做固定三种同人异记录生理替换与生理置训练中心诊断；原配对须不弱于置中心，异记录三规则平均每折恶化至少2%才支持条件信息增量。若基本门失败，完整保留结果而不追加这项显卡开销。本单元只检验新基底，不自动接受为最终方法。
