# 原始数据与冻结读出对照计划

本轮完成 CLARE 生理负荷数据与 CogPilot 飞行任务数据的原始标签、时间窗和单位审计，再评价简单参照和同维度读出。冻结模型、原成绩和历史来源保持不变。编码器更新数为零，所有新输出独立保存。

原始 CSV 位于原服务器。本地以受试者分层、记录首尾窗口及样本标识散列确定抽查，不依据目标或预测值选样；每个数据集每个任务至少 20 窗。独立脚本直接读取 CSV，不调用仓库目标生成函数，比较原始标签、缓存输入逐字段摘要、时间支持及源文件身份。分类完全一致；浮点目标允许一次 float32 存储舍入，时间允许两个原生时间浮点间距（CogPilot 日期乘 86400），不改变冻结推理的任何验收阈值。无法从原说明确定的语义或单位单独列出，不将数值复现冒充语义确认。

模型固定为种子 17、原确认第一折的完整方法及五种传统对照，不按本轮成绩选择检查点。使用原模型的归一化和加载身份，对登记开发受试者（CLARE 4 人，CogPilot 7 人）作冻结迁移表示导出；证明这些受试者不在模型原训练、验证、留出样本名单中。此结果回答固定表示在开发集上的可读出性，不替换原确认成绩，也不作为新独立确认。此前开发集参与方法开发的历史仍予保留。

读出采用原登记三折外层划分；每折训练受试者内部再逐人留一选参。所有标准化、主成分分析仅在对应内层训练数据拟合，最终以外层训练数据重拟合，外层验证只评分。分类逻辑回归 C 为 0.1、1、10，回归岭参数为 0.1、1、10、100、1000、10000；相同网格、受试者等权选参，分类训练缺类即记录不可用，不退回窗口随机划分。指标先逐人，再逐折等权；完整记录每折、每人、参数和预测。

完整 64 维与原生第一流 24、第二流 24、跨流 16、两分支 48 维比较，同时补完整表示经训练内标准化和主成分分析压缩至 24、16、48 维。固定高斯随机投影 64→24，种子 17、29、43 全部报告。完整表示增加强正则网格，并保留原网格单独对照。传统对照采用相同扩展网格。零变化、训练均值/中位数、训练多数类及 CogPilot 历史两秒皮电变化不参与参数挑选；CLARE 标签持久性因任务未允许实时标签输入记为不适用。

预算上限：原始审计与参照 CPU 2 小时；冻结表示 GPU 2 小时；同维度和读出各 CPU 4 小时。只持有现有显卡锁时推理，不抢占。原始目标/时间/转换不一致则暂停相关任务后续拟合，先记录原因；表示或读出超时保留已完成项，不将超时写成性能失败。不启动后续长训练、同骨干重训或新独立确认。

## 原始边界审计后的单因素补充

全量开发事件端点检查发现：日期舍入使 1462 窗包含事件时刻的航电点，其中 28 窗还包含事件时刻的皮电点。原始规则下已完成的读出保留为问题输入上的诊断，不作为严格历史输入合格结果；暂停继续使用该视图的候选拟合。新增一个隔离视图，仅以原生事件时刻为严格右开端点排除各流的事件及以后观测，派生新的观测身份，不改写缓存。目标、窗口名单、模型、归一化、三折角色、读出网格和投影种子保持不变，重新导出 CogPilot 的 11 条冻结路线并按相同规则读出。新增预算仍计入上述 GPU 2 小时和 CPU 上限。历史趋势也使用同一真实端点。本对照检查输入边界影响，不替代冻结模型重训或正式确认。
