# 原始数据、简单参照与同维度读出诊断

**本轮支持优先修复任务口径、严格时间边界和读出稳健性，尚不支持直接扩大编码器训练。** 原始 CSV 抽查与缓存数值一致，但发现 CLARE 生理负荷数据的项目分类阈值不同于原论文，以及 CogPilot 飞行任务数据的事件端点与目标区间重叠。简单参照和受试者隔离读出确认：扩大正则可以缓解大误差，却不能保证获得有效预测信息；CogPilot 难度分类的第二流在相同维度下明显优于完整表示压缩，问题不能仅由维数解释。

本轮新材料均位于独立目录。冻结数据、编码器、原读出模型和历史成绩保留；编码器优化器更新数为零。只进行了冻结推理与小规模线性读出拟合，没有启动长训练，也没有改论文成绩。

## 直接使用的材料

**全部候选和失败边界均可追溯，不只报告最优组合。** [原窗口完整对照表](COMPARISON.md)列出两域、两路线、全部同维度候选与五种传统方法；CogPilot 事件回归另以 [严格端点对照表](BOUNDARY_COMPARISON.md)核验输入修正后的同一矩阵。[原始数据审计](DATA_AUDIT.md)解释标签、单位、时间和来源问题；[下一步方案](NEXT.md)给出具体修复顺序、判据和预算。机器可读汇总为 [comparison.csv](comparison.csv)、[boundary_comparison.csv](boundary_comparison.csv)，逐折、逐人、选参记录及压缩预测表保存在本目录。

## 数据和评价设计

**本轮检验固定表示的跨受试者读出能力，不重写原五折确认结果。** 模型固定为原确认第一折、种子 17 的完整方法和五种传统方法；完整方法为论文完整配置。原确认受试者与本轮登记开发受试者没有交集，检查点及其训练内归一化直接复用。CLARE 为 4 人、794 窗；CogPilot 为 7 人、1062 个难度窗口及 1462 个事件窗口。完整方法、独立第一流、独立第二流、多模态变换器 MulT、连续时间变换器 ContiFormer 各两条路线，朴素时间同步一条共享路线，共 22 条冻结表示路线。

**选参数与评分严格按受试者隔离。** 使用登记的三个开发划分，各外层训练受试者内部逐人留一选参，然后在外层训练全集拟合读出、只在外层验证受试者评分。标准化、主成分分析（PCA）均在相应内层训练数据拟合；分类训练缺类不回退到随机窗口划分。本次没有不可用的训练缺类组合。分类逻辑回归使用 0.1、1、10 三档正则倒数；回归岭参数使用 0.1、1、10、100、1000、10000 六档，所有传统方法相同。完整方法保留原四档回归网格作为单独对照。

**同维度控制覆盖信息来源与压缩方式。** 完整表示为 64 维，内部第一流与第二流各 24 维、跨流 16 维、两分支合并 48 维。完整表示分别压缩至 24、16、48 维；高斯随机投影 24 维固定种子 17、29、43，全部报告。PCA 前按训练统计标准化，投影后的读出继续使用相同标准化规则；这意味着主成分方向仍会在读出前缩放，不能把它解释为唯一或最优压缩方案。

**这些是开发诊断，样本数不足以替代独立确认。** 登记开发受试者此前参与过方法开发，本轮的选参隔离不恢复其整体研究盲性。只有 4 或 7 名受试者，折间标准差不是置信区间，窗口数不能充当独立样本数。原五折内部验证只用于补齐同集简单参照，不用于本轮嵌套选参。不同总体间的数值不得直接相减声称修复收益。

## 关键发现

**原始数值一致不代表任务语义完全一致。** 106 个原始窗口、130 项目标和 1128 项字段通过数值核验。CLARE 项目阈值为 ≥7，而原论文标准二分类为 ≥5；开发集有 313/794 窗处于这两者之间。分类阈值变更应另建任务版本，全方法统一评价，不能事后修改成绩。原文依据见 [CLARE 第 VI-B 节](https://arxiv.org/html/2404.17098v2#S6.SS2)。原始单位元信息与提示音绝对时间锚点仍有待补项，详见数据审计。

**CogPilot 的严格端点存在可定位问题。** 原始日期减法使事件时刻在相对时间中成为 11.9999952614 秒，从而进入 `<12` 的窗口。1462 个事件窗口均包含事件时刻航电点，其中 28 窗还包含属于事件后目标区间的皮电点。原始输入读出已保留并明确标记；隔离的严格端点对照只剔除端点及以后观测，保持标签、名单、检查点和调参规则。该对照不能修复模型历史训练时已见过的旧端点，亦不取消离线事件选择的条件性。

**严格端点修正没有解释当前性能差距。** 额外完成 11 条冻结路线的隔离视图导出及相同嵌套读出。九条传统路线表示逐值不变，两条完整方法路线最大变化仅约 3.58×10⁻⁷、2.38×10⁻⁷；所有分类表示逐值不变。标准 96 点查询网格止于事件前 0.125 秒，与该结果一致。修正后 CogPilot 任务引导完整回归仍为 0.25360，训练均值为 0.25185，中位数为 0.25135，零变化为 0.25244；最好的传统参照朴素时间同步为 0.24973。端点属于应修的输入合同问题，目前不是这次固定表示退化的主要解释。

**简单参照继续否定“加强正则已经带来有效回归收益”的结论。** 在原五折相同内部验证窗口上，CogPilot 任务引导完整方法均方根误差（RMSE）为 0.144216，固定岭参数 10000 后为 0.136023；训练均值为 0.134446，训练中位数为 0.133713，零变化为 0.133649。后两项同样采用全部五折、相同受试者等权口径。历史趋势有一窗缺少更早两秒观测，对应折记为不可计算，不删除该窗或将四折均值冒充五折结果。

**CLARE 的强正则改善主要体现为控制不稳定输出，尚未超过常数。** 在本轮三折开发迁移读出中，任务引导完整回归从原网格的 5.02717 降为扩展网格的 2.38362；训练均值为 2.11871，中位数为 1.89986。原网格对受试者 1629 的预测平均偏差为 +16.497 分，强正则后为 +1.864 分；另外两人的强正则预测标准差约 0.041，明显小于其目标标准差。这支持“降低异常和向均值收缩”，不能单凭总体误差下降证明提取了更多任务信息。分类完整表示为 0.31008，低于多数类 0.32732，亦低于朴素时间同步 0.49294。

**CogPilot 难度分类的同维度结果将问题定位到表示组合与读出使用方式。** 任务引导路线中，完整 64 维宏平均 F1 为 0.22895；内部第二流 24 维为 0.46249，而完整表示的 PCA 24 维为 0.23505，三个随机投影为 0.20939、0.23489、0.20754。独立第二流为 0.50305。内部第二流就是完整向量的一段，说明有用的分类信息仍然存在，不能把退化全部归为编码器已经丢失信息。减少维数本身未解释第二流的优势；后续更值得先检查分块正则和读出，而不是立即重训全部编码器。独立第二流使用不同骨干，其额外优势仍不能直接归因于融合模块。

**CLARE 的分支优势并不跨压缩方式一致。** 任务引导回归中，第二流 24 维为 2.29127，PCA 24 维为 5.15701；但两分支 48 维为 2.39314，PCA 48 维反而为 2.14351。分类的三个随机投影分别为 0.47239、0.29024、0.43194，变动明显。不能挑最佳投影作为已选定修复，也不能由某一分支胜出宣布负迁移机制成立。

**训练统计下的特征漂移可解释为什么读出容易不稳定，但尚不构成唯一因果解释。** CLARE 任务引导完整表示第一开发折的验证特征最大训练标准化幅度达到约 109.96，约 32.45% 的验证特征值位于对应训练特征范围之外；三个训练折的有效秩约为 2.91–3.23。名义 64 维不等于 64 个独立有效方向，低方差方向在标准化后也可能被放大。见 [feature_shift.csv](feature_shift.csv)；该统计按数据域的全部开发窗口计算，不能替代逐任务机制消融。

## 复现与验证

**脚本均为本轮审计入口，不修改生产算法。** 原始核验需要原服务器可访问；冻结导出需要对应检查点、已准备缓存和可用显卡锁；纯指标复核不需要训练。依次运行本目录的 `audit_raw.py`、`audit_semantics.py`、`boundary_audit.py`、`export_frozen.py`、`readouts.py clare`、`readouts.py cogpilot`、`original_validation.py`。严格端点视图另运行 `export_frozen.py --exclusive-boundary` 和 `readouts.py cogpilot --exclusive-boundary`，其资产与表使用独立名称，旧输出不覆盖。汇总使用 `summarize.py`，最终验证使用 `self_check.py`、`verify.py`。

解释器固定为 `/home/wangminan/env/anaconda3/envs/chronaris/bin/python`，设置 `OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1`。独立资产目录为 `artifacts/application_evaluation/2026-10-18-controlled-readouts`；完整表、逐预测记录、源文件散列和脚本随 Git 交付，模型与原始录制文件不重复入仓。严格端点表由 `boundary_report.py` 生成；最终验证数及材料散列见 `verification.json`、`evidence.json`。

**最终核验覆盖全部诊断预测和冻结来源。** 258028 条新诊断预测重新计算得到 1388 项逐人指标，均与交付表一致；979 份原始来源文件散列不变，其中包含上轮已登记的 853 份冻结证据。原输入与严格端点共完成 33 条表示导出，累计导出墙钟时间约 24.3 分钟（含缓存读取），三次嵌套读出合计约 41.1 秒。外层标签扰动、训练内变换、缺类拒绝、端点排除与来源不变检查通过。未修改编码器、生产数据加载逻辑或旧结果；独立确认及编码器修复效果仍待后续实验。
