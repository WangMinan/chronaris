## 本轮验证

1. 定向测试：`tests/runtime/test_fusion_workbench.py`、`test_fusion_workbench_workflow.py`、`tests/representation/test_contracts.py`、`test_oof_export.py`，36项通过，用时4.36秒。隐藏显卡、单计算线程、显式使用既有解释器，未启动训练。
2. 三窗口真实HTTP推理输出为3×96×64，CSV逐值与标准数组一致，下载回读通过；批量与逐窗口最大绝对差5.960464477539062e-07，在原1e-05绝对/相对容差内。来源检查点散列保持一致。
3. 两次15窗口处理用时3.376054秒和3.199383秒（包含模型加载、窗口推理、标准封装和回读，结束计时在最终JSON/ZIP写出之前）；模型加载约0.307/0.304秒。HTTP提交至结果查询和汇总交付完成分别约3.723/3.605秒，含轮询等待，不是纯推理延迟。
4. 独立服务进程的峰值常驻内存约870.449 MiB，结束采样时常驻内存约861.941 MiB。验证器自己的峰值内存单独保存在机器记录中，不能冒充服务内存。该峰值包含此前三窗口任务、查询与交付，非15窗口模型净内存。
5. 当前服务实际列出1个已登记模型，`semantic_event_enabled=false`，其配置为`variant=full`、`fusion_kind=safe_lag`、`attention_kind=legacy_cosine`。名称full不代表事件语义模块已启用；检查依据为权重真实配置。先前修复记录检查过3个兼容候选检查点，和当前页面登记1个模型是不同统计对象。
6. 静态核对当前模型加载会按保存的事件语义开关重建网络并严格加载权重，所需接入接口已经存在。当前来源文档中的“自监督”模型要求与训练完成校验保持有效；不可在推理时把未训练组件临时打开。
