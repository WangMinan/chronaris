## 固定选择与训练复用

编排重新核验仿真初筛结果及八条件压力，齐全后按每条路线的既定前三名构建 CogPilot（虚拟飞行公开数据）和 CLARE（认知负荷公开数据）的第一开发折。始终保留修复参考用于计算相对收益；参考比较不额外引入新结构候选。四种可训练基线各自比较 32/64 维容量，固定网格基线独立使用已经启动的 CPU 开发矩阵。

同一数据域、方法、候选、折和种子的两条入选路线合并为一个单元，共用一次 300 更新无标签初始化。仅入选自监督路线时不启动联合适配；仅入选任务引导路线时仍完成相同预训练，随后 50 次任务头预热与 200 次联合更新。所有消费者继续从头拟合，共同初始化范围没有跨越数据角色或架构。

公开初筛仍只使用种子 17。完整三折及三种子复核已接入下述有界计划，沿用已有 1,500/500 更新上限入口；组合确认与最终采用判断继续等待真实复核成绩。

## 恢复与验收

就绪计划记录候选来源、公开受试者清单哈希、路线、预算和源码。实际执行前固定该计划，恢复时拒绝不同的选择或来源；完成和失败单元分别保留，失败不会被换成另一个未入选候选。两条路线的共有候选只对应一个预训练单元。

测试以两域共 28 个组合单元验证路由与共享初始化计划，重复执行不增加训练调用，仿真或压力未齐时不会调用训练器。真实训练器的缩小合成测试验证了公开自监督单路线和任务引导单路线各自闭环。集成检查 5 项通过、1 项 CUDA 检查跳过；完整 CPU 回归 572 项通过、30 项跳过，用时 138.20 秒，见[验证摘要](validation_summary.json)。
