# 鼎新跨架次航电内容隔离

当前鼎新快照的留一架次划分未通过输入内容隔离。两个架次在 30 个相对时段的 965 维航电值、有效掩码、原生相对时间戳均逐值相同；60 个按架次命名的上下文只有 30 个内容签名。机动目标统计的十个语义类别也逐值相同。

每折内部训练与留出共享 18 份内容，验证与留出共享 6 份；若最终消费者使用完整训练架次，则与留出共享全部 30 份。之前的命名、时间边界及文件哈希检查无法识别这种跨架次重复，因为文件时间与架次标识不同。

[完整内容审计](../../../../artifacts/runs/2026-09-08_v4-fixed-native-development/vehicle_content_audit.json)保留每个内容签名及两折交集；[逐时段原生对比](../../../../artifacts/runs/2026-09-08_v4-fixed-native-development/vehicle_duplicate_check.json)保留值、时间和掩码的独立比较。窗口签名不附加各自的架次名称或生理数值，并剔除填充点，避免用标识差异替代航电输入差异。

正式鼎新评价入口现会先写入内容审计，并在发现跨角色相同航电输入时停止。合成测试确认生理值不同、架次名字不同也不能绕过检查；真实数据和命令行审计均确认当前隔离失败。仿真和公开数据继续执行既定计划，鼎新开发时间块结果保留为组件诊断，外层主表保持未生成。

[固定基线开发归档](../../../../artifacts/runs/2026-09-08_v4-fixed-native-development/report.md)的 24 个单元已通过目标和冻结模型重放，其中鼎新使用确定性修复后的六个新单元，原六个单元完整保留。模型重放一致与外层数据隔离是两个不同的验收项。
