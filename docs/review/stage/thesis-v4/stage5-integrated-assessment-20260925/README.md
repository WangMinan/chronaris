## 两项优先发现

**补充下游的逐窗口通道否决规则与现有单流窗口不兼容。** [筛选实现](../../../../../src/chronaris/evaluation/application_tasks/application_consumers.py)要求每个有效训练窗口内的每个保留通道都有时间变化，因而不同窗口中的不同零值分支可以联合删除全部通道。双流缺失时对应分支置零是[融合实现](../../../../../src/chronaris/modeling/fusion_encoders/safe_lag_fusion.py)的显式行为。

下表记录本机新增检查，支撑优先修复评价器的方向；准备好的输入核验不等于原始记录与编码器全链路审计。

| 检查 | 本机结果 | 能支持的判断 |
| --- | --- | --- |
| 真实失败表示 | 578 个窗口、96 个时刻、64 个通道，573 个有效窗口；所有数值有限 | 筛选失败不能直接解释为整体表示塌缩 |
| 36 个有效异常窗口的输入与输出对应 | 3 个窗口生理流在最后查询点前无有效观测，33 个窗口第二输入流不可见；对应旁路及交互分支均严格为零 | 准备好的输入与零值输出分块相符，支持单流缺失解释 |
| 5 个无效窗口 | 两流均不可见，全部 64 维时间变化低于阈值 | 应继续遵守既有无观测窗口规则 |
| 固定版本 `aeon 1.5.0` 直接拟合 | 用 573 个有效训练窗口、全部 64 通道、10,000 个配置核、种子 17 拟合 MiniROCKET 时序卷积特征方法；578 个窗口输出 9,996 维有限特征 | 真实输入并不要求当前包装器的逐窗口通道否决 |
| 重放与来源 | 两次转换逐值一致；失败表示文件 SHA-256 散列未变 | 支持修复方向；尚非跨进程保存恢复或完整下游验收 |

逐窗口记录与诊断范围见[诊断证据](diagnostic_evidence.json)。仍需在修复验收中追溯异常窗口到源记录、查询掩码及冻结编码器输出，确认缺失不是读取或时间处理错误。直接库测试没有拟合分类器或回归器，没有产生替代主成绩。

**正式训练入口与当前固定参考存在实质配置差异，必须在正式计算前消除隐藏切换。** [旧正式训练](../../../../../src/chronaris/evaluation/application_tasks/v4_confirmation_training.py)对 Chronaris 开启额外机制、显式时移、语义事件和可学习查询；预训练学习率为 0.0003、公开有效批量为 32、最多 1500 次且使用早停。[当前参考配方](../../../../../src/chronaris/evaluation/application_tasks/stage45_recipe.py)未采用这些额外机制，学习率为 0.001、有效批量为 16、至少 300 次并完成固定预算。这是尚未执行的入口差异，不表示已完成单元发生了配置切换。

## 研究判断与论文组织

**当前证据支持任务相关收益，并清楚显示回归与跨域不足。** 首折三种子任务引导下，CLARE 生理负荷分类宏平均 F1 为 Chronaris 0.431249、ContiFormer 连续时间变换器 0.351981，增加约 0.0793；回归均方根误差为 3.197825、1.761523，增加约 81.5%。CogPilot 虚拟飞行数据分类为 0.294870、第二输入流单流 0.458489，差约 −0.1636，回归误差增加约 8.0%。这些是开发均值，尚非跨折稳定性或独立确认结论。

**论文应分别回答任务价值与机制作用。** 公开固定参考检验连续融合表示在共同下游中的价值；明确启用物理关系和时间机制的仿真配置检验相应机制贡献。当前公开参考未启用的物理残差、显式时移及额外事件机制，不能由公开成绩背书。物理消融须有非空关系和实际损失参与；单流旁路只提供保留信息的结构，不能保证优于强单流；历史信息掩码须经完整链路的未来扰动验证。

鼎新继续提供单记录组件验证和真实片段复盘；既有回归收益保留，不依赖新增一手数据或专家标签。既有旧版本机制失败与三轮优化不利结果继续归档。不同监督和外部预训练条件分别展示，受试者作为统计基础，折、种子和窗口不冒充独立受试者。
