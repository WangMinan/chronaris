# 近期模型接入复核

日期：2026-09-11。阶段 3 承接[共同下游合同](../../../../requirements/common-downstream-executable-contract-v1.md)，验收官方近期模型的实际表示和真实开发执行闭环。

## 范围与计划

本轮固定官方源码、外部权重和依赖，复用三个真实数据域的既有工程样本、分组及线性下游。TimeCMA 语言模型增强方法提取预测投影前隐藏状态；Chronos-2 预训练时序模型提取多变量编码器的窗口汇总标记。两者均声明窗口末端能力，输入只来自合法历史。

TimeCMA 保留官方跨模态结构，采用已有汇总任务标签做必要短训，移除训练头后另行拟合共同下游。Chronos-2 分别验收外部预训练权重冻结使用和训练历史内部后缀预测适配。训练后缀不越过原窗口，不使用共同下游目标；两种监督路线分别记录。

复核依次检查来源散列、真实隐藏位置、掩码及窗口隔离、训练更新与梯度、检查点恢复、语言缓存恢复、表示重放和共同预测重放；记录参数、显存及分项耗时。工程预算不用于建立正式方法排名。

SensorLLM 传感器—语言对齐模型核验官方基础权重访问、通道配置、文本模板及两阶段训练依赖。遇到访问或接口阻塞时记录实际错误，不用随机初始化结果冒充预训练模型证据。

## 已核验结果

**两个必做方法与一个开放骨干变体已完成真实开发下游。** TimeCMA 语言模型增强方法和 Chronos-2 预训练时序模型覆盖鼎新、CogPilot 虚拟飞行数据和 CLARE 生理数据，共 9 条路线；SensorLLM 的本地 DeepSeek Llama 蒸馏骨干变体在 CLARE 增加 1 条分类适配路线。合计 10 组独立线性下游、53 个标量估计器及 554 条验证预测。

下表列出关键复核的实际证据，支撑阶段 3 的工程结论；正式任务比较仍需阶段 4—5 固定完整预算与矩阵。

| 表示位置 | TimeCMA 官方解码器逐值对照、Chronos-2 汇总标记及窗口隔离通过；SensorLLM 使用分类头之前的真实语言隐藏状态 |

**两项实际问题已经处理，并保留原现场。** 鼎新四窗口 Chronos-2 适配逻辑分配峰值超过物理显存，改为单窗口后保持全部 977 个通道并通过恢复；新入口限制缓存分配器最多使用可见显存的 95%。SensorLLM 在当前 Transformers（模型工具库）版本下缺少底层自动模型注册，接入层补齐注册后成功加载，官方网络结构未改写。

**原版 SensorLLM 的权重访问限制与变体结果分别记账。** 原始 Llama-3-8B 及较小 Llama-3.2-3B 均返回访问受限；按用户提出的替代方向，使用官方公开 DeepSeek Llama 蒸馏权重。DeepSeek 聊天接口不能直接承担传感器嵌入插入、隐藏状态提取与反向训练；本地变体已经完成两阶段计算，但不等同于原版模型复现。
