# 固定网格基线与逐查询掩码

六方法中的固定网格同步基线已接入新版本掩码、三种子拟合、共享表示导出和原生消费者。CLARE（认知负荷公开数据）完整开发首折已完成实际拟合与评价，完整 CPU 回归为 561 项通过、30 项跳过。

## 正确性与版本

原适配器把窗口内任一点可见扩展成全窗有效，并使用全窗均值；微调接口则使用逐查询可见掩码。新版本统一使用实际历史可见性和有效查询数池化，输入开始后的无观测前缀保持无效，输出严格为零。

新固定基线检查点使用第二版格式，显式记录有效性策略。第一版检查点加载为历史窗口策略，适配器保留原推理和均值算法；v4 拟合恢复拒绝历史掩码策略。旧权重、旧证据及运行中的冻结工作树不改写。

## 两条路线与计算量

该基线复用既有因果前向填充、训练角色归一化与 PCA（主成分投影），投影种子支持 17、29、43。其编码器没有可反传参数，因而两条路线共享同一表示；两路展示明确记录这种复用，编码器标签反传、神经优化器更新均为零。拟合和消费者的真实 CPU 耗时单独保留，不伪造任务头预热或联合适配次数。

新加载器核对数据清单、内部训练角色、归一化、投影种子、源代码和文件哈希；验证与留出窗口不能参与投影拟合。公开与鼎新留出评价复用现有函数，鼎新仍按已冻结编码器重新拟合完整训练架次的最终消费者目标。

## 实跑与验证

CLARE 第一开发折使用 366 个训练窗口和 428 个验证窗口，投影拟合耗时 10.20 秒。按受试者汇总，线性消费者的负荷分类宏平均 F1（分类综合指标）为 0.4547、回归均方根误差为 4.3165；MiniROCKET（时间卷积特征消费者）对应为 0.3820 和 3.3214。这些是种子 17 的开发结果，完整三折三种子结果继续按计划运行。

[验证摘要](validation_summary.json)保留实际路径、检查点哈希、消费者文件和日志。合成输入集成检查覆盖公开与鼎新两域、三个种子和两条路线；对应表示完全一致，拟合只读取训练窗口，缓存恢复不重新读取原生输入。全窗缺失、无观测前缀、历史扰动、微调掩码一致性及旧检查点兼容通过。

复现入口为 `run_thesis_v4.py naive-development --domain clare --fold-index 0 --seed 17`。使用仓库 `chronaris` 环境并设置 `CUDA_VISIBLE_DEVICES=''`，该过程不占用正在进行神经训练的 GPU。
