# 仿真初筛汇总与三种子复核入口

实际候选结果已接入可复核汇总，三种子复核复用同一训练器。当前修复参考完成自监督与任务引导两条路线，余弦注意力候选继续训练；全体候选与 GPU 压力结果未齐，不输出进入公开开发的最终名单。

## 初筛口径

初筛以三项任务等权排名，不按窗口数加权，也不比较不同方法的预训练损失绝对值。下表明确每项主指标的固定消费者，其他消费者和机动片段、边界及延迟成绩保留在完整指标记录中。

| 任务 | 固定消费者 | 排名主指标 |
| --- | --- | --- |
| 未来负荷分类 | 线性逻辑回归 | 宏平均 F1，越高越好 |
| 未来负荷回归 | 线性岭回归 | 均方根误差，越低越好 |
| 机动逐点分类 | 因果时序卷积与持续时间解码 | 逐点宏平均 F1，越高越好 |

每条表示路线、每种方法单独排序，任务名次取平均；同分时依次按编码器参数量、实际训练时间处理。所有已规定候选结束后，汇总器才生成完整排名；八条件压力未齐时不输出进入公开开发的名单。30 秒缺失的第 95 百分位误差相对参考是否超过 20% 单独展示，单种子初筛不作最终采用判定。三种子收益、其他任务退化约束及公开数据域等权复核仍按完整计划执行。

汇总器从保存的逐窗口预测重新计算主指标，核验消费者模型、预测、表示文件的哈希，检查全部验证窗口、标签来源、训练更新数及扩展数据清单。旧 256 条轨迹结果、工程冒烟成绩或确认角色不能进入此初筛。相同预训练初始化在两条路线中以同一检查点哈希标识，监督更新和消费者更新分别记录，汇总成本时需去重共享初始化。

## 复核预算与运行接口

复核入口支持种子 17、29、43，以及独立指定自监督、任务引导路线。预训练最多 1,500 次更新，每 100 次验证，至少 500 次后按耐心五次早停；任务头预热 50 次，联合适配最多 500 次，每 50 次验证，至少 200 次后按耐心四次早停。路径中的 1,500/500 表示预算上限，实际更新数及最佳位置从检查点和运行状态读取，不将上限冒充实际训练量。

以下命令在候选与路线已按计划选定后使用；当前未启动复核，不因接口可调用而额外扩展搜索数量。

```bash
/home/wangminan/env/anaconda3/envs/chronaris/bin/python \
  scripts/evaluation/application_tasks/run_thesis_v4.py candidate-review \
  --domain simulation --method chronaris --candidate-name reference \
  --seed 29 --routes self_supervised
```

CPU 集成测试通过实际短训练验证了种子传递、仅执行指定路线、预算和早停参数、统一消费者导出、确认角色隔离。测试缩短后的更新不作为三种子研究结果。汇总测试还覆盖未完成候选、未完成压力、修改成绩与修改预测文件的拦截。
