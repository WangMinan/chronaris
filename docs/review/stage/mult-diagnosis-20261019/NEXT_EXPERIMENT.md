# 唯一优先方案：保形生理输入的同骨干因果跨模态增量验证

2026-10-19。**将因果 MulT（跨模态 Transformer）作为新研究基底，但先证明修复后的生理信息能提供条件增量。** 当前仅为待执行提案；用户要求暂停训练，本轮不实施本方案。

## 研究假设与模型范围

明确假设：短标定段尺度与波形硬限幅破坏了部分动态；在更能学习任务的同一因果 MulT 内保留这些动态，可以得到超出同容量飞机模型和原处理 MulT 的跨人收益。若无收益，则不能继续将这一绩效任务当作生理融合优势的主要证明。

原生处理修复和信息增量是本次唯一变量族。不引入新的任务、冻结弱飞机基底的交叉残差、额外事件损失、物理损失、质量门控或延迟搜索。现有历史绩效直达、因果掩码、64维观测表示和过去5秒持久性跳接保留；网络各部分联合学习。跨模态注意力本身来自MulT，不能更名后宣称自研创新。

## 输入修复的具体候选

所有5951个窗口、飞机12字段、官方标签及严格过去边界保持。先在原生频率计算因果带通动态，再压缩汇总特征，不在滤波前把原始标准化波形截断成平台。保留每通道均值、对数标准差、对数带通均方根和过零率四项，共16项，保持输入维数。

局部中心仍用窗首2秒。尺度为局部四分位间距与拟合人员同通道非退化局部尺度（严格大于1e-6）的第10百分位的较大者，再保留原数值下限1e-6；百分位只使用当前拟合人员，禁止由选模或评分人校准。对均值采用反双曲正弦压缩，对非负幅度量保持log1p，对过零率保留原值；之后统一训练内尺度化。反双曲正弦在实数范围内单调、无硬平台；尺度下限减少两秒近乎平坦造成的异常放大。若拟合人员某通道无非退化尺度，输入资格失败并停止，不由评分人补足。参数不按评分成绩调回。

这是保留波形差异的工程候选，不等同于已验证的生理指标，也不声称所有大幅值都是有效生理活动。质量记录中的缺口、非有限、饱和和标定尺度不足分别输出；不根据标签剔除窗口。进入训练前必须通过：同一输入历史前缀修改/删除未来后不变、无非有限特征、原标签/源身份不变、合成阶跃叠加振荡仍保留振荡、真实原生高限幅窗口不再因硬限幅产生零方差平台。首2秒不可用和末端缺失规则不变；不提高来源精度或放宽1e-5历史隔离容差。

## 有界执行与验收

1. 授权后先登记准确实现、散列、统计规则和预算，再做零更新输入验收。本文件不是启动授权。
2. 第一个有界单元固定现有两折、种子17、三种必要版本，共6个拟合；神经训练上限100轮、至少20轮、耐心15轮、每模型60分钟、整个单元4小时。保留现有优化器和训练内选模规则；共同表示读出为主，专用头单列。所有模型与读出在打开外层分数前锁定。
3. 主门：候选共同读出在两折均比持久性、原强飞机、同容量飞机MulT、原处理MulT及适用强传统参照至少降低2%逐人等权均方根误差；平均绝对误差不恶化超过2%，第一折至少2/3评分人改善、第二折2/2改善。明确比较强控制，不能换成较弱的路线凑过门。
4. 配对依赖辅助门：固定同人不同记录的3个无标签替换规则，对候选共同读出做冻结诊断；两折平均误差均应恶化至少2%，且真实配对不能持续弱于去除生理数值。这是辨别模型使用配对信息的辅助条件，不代替训练消融或统计确证。
5. 首单元任一主门失败就停止本候选，不加损失、扩大网络、换种子捞结果或扩矩阵。若只胜原处理而不胜同容量飞机，结论限为输入修复，不能宣称融合优势；若只专用头胜出，不计为统一表示成功。
6. 首单元全部通过才预登记种子29的一次重复，复核同向稳定性；两种子均过门才讨论正式确认及大模型比较。两个开发划分有历史暴露、人员交叉，不能当独立确认，也不把重叠窗口当独立样本算显著性。
