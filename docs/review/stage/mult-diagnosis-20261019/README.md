# 跨模态基底与生理限幅诊断

2026-10-19。**MulT适合作为新研究基底；现有优势主要保留在削弱生理内容之后，尚不能作为人机互补证据。原生波形审计同时确认，短标定加硬限幅确实抹掉部分动态。** 最值得验证的是[保形生理输入的同骨干因果跨模态增量单元](NEXT_EXPERIMENT.md)，而非继续沿用弱飞机基底的残差修正。本轮全部为冻结推理、原始输入复算和统计汇总，训练更新与新读出拟合均为零。

## 优势确实存在，但来源尚未完全拆开

**MulT的共同表示读出在五名评分人员上都优于飞机单流。** 下表展示逐人均方根误差，单位为官方综合飞行误差分，越小越好；两折分别对三人、两人等权汇总，不能混成五个独立外部确认实验。

| 开发划分 | 人员 | 飞机单流 | MulT共同读出 | 相对降低 |
| --- | --- | ---: | ---: | ---: |
| 第一折 | 003 | 0.17874 | 0.17178 | 3.89% |
| 第一折 | 011 | 0.52501 | 0.39146 | 25.44% |
| 第一折 | 022 | 0.33426 | 0.28147 | 15.79% |
| 第二折 | 008 | 0.23822 | 0.21163 | 11.16% |
| 第二折 | 025 | 0.20160 | 0.17279 | 14.29% |

第一折整体降低18.62%，第二折降低12.60%。第一折011的改善贡献约69.1%的折内均值差距，但其余两人也改善。见[逐人差距与贡献](subject_comparison.csv)。该任务能够预测得比持久性更好，不能把此前候选失败全部归因于任务无信息。

**现有比较同时改变了结构、容量和训练方式。** 仓库因果MulT有两向跨模态注意力、各自的后续时序编码及输出投影；实际模型有1,016,577参数，飞机单流111,233参数，ContiFormer连续时间融合和修正分支各114,305参数，分别约9.14倍、8.89倍。原残差候选还额外依赖冻结飞机基底及跨人交叉残差，而MulT直接联合学习目标减持久性的修正。因此，更好的时序编码、容量和优化适配均是合理解释，尚未用同骨干训练消融分离。参数量本身也不能证明容量是原因。

**训练证据支持优先更换可学习的基底，不支持简单追加原候选训练轮数。** MulT第一折最佳第12轮，归一化训练损失0.2665、选模误差0.20795；飞机最佳第1轮，损失1.0048、选模0.27753。第二折MulT最佳第14轮，损失0.3236，而飞机最佳第10轮损失0.9898。这里是各自在最佳选模轮的训练期加权损失，含随机失活，不能当独立泛化误差或直接跨残差目标比较。现有停止规则都正常执行，并非超时截断，也不是证明全局收敛；见[训练与容量](training_comparison.csv)。

**表示与专用头必须分别看。** 第一折MulT任务头为0.39589，共同岭回归读出为0.28157；第一折011任务头0.61796，甚至略弱于该人的持久性0.61731。第二折两种读出接近0.1922。说明第一折有可解码表示未被任务头稳定转成跨人预测；不能只靠延长任务头训练或选择最好的报告路线来解决。今后继续将共同观测表示作为主门，任务头另列。

## 冻结生理干预：大部分优势在内容移除后仍保留

**生理数值置为训练中心后，共同读出反而略好。** 下表为两折原模型、原读出在同一外层窗口上的诊断，均未拟合任何参数；“置中心”保留原可用性、年龄与时间信息，只将训练尺度化后的生理数值置零。

| 生理输入干预 | 第一折共同读出 | 第二折共同读出 | 第一折任务头 | 第二折任务头 |
| --- | ---: | ---: | ---: | ---: |
| 原始配对 | 0.28157 | 0.19221 | 0.39589 | 0.19216 |
| 数值置训练中心 | 0.28019 | 0.19138 | 0.39288 | 0.19643 |
| 全路缺失 | 0.29152 | 0.19253 | 0.40129 | 0.19712 |
| 同人下一条记录替换 | 0.28217 | 0.19350 | 0.39708 | 0.19674 |
| 有效历史数值反转 | 0.28095 | 0.19274 | 0.39581 | 0.19309 |

同人不同记录替换只使共同读出恶化约0.21%和0.67%；反转数值时间顺序也没有稳定大幅恶化。完全缺失两折仍优于原飞机单流。这些结果更支持“飞机历史建模足以承载大部分现有优势”，不支持强配对生理增量已经成立。第二折任务头对生理改变更敏感，不能概括为网络完全忽略生理。

干预不是重新训练的飞机对照。缺失和置中心可能造成分布变化；置中心仍保留缺失模式；同人换记录仍保留该人的共性，且只是固定一个替换规则。其作用是检查冻结网络依赖，不是证明生理因果作用或无用。历史反转/异记录替换仅用于离线破坏对应关系，不是可在线采用的输入。全部41990条干预预测、50项逐人指标、实际供体身份见[完整指标](intervention_metrics.csv)、[汇总](intervention_summary.csv)、[供体表](intervention_donors.csv)。

## 原生限幅确实造成信息损失

**两秒局部尺度不足与滤波前限幅共同改变了动态，而不只是压缩极端数值。** 审计覆盖全部84条记录、5951窗、23804个通道窗；原生252份生理文件散列与冻结来源一致，最终查询16项特征及掩码逐一复算，最大差0。

原处理先用首2秒中位数和四分位间距标准化，再截到[-20,20]，最后带通滤波并汇总过去2秒。首2秒很平坦时，后续普通变化也可能变成极大的标准化数值；截断后不同波形值变成同一常数，滤波器接收到的波形已经失真。

下表统计最后两秒原本仍有波动、限幅后完全平坦的情况，以及带通均方根幅度变化。只对最终查询有效的窗口计算后三项；脉搏波和皮电各5950个，呼吸和心电各5951个。对未限幅波形的带通结果使用同一滤波器、初始状态和时间段，差异只来自波形限幅。

| 生理通道 | 首2秒尺度触及1e-6下限 | 最后2秒被压平 | 带通幅度保留不足一半 | 带通幅度反而超过两倍 |
| --- | ---: | ---: | ---: | ---: |
| 光电脉搏波 | 198 | 33 | 221 | 0 |
| 皮电 | 14 | 932（15.66%） | 680 | 314 |
| 呼吸 | 742 | 356（5.98%） | 771 | 1 |
| 心电 | 0 | 0 | 1 | 0 |

皮电932个压平窗分布于全部七人；呼吸压平分布于六人，并非只存在一个异常人员。皮电全窗四分位间距相对首2秒的中位倍数6.5，95百分位30.9；呼吸对应2.0和约24618，后者与大量首2秒零尺度相符。全窗尺度只用于离线诊断，不回灌历史特征，见[汇总](clipping_summary.csv)、[逐人记录](clipping_by_subject.csv)和[全部原生窗口统计](native_clip_windows.csv)。

**已证明波形差异被抹掉，尚未证明被抹掉的是目标相关生理信息。** 变化可能来自生理过程，也可能来自设备量化、缓慢漂移或接触伪迹。限幅造成带通幅度增加也提示非线性失真，不能把未限幅后的能量一概当成更好的信号。需用同骨干、同样本的重新训练对照回答预测效用，不能仅将未限幅输入喂给旧模型后用分数选处理参数。

**限幅也不是MulT胜出的完整解释。** 以四通道任一全窗限幅比例超过10%划分高限幅组，在每个评分人员的高、低两组中，MulT都优于飞机单流，见[10个逐人质量分层](clipping_error_slices.csv)。这些组存在任务难度和人员分布差异，且窗口重叠，只是描述性切片；没有把它们作为独立显著性样本或删去高限幅窗口。

## 重构决定与导师目标

**可以且值得改用MulT基底，但不应把原MulT换名就作为本文新方法。** 它在同信息任务上的学习与跨人表示更有希望，支持保留历史信息隔离、连续时间接口和标准表示交付，重新构造生理输入及融合增量。是否具有方法独立贡献，要由超过原MulT的明确改进和消融支持；本次尚未建立这种证据。

唯一优先方案见[NEXT_EXPERIMENT.md](NEXT_EXPERIMENT.md)：同一MulT分别训练同容量飞机输入、原处理双流、保形动态双流，先把容量与输入损失拆开；统一共同读出、样本和预算，仍用至少2%的两折改善及逐人/平均绝对误差门。先验证一个有界单元，失败即停止，不再堆叠未经验证的交互、损失或整矩阵。

导师的两点要求仍是最终目标：全面超过适用传统参照，并部分超过先进大模型。MulT由2019年[原论文](https://aclanthology.org/P19-1656/)提出方向性跨模态注意力，是传统融合参照；换成它不等于完成先进大模型比较。论文已登记的最终任务范围和独立确认不能由本次两折替代；任务预测优势也不能替代直接时间对齐机制证据。
