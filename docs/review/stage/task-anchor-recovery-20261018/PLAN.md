## 判定原则

CLARE 有明确采集／作者依据的锚点偏差可通过新版本数据映射修复；只有起点差或任务成绩变化不足以决定修正。无法获得锚点时，不宣称已完成严格窗口监督验证；优先考虑有明确时间标记的任务或数据，而不是盲调。

若时钟偏移与生理延迟在可见信息中不可区分，方案必须引入外部同步锚点／零延迟共享信号或明确已知一项的约束；没有识别条件时报告总有效滞后，不分别声称恢复时钟与生理时延。新实验设计必须记录真值隔离、未来信息边界与不可辨识负对照。
