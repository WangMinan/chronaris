## 2. CLARE：未证实存在可直接修正的两分钟偏移

**评分触发机制已核实，文件级锚点尚未核实。** 原论文明确以 10 秒蜂鸣提示口头评分，采用 iMotions 同步采集，并按 10 秒分段；作者当前下载入口的正式发布 README 与本地逐字节一致。当前公开仓库和下载清单没有提供评分配准脚本或逐次蜂鸣／报告时间。

0 秒与 120 秒两组实验起点可与基线分段、时间原点重置的不同方式相容。部分 120 秒起点实验与约 121 秒基线尾部相邻，因此不能据此统一平移数据。第 1674 名受试者首实验有 54 行标签但只有 42 个有限评分，第四次实验文件也缺失；当前 794 窗清单没有把这些缺项伪造成有效数据。

**需要的来源已经具体化。** 至少获得一种可把每条记录绑定到任务开始与评分行的依据：iMotions 任务／蜂鸣标记、原始口头评分时间记录，或作者的导出裁剪和行号配准说明。当前代码按脑电首采样加行号乘 10 秒建立窗口，这一假设可以完整复现，但无法仅凭现有数值唯一验证。

若拿到依据，新增版本化锚点清单并重新派生窗口即可修复；旧结果保留。若拿不到，CLARE 仍可作为明确文件起点与评分行序假设的负荷分类基准候选；精确评分时刻或真实跨流延迟的主要证据则需要有明确时间标记的数据。当前没有证据宣布整个 CLARE 数据集无效，也没有依据宣布锚点已修好。是否作为普通分类主实验，还需按既定协议获得可靠性能，不能仅因缺少逐次蜂鸣日志就把全部分类结果作废。

## 3. CogPilot：原事件响应不保留为新版主实验

**原目标可以算对，但缺少承担主实验的足够依据。** 事件来自本项目滚转峰值规则，不是官方事件响应真值；匹配非事件的绝对变化优势不稳定，时间扰动会改变部分目标方向，模型和冻结融合没有超过简单参照。

本轮前趋势延续误差为 0.35739，按窗口几何固定的 2.5 倍线性趋势为 0.61955，都高于中位数 0.25135。两处时间回退与事件输入／目标窗的交集为零，只影响一个匹配控制；去掉该控制的敏感性结果几乎不变。因此，不能把事件任务问题归结为修好这两处时间回退即可解决。

**优先在同一数据集换任务。** 官方逐时刻飞行绩效在全部 84 条开发记录中存在，综合分量算术一致，汇总差异在导出舍入范围内。但网页、字段命名与发布脚本存在归一化／缩放口径差异，需要明确采用发布综合误差分及新窗口规则。

建议替代候选为“过去 30 秒历史预测未来 5 秒发布综合误差”，先做目标覆盖和持久性资格检查，再决定是否进入模型比较。它是基于官方指标的新前瞻任务，不是原挑战协议的完全复现，不保证生理流一定带来增益。难度分类可继续作为飞行条件识别；不把难度直接当作主观认知负荷。

## 4. 直接时差恢复：工程缺项与不可辨识性分别处理

**可修的是直接估计接口、符号约定和评价流程；不能靠训练修的是缺乏独立信息。** 新方案要求输出有符号钟差、漂移、时间映射与可用性，并与零校正、常偏移及直接仿射参照比较。现有冻结表示探针和共同时刻查询保持原定位，不冒充已经实现的校时器。

在未知生理延迟的纯延迟模型中，可见总滞后为 `钟差＋响应延迟`。本轮实跑三个不同分解、同一总滞后的反例，可见信号完全相同；没有同步锚点时无法唯一分开两项。飞机单流运动学约束不会自动提供生理设备的时钟锚点。

完整方案已规定 25 个基础条件、15 个固定压力条件、独立轨迹、真值隔离、标定与评分锚点分离、漂移的短／长跨度分辨率，以及不允许利用文件边界识别条件。当前只完成协议和代数自检，新数据和估计器尚未实现，不计为恢复实验通过。

## 6. 下一步顺序与论文影响

**继续先做不训练的资格工作，当前不启动同骨干训练。** 顺序是：CLARE 获取并核验锚点来源；CogPilot 固定官方绩效新任务及无拟合参照；直接时差实现真值隔离和传统直接参照。只有主要任务定义可信、必要参照齐备，再决定一项同骨干有界训练。三项可以独立推进，不必因一个来源等待而暂停另外两项。

论文中，第二章补锚点和度量版本；第五章把当前事件响应归入诊断／扩展并保留完整历史结果。第三章继续保留共同时间查询与有依据的物理约束；在直接恢复实跑之前，不把未知钟差校正写成已验证能力。第四章的历史信息可见范围继续有效，与生理因果识别分开。上述为修订建议，本轮没有改正式论文章节。
