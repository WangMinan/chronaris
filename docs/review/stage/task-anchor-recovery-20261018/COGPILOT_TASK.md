# CogPilot 事件响应任务的去留与替代

**建议将当前滚转事件响应回归移出新版主实验，保留为诊断或扩展实验；优先换任务，不必立即换掉 CogPilot 数据。** 该决定针对当前目标定义与证据，不等于证明人体不存在事件响应，也不改变旧冻结任务和完整结果。

## 主任务资格

**当前事件与目标由本项目构造，官方主要任务是难度和飞行表现。** [PhysioNet 数据说明](https://physionet.org/content/virtual-reality-piloting/1.0.0/)描述四种飞行条件、同步生理信号及飞行路径／速度表现，未把滚转变化峰值后的皮电差定义为标准标签。当前代码使用整段记录的滚转角速度幅值分位阈值选择峰值，再计算后 8 秒与前 2 秒皮电导中位数之差；这是离线事件条件目标，事件本身的选择已使用完整记录。

**该目标缺少稳定的幅值对照与可预测性优势。** 上轮全部 1462 个事件相对匹配非事件的绝对变化差只有约 0.01016 微西门子，受试者区间跨零；±1 秒移动约使 10% 窗口的目标符号翻转。两路线冻结完整表示和组合仍未超过训练中位数。因此它不适合承担“完整方法全面优于基线、部分优于大模型”的主要证明任务。

**补充前趋势也没有解释出可靠的可预测信号。** 下表使用原登记开发三折、逐人及折间等权，目标和样本不变；均为均方根误差，单位微西门子，越低越好。新参照没有拟合参数。

| 参照 | 误差 |
| --- | ---: |
| 训练中位数 | 0.25135 |
| 训练均值 | 0.25185 |
| 零变化 | 0.25244 |
| 过去两个 2 秒段的变化延续 | 0.35739 |
| 按窗口中心间距固定为 2.5 倍的线性趋势 | 0.61955 |

过去变化与目标的逐人秩相关从约 −0.19 到 0.73，差异很大。目标与前基线的负相关也包含差分目标自身的数学耦合，不能据此直接解释为生理效应。完整数值见 [trend_summary.csv](trend_summary.csv)、[trend_correlations.csv](trend_correlations.csv) 及逐折／逐人文件。

**两次时间回退不能解释本批事件目标的整体问题。** 两个回退区间与全部 1462 个事件的输入／目标窗均无交集，只影响一个匹配控制时刻。原完整匹配结果保留；排除该控制的敏感性分析使平均绝对变化差由 0.010158 变为 0.010142，实质判断不变。见 [reversal_affected_windows.json](reversal_affected_windows.json)、[matched_control_sensitivity.csv](matched_control_sensitivity.csv)。

## 可用的替代目标及新发现

**官方逐时刻飞行表现文件在本批 84 个开发记录中完整存在。** 共核查 163768 行，发布的综合误差与三个发布分量绝对值之和最大差为 1.78×10⁻¹⁵，时间无回退。逐记录累加与汇总表的最大差为 0.0064，均在四位小数导出的累计舍入范围内。见 [performance_sources.csv](performance_sources.csv) 和 [source_verification.json](source_verification.json)。

**使用该目标前，应先锁定度量口径。** 官方网页描述累计误差按时长归一化，但随包 `compute_flight_performance.m` 定义时长后未在汇总中使用，实际汇总是误差相加。源码还先把空速差除以 10 并限幅，再保存到带有节单位名称的字段。因此新版应引用“发布的综合误差分”，记录其计算约定，不直接把该缩放列解释为未缩放的节，也不把样本和、样本均值、时间加权均值混用。

推荐替代候选为“根据过去 30 秒的生理与飞机历史，预测未来 5 秒的发布综合误差”。这是基于官方指标的新增前瞻任务，不冒充原数据挑战的完全同协议复现。未来目标必须来自排他截止点之后；输入只用截止点之前的信息。不得把同一时间段中已决定目标的飞机字段输入模型，再将公式重构成绩称为预测收益。

拟议执行约束如下，当前尚未生成或评价新任务：

- 先固定未来 5 秒时间加权均值的积分／插值与缺口规则；发布累计值另作来源校验，不混入该均值。输入和目标都要求真实时间支持，所有方法使用同一有效样本清单。
- 以受试者为外层组，同次运行及重叠窗口不跨角色；训练内拟合归一化及选参，说明已有研究设计的暴露历史。
- 必须包含训练均值／中位数、最近 5 秒综合误差持久性、仅飞机历史、仅生理历史和双流；现有难度分类按官方难度保留，但不等同于认知负荷真值。
- 先进行无训练的标签分布、覆盖、恒定性和持久性审查；若目标几乎可由近期误差延续解释，或生理没有增量，仍不能保证适合融合主实验。禁止为了提高成绩循环挑选预测时域。
- 既有冻结模型可供后续新版本推理研究，但新目标、窗口和评价必须独立绑定；旧事件响应成绩不得迁移成新任务成绩。

## 换任务与换数据的边界

**当前可以保留数据，替换主回归目标。** 若官方绩效前瞻任务经过上述资格检查仍不能提供有效变化或跨人评价支持，再考虑具有独立工作负荷／表现标注和时间同步日志的数据。若必须证明某种机动导致特定生理响应，则需要有可信事件标记、响应定义和混杂控制的数据；当前滚转峰值加皮电差不能凭模型训练补齐这一证据。

本轮完成的是原任务主实验资格判断、替代来源核验和新任务合同提案；没有宣称替代任务已经训练成功或一定超过强单流。
