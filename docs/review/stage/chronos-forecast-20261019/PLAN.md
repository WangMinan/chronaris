# 夜间原生时序预测适配对照

2026-10-19。此前Chronos-2时序预训练模型的高维表示读出未获优势，不足以评价其原生预测能力。本单元补充与未来五秒飞行误差任务直接匹配的先进模型对照，回应导师对强大模型比较的要求；不把换用预训练模型本身称为本文创新。上一轮表示读出及历史自监督结果完整保留。

## 输入与来源

使用合格扩展单元的18387窗、两折19/20名拟合人员、原选模与评分人员；保形生理16字段、飞机12字段（含4项历史绩效）及掩码完全复用。此单元没有新增静息校准条件。两个视图为飞机12字段、完整联合28字段，全部历史绩效对两者均开放。固定原Chronos-2权重版本、官方源码及77项资产，不下载、升级或改写它们。

同一窗口的变量属于同一注意力组，不同窗口/人员分组隔离。96个查询覆盖过去30秒，原生输出前16个步长对应随后5秒；输出使用综合飞行误差通道的中位预测通道，在16步上取均值，再反变换到原误差分单位。模型不接收未来协变量或未来标签输入。这里只评价一个点预测量，不宣称其他分位数经过校准；中位通道均值也不称作均值分布的中位数。

## 训练与选择

每折、每视图从同一外部预训练权重独立初始化。除零样本原生预测外，完整微调原生网络，直接最小化预测均值与官方未来五秒均值的均方误差，按原折目标尺度缩放并使用人员等权。未来标签只用于外部训练损失，不输入预测器；不构造常数未来轨迹去伪装逐时刻监督。

固定FP32、种子17、AdamW学习率1e-6、权重衰减0.01、梯度裁剪1、批4；最多5个完整轮次，至少2轮，选模误差连续2轮未达到缩放误差1e-6改善即停止。每轮按种子17加轮次打乱拟合窗口，两个输入视图的顺序相同。零样本状态作为第0轮参照参与选模，如果适配没有改善则保留第0轮；所有路线都如实报告实际更新量和选择轮次。

每1000次更新及每轮结束保存完整优化器、随机状态、样本顺序位置和检查点；截止时保存当前状态，未完成完整比较不作性能结论。单元最长4小时，与北京时间09:30取较早；总计两折两个视图四个适配，不拓展其他任务、种子或模型矩阵。编码器资格先做真实输入前向、有限梯度、重载和跨样本隔离，优化更新为零；通过且代码与合同已提交才训练。

## 评分、停止与使用边界

前序合格扩展单元须完整结束并重放；若静息开发诊断被激活，先完成其两折与必要条件比较。随后执行本单元，四个模型全部锁定后才评分。报告零样本与所选适配状态、逐人均方根误差与平均绝对误差、暴露量和资源消耗；相同训练人群MulT、飞机、统计读出以及所有既有强参照保留。原生任务适配与64维共同表示比较分开，不将一条路线的结果替代另一条。

联合输入只有在两折相对全部适用控制误差至少降低2%、平均绝对误差不恶化2%、第一折至少2/3及第二折2/2人员改善时才进入配对诊断；固定三种同人异记录生理替换平均每折恶化至少2%，真实配对不弱于置训练中心，才支持条件生理增量。未过门保留结果并停止该候选，不放宽条件。

本单元是有明确预算的开发比较。小模型与预训练模型的历史预训练量、每轮更新数、主任务标签暴露量均披露，不能以“相同人数”冒充所有计算预算完全一致。导师第二点要求仍需本文方法在完整、独立且公平的比较中通过，不能因增加一个大模型对照提前宣布实现。
