# 原生预测输入与软件验证

**两折、两个视图的输入资格已通过，尚未启动大模型监督适配。** 复用18387个合格窗口，第一折15006个拟合窗，第二折15873个拟合窗；评分仍为原五名开发人员在两折中的固定分配。飞机视图实际22通道，联合视图42通道，均含原观测值、对应观测龄和严格历史五秒均值。同一生理通道四项统计量的观测龄、四项历史绩效的观测龄逐值相同，核验后各保留一份；完整映射见[无损去重记录](age_deduplication.json)，原带重复通道的输入收据单独保留。

**历史均值缺失与短前缀已经区分。** 原缓存8405个零值都能由合法近邻支持检查判为缺失，没有模糊零值；前15个查询尚不具备完整五秒区间，也统一屏蔽。原缓存、原模型与标签没有修改，第一次只检查零值的输入收据保留在 `input_qualification_before_full_window_mask.json`；修正原因见[input_mask_correction.json](input_mask_correction.json)。最终输入身份以[input_qualification.json](input_qualification.json)为准。

**原生预测适配的软件流程经过真实结构的小网络闭环测试。** 测试覆盖窗口分组隔离、预测头梯度、逐批中断后的权重/优化器/随机状态/顺序一致、四模型锁定后评分、独立指标计算和新进程式重载重放。数值型样本标识在CSV中显式按字符串读取，防止身份被自动改型。上述软件测试使用小型随机网络，不属于真实数据性能结果。

下一步仍需在显卡空闲且持锁时，对原1.2亿参数权重完成四项真实输入前向、反向、隔离与重载资格，优化更新数保持零；资格收据提交后才进入[预登记适配单元](PLAN.md)。前序扩展和已激活静息诊断必须先完整结束，执行入口会检查这些状态。
