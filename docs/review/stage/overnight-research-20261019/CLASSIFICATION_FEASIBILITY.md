# 已登记飞行难度分类的训练内可行性检查

2026-10-19。历史监督GPU单元运行期间，仅并行执行CPU资格与轻量读出检查，不启动新的分类神经训练，不调整回归任务。

对象是已登记的CogPilot四类飞行难度，标签来自原PerfMetrics.csv的subject/date/run/difficulty，与目录等级交叉核验；不称作主观认知负荷。先核对本地来源摘要散列，再远程核对原PerfMetrics.csv散列，确保复用标签来源未变。

沿用5951个已经合格的30秒历史窗口及两个人员划分，维持同人/同记录不跨训练、选模和评分角色。此时只在拟合人员拟合、选模人员比较，外层不评分；说明窗口重叠及开发暴露，不据窗口数计算独立显著性。

固定五个统计读出：飞机、相对生理动态、两者拼接、生理动态加首2秒绝对水平/尺度、双流加该绝对信息。绝对信息只来自过去输入窗，使用asinh(中心)和log1p(尺度)，后续标准化/类别平衡和逻辑回归仅由拟合人员学习。C网格0.01/0.1/1/10/100，按选模人员宏平均F1选择；报告所有候选与多数类基准，不只报最优。

标签唯一对应、每个人员和角色均有四类、所有输入有限、来源无变化才算任务工程资格通过。是否有条件增量另报：双流相对飞机的宏平均F1差值，两种生理方案均完整列出。这是任务优先级诊断，不能把两名选模人员的成绩当独立确认或导师目标达成；未根据外层成绩改标签或挑时域。
