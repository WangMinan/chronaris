## 模型实现与测试

候选复用现有两路64维连续时间单流编码器，连接后线性投影为64维；只训练新回归任务，不加事件模块、物理项或交互搜索。独立单流使用与候选对应分支一致的随机初始化。传统融合复用现有两个适配器；原方法的原始观测接口保持不变，新增入口只复用已经核验的历史查询。

共同输入为四个生理字段和八个飞机字段。历史查询使用严格过去的原始值、有效性与观测龄；归一化采用仅拟合人员的历史查询中位数和四分位距。持久性另使用过去已发布的综合误差分，是保留的强参照；新神经模型不读取这个派生分值或未来绩效文件。

23项不同定向测试通过，覆盖目标时间隔离、非均匀积分、未来修改/删除、角色封闭、归一化隔离、原始入口与缓存查询逐值一致、双分支梯度及既有单流/传统融合回归。资格检查时编码器更新为零；随后按合同完成五种模型共25,191次更新。

## 本轮决定与后续边界

**不采用此候选，不启动第二个单元或整个矩阵。** 新任务已具有可核验目标、严格历史输入和充分有效样本，可以作为可复现的前瞻预测研究候选；本轮尚未形成融合优势，因此不将其升级为第五章“全面优于基线”的主证据。原有两个分类任务的计划地位保持，尚未由本轮重新训练或验收。

同骨干与单任务训练是本轮联合候选，不把结果归因成某一因素的独立作用。后续若继续，需要新的一项明确假设和事前合同；当前结果不授权循环更换时域、受试者、种子或融合组件。论文原件、第六章应用权重、旧事件任务及全部冻结成绩保持原样。
