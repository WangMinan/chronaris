# 新版任务范围与单个模型比较单元

2026-10-18。先提交本合同，再生成新目标、检查资格；通过后执行一个完整开发比较单元。用户已明确授权检查通过后修改模型并训练，不再沿用上一轮的全面训练暂停。原数据、模型、结果、论文原件与历史失败均保留。

## 1. 研究范围和本轮问题

新版性能主线保留 CLARE 生理负荷标准分类（评分至少5）与 CogPilot 飞行难度分类；CLARE 的窗口配准假设必须披露，不能承担精确生理时差真值。新增候选主回归为 CogPilot 官方综合飞行误差前瞻预测，通过本轮资格与开发比较后再决定正式主实验地位。旧评分回归和自定义事件响应完整保留，后者降为诊断，不按新成绩删除任务。主任务范围改变须在导师沟通中明确，不能把本轮成功等同于导师全部要求已经实现。

仿真继续承担时间、物理和历史信息机制；鼎新保留真实输入及系统案例。直接钟差恢复独立推进，不作为普通分类或有明确时间支持的预测实验的无限期前置条件。本轮仅执行新增回归资格和一个开发单元，不启动分类、大模型、其他种子、其他折或全部历史矩阵。

本轮检验：以已有较强连续时间单流骨干建立双分支、保留两路信息、只训练一个预测任务，能否超过强单流和传统融合。现有冻结表示没有互补收益不作为禁止新模型训练的条件；目标来源与历史隔离不合格则必须停止。

## 2. 新任务与数据角色

- 仅使用已登记七名开发受试者的84条记录，名单来自上一轮 `performance_sources.csv`；不读取公开确认人群的新目标。输入为截止点前30秒，预测截止点后5秒发布的 `total_error`，名称为“发布综合飞行误差分”，不将缩放后的分量误称为原始物理单位。
- 截止点从四类输入流与绩效文件共同覆盖起点后30秒开始，每5秒一个；结束于共同覆盖终点前5秒。所有候选窗完整登记，按数据规则保留或拒绝，不按目标大小或模型误差选窗。
- 输入严格早于截止点；绩效未来目标严格取 `(截止点, 截止点+5秒]` 内有限点。用相邻观测时间的中点分隔单元，首尾单元延伸到目标边界，计算时间加权均值；首末观测离边界及相邻点间隔均不得超过1秒。过去5秒持久性使用同一积分规则且严格不读截止点及未来值。无未来绩效字段进入输入。
- 输入复用四个生理通道、八个飞机通道和皮电单位转换。96个均匀历史查询点，逐字段只取查询时刻及以前的观测，保留真实观测时间、掩码；不使用双向插值。每一输入流至少90%的查询点具有有效观测，观测龄不超过2秒；每个字段至少有一个有限历史观测。时间回退影响区间相交的窗口拒绝并登记，不重排原始数据来隐去异常。
- 来源文件前后散列一致；重复身份、重复时间、非有限目标、综合误差分量不一致及角色混用视为故障。原发布的舍入事实保持，不修改原始值。
- 首个开发折沿用已登记外层分组：开发评分人员为003、011、022；训练池为008、004、025、019。为独立选模，按受试者编号排序取训练池最后一人025作内层验证，004、008、019用于拟合。标识均带 `sub-cp` 前缀。窗口与同一运行不跨人员角色。
- 所有归一化、常数、监督训练与读出拟合仅用拟合人员；025仅选停止点与读出正则；三名开发评分人员仅在模型和读出锁定后评分。这些人有历史开发暴露，不称新独立确认。

## 3. 任务资格：先算后判，不以融合已经胜出为前提

资格报告先包含全部七人和逐记录覆盖、拒绝原因、目标分布、时间支持、常数与过去5秒持久性。训练入口必须读取通过的资格收据。

硬条件：84条来源均可核验；七人每人至少8条有效记录、100个窗口；总候选窗保留率至少80%；每人目标标准差至少0.01分；来源算术和输入/目标时间隔离测试通过。阈值用于本次有界试验的可用性筛选，不宣称是数据集通用质量标准。

在四人训练池内逐人留一，比较训练均值/中位数和过去5秒持久性，逐人等权计算误差。若持久性均方根误差低于训练均值误差的20%，将任务判为近似延续即可解释，本轮不训练，也不自动改预测时域。该20%是预先指定的止损规则，不是显著性阈值。持久性不优于均值并不自动判定无法学习；只要目标和覆盖合格，允许用本轮单元检验可学习性。

若资格不通过，交付证据及原因后结束，不换任务试到通过。精确记录通过、失败与未完成三种状态。

## 4. 模型与公平对照

“一个完整单元”定义为一个数据任务、一个开发划分、种子17、一个候选及回答问题必需的固定对照组，不是整个多任务多种子矩阵。新任务无法拿旧事件分数充当基线，必要对照须在同一新样本上拟合。

| 方法 | 本轮操作与作用 |
| --- | --- |
| 训练均值、训练中位数、过去5秒持久性 | 无神经网络训练，判断基本预测价值 |
| 历史飞机/生理/双流统计量岭回归 | 相同历史观测，补强低成本传统预测参照 |
| 生理单流、飞机单流 | 复用现有因果连续时间变换器骨干，分别单任务训练，建立强单流 |
| MulT 跨模态变换器、ContiFormer 连续时间融合 | 复用现有实现，同任务同选模条件训练，避免只和弱参照比较 |
| 新双分支候选 | 复用两路相同单流骨干，连接表示并投影为64维，只训练当前任务，不增加事件、物理或新交互项 |
| 已训练独立单流表示直接拼接 | 不再训练编码器，用共同读出检验联合训练是否确有价值 |

因此最多五次必要神经网络拟合（两单流、两传统融合、一候选），每种一次；不再搜索候选结构。参数量与实测计算时间分别报告，不把相同更新预算说成相同计算量。新候选是同骨干基底验证，不提前称为已实现新语义融合机制。

主评价为冻结编码器后、统一岭回归读出的逐人均方根误差；表示均使用96个历史查询点，输出64维（独立拼接另标128维），末端有效状态作窗口表示。岭参数固定为0.1、1、10、100、1000，由内层验证逐人误差选择。专用训练头成绩单列，不能替代统一表示成绩。训练目标标准化只拟合训练人员。

各方法使用种子17、64维、两层、四注意力头、失活率0.1，AdamW学习率0.001、权重衰减0.0001、批大小32、梯度范数上限1。同一受试者等权的均方误差、同一训练数据顺序；最多100个完整epoch，至少20个epoch后才允许连续15个epoch验证误差无改善停止；改善阈值为1e-6标准化误差。保存最佳与最后检查点、逐epoch曲线、更新次数和计时。验证用于选模，外层评分不进入停止条件。

总GPU墙钟上限4小时（包括必要对照），每模型最多60分钟；达到时限且未满足训练结束规则记为预算未完成，不当作失败或通过，不削减基线预算制造优势。遇显卡锁占用先等待，不抢占；数值异常、未来泄漏、来源变化或检查点无法恢复则停止。首个完整单流实际耗时用于报告本单元可完成性，不据此扩大范围。

## 5. 验收与停止

工程验收：目标独立复算；来源身份一致；训练/验证/评分人员不交叉；未来值修改及删除不改变历史查询输出（绝对/相对容差均1e-5）；保存后重新加载预测复现；所有规定对照完成；逐样本预测独立重算逐人指标。

开发成功：统一读出的候选逐人等权均方根误差，相对全部适用常数、持久性、历史统计、两强单流、两传统融合及独立拼接均降低至少2%，并且相对最强总体参照在至少三名评分人员中的两名改善。平均绝对误差与各人结果同时报告，不能只交平均值。2%为本轮继续研究的最低实用增量，不称统计显著或满足全论文要求。

若任一对照未完成，结论为比较未完成；若工程通过但性能不达标，保留候选并结束本轮，不再追加结构、调窗口、改变标签或重跑种子。若通过，也仅建议下一项预登记复核，不自动扩到第二折或完整矩阵。仅一个开发单元不支撑跨人普遍优越或毕业要求已满足。

最终正式阶段仍须覆盖全部确定主任务与合理收敛的传统对照，并比较 TimeCMA、Chronos-2 和明确变体身份的 SensorLLM；正式方法集合、适配和预算另冻结，本轮不重新训练这些大模型。
