## 受控变化与验证

六个模型与上一单元的公共训练轮次中，训练损失和任务头选模误差逐值一致；额外的表示评估没有改变随机训练轨迹。新的最佳轮及旧最佳轮的共同读出选模误差见[选择诊断](selection_diagnostic.csv)。第二折原处理MulT仍选第14轮，其状态与旧原处理逐字节一致；第一折改选第6轮，状态不同符合预期，不能要求它复现旧第12轮成绩。

75582条主比较预测、16796条配对诊断预测独立复算110项逐人指标，最大差4.45×10⁻¹⁶；14条路线新进程重放最大差1.78×10⁻¹⁵，原容差未改。1783份保护来源不变，详见[验证](verification.json)与[资产](asset_manifest.json)。新增完整CPU合成训练检查通过，验证最佳读出检查点及评分角色不打开；原有同容量、因果和验收门继续复用。

本结果不支持将候选升级为论文最终方法；它排查了一个真实的选模混杂。后续历史监督单元沿用相同对照，进一步检查连续表示是否缺少中间时刻的训练信号，不扩大整个论文矩阵。
