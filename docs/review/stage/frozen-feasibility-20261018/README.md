## 2. 任务有效性：工程目标正确，科学解释仍需补证

**全部已登记目标与原始记录一致。** 远端只读核查 84 条 CogPilot 事件记录、15 条 CLARE 记录，共 219 份原始文件和说明；1,462 个事件目标按皮肤电阻千欧转换为皮电导微西门子后逐值匹配，794 个 CLARE 窗口的原评分、标准与历史分类共 2,382 项检查一致。源文件读取前后散列相同。由此排除了本批样本中单纯目标抄录或单位换算错误作为主要原因。

**CLARE 尚缺逐评分的独立时间锚点。** 标签每列 54 行，没有时间列；脑电起点分为约 0 秒与 120 秒，外周流相对脑电首观测差约 −0.75 至 39.52 秒。原说明与[作者仓库](https://github.com/Prithila05/CLARE)支持每 10 秒评分，但未解释逐记录评分行与信号起点的绑定。该差异也可能由采集缺失造成，目前不据此断言时钟错误，不擅自平移输入。信号物理单位的完整导出依据仍未补齐。

标准高负荷比例在四名开发受试者中为 75.00%、56.02%、89.35%、98.00%；跨人的分布差异较大。任务引导编码器原先使用历史 ≥7 标签训练，本轮 ≥5 结果是冻结表示迁移，不能代替按标准任务重新训练后的评价。

**CogPilot 事件相对匹配非事件的绝对变化优势不稳定。** 1,462 个事件全部匹配，共 1,016 个唯一控制时刻；按过去飞行状态、时间与皮电采样率匹配，没有读取未来响应来选择控制。逐受试者绝对变化差平均为 **+0.01016 微西门子**，描述性受试者重采样区间为 **[−0.01076, +0.02809]**，五人正向、两人负向。有符号配对差为 −0.02093，区间 [−0.04354, −0.00156]，反映匹配条件下方向的差异；它不等于稳定增强的生理反应，也不证明事件前可以预测该变化。

**小幅时间扰动保留部分排序，但会影响个别窗口的方向。** 前后移动 0.5 秒时，平均秩相关约 0.93—0.94，约 4.8%—5.3% 窗口符号翻转；移动 1 秒时相关约 0.82—0.85，约 10% 翻转，目标差异均方根约 0.14 微西门子。当前证据支持保留该任务作为离线事件条件诊断，尚不足以将它作为主要融合优势任务。

两条 sub-cp019 皮电记录分别有约 2.14 秒和 3.13 秒时间回退，初次顺序检查因此停止。复核后确认原标签采用时间区间布尔筛选，对源行顺序不敏感；新审查保留行顺序、逐值检查和回退计数，没有删除或重排数据，也不据此认定采集时钟已校正。初次日志保存在 `raw_remote_initial.log`。

CogPilot 官方质量摘要另作来源检查，见 [quality_documents.json](quality_documents.json)。其传感器质量表不能替代本任务的目标真值。详细质量报告体积较大，本轮停止了其全文解析，结论不依赖未审阅部分。

**全部 12 种既有条件、22 条报告路线和 792 项原模型误差复算一致。** 下表先计算每条件的全窗口均方根误差，再在对应条件组等权；单位均为秒，越低越好。六种非零偏移为正负 0.25、1、3 秒，四种附加响应滞后为 2、5、15、30 秒。

任务引导完整表示的偏移幅值超过训练均值，但仍未超过生理单流；偏移方向没有超过零参照。响应时延也未超过常数与朴素同步。相比内部消融的局部提升继续保留，不能据此写为外部比较的整体优势。

当前可评价的是冻结表示的线性可解码性。原时间探针没有漂移预测或直接时差校正输出，因此该两项记为缺项；已有漂移条件下的下游任务表已完整导出，但不将任务分数替代漂移恢复误差。

## 4. 互补性：主候选无稳定联合通过，选权重多数退回强单流

**标准任务的 24 个主要对照均未通过稳定联合门。** 四项标准任务 × 两路线 × 三种主要组合（拼接、压缩、固定均权）共 24 项，均未同时超过简单参照和两种独立单流并满足至少两折、受试者多数改善。探索性选权重也未通过。下表是任务引导路线的摘要，完整表保留两路线及历史阈值。

**CogPilot 分类的全部六个路线／折组合都选择第一流权重为零，即退回飞机单流。** CLARE 标准分类也主要依赖第二流，训练内选权重没有取得稳定增量。固定均权避免额外权重搜索，结果仍未支持加入第一流的收益。自监督事件回归的固定均权为 0.25317，超过两种单流，但未超过中位数 0.25135。

历史 ≥7 任务引导分类的固定均权为 0.42931，高于本轮三档单流和多数类均值，但逐人／逐折稳定性未通过，且仍低于保留的原三档朴素同步 0.49294。该局部改善不能用于事后选择历史阈值为唯一主任务。

**主成分压缩暴露出跨人分布与近零方差放大的问题。** CLARE 原始压缩回归误差为 31.48817／225.04444；限幅后约为 2.98，仍未超过参照。首折保留的最小训练主成分标准差约 1.4×10⁻⁶，而外层标准化分量达到约 216 万。该处理对分布漂移数值敏感，失败保留在全表，不能单独据此认定原始模态没有互补性。拼接与固定均权也未通过，因而总体进入判断并不只依赖这一压缩失败。

上轮完整表示的分块正则分类 0.43363／0.31249，以及全部传统三档、九档等控制继续单列，不因本轮采用统一三档完整表示而降低对照要求。42 组（126 个折值）未改控制与上轮复现一致。

## 5. 是否进入同骨干有界训练

**当前决定为暂不进入融合性能训练阶段。** 这是一项基于本轮进入判据的决策，不是断言整个连续时间方向不可行。未通过的主要原因分别是：

1. CLARE 标准任务尚有评分时间锚点与输入单位依据缺项；冻结单流已存在较强分类信息，但本轮没有稳定融合增量。
2. CogPilot 难度主要由飞机单流支撑，现有生理表示没有提供稳定增量；同骨干公平比较仍有研究价值，但尚没有足够收益线索优先投入完整训练矩阵。
3. 两项回归均未持续超过简单参照，事件匹配和时间扰动结果进一步要求谨慎解释目标。
4. 时间机制缺少方向恢复、直接校正和漂移估计证据，当前探针不足以支撑以此为核心的训练收益假设。

**下一步按依赖关系补证，然后只选择一个可判定的问题。** 先核实 CLARE 评分行、实验开始、信号截取的对应依据；保持原快照，确有来源时才建立修订视图。其次检查 CogPilot 回退记录与事件前趋势，确定事件标签的生理解释及可靠时间范围，不按最低模型误差反选窗口。并把时间机制评价明确为直接估计／校正或表示可解码性两类，采用非零偏移和独立响应延迟变化，先完成参照与可辨识性检查。

只有在任务口径可信、输入来源一致，并出现跨人稳定的增量或一个具体可验证的骨干／目标假设后，再登记单个同骨干实验：第一流、第二流、双流拼接，固定起点、监督曝光、选择规则及完整训练预算。此时的用途是检验该假设，不以“换强骨干一定提高”作为承诺；无增量则不继续增加复杂交互。当前不建议继续扩读出网格，也不建议直接重跑整个历史矩阵。
