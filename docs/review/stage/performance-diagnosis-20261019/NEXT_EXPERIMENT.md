# 下一项方案：信息公平的生理残差增量试验

2026-10-19。**只验证一个假设：在同样掌握过去飞行绩效、保留有效生理动态的条件下，生理输入能否跨人修正强飞机基底的剩余误差。** 这是本轮诊断后的优先提案，不是已实施的新模型，也不授权立即训练。用户本轮明确暂停训练。

## 为什么优先做这一项

旧比较没有让神经模型访问持久性使用的历史绩效分，且生理波形直接压成3.2 Hz历史点。继续在此输入上调骨干、增加交互或加种子，不能区分信息缺失与方法不足。另一方面，冻结干预证实生理分支的人员偏置会损害候选，直接联合微调也没有保护强飞机能力。因此下一项先修正可比较的输入条件，用保留强基底的残差结构直接检验增量，不先堆复杂模块。

## 同一实验的共同输入与唯一模型差别

**任务保持过去30秒预测未来5秒综合飞行误差，不再扫描预测时域或按成绩挑人。** 原始成绩保留，新输入版本另建来源清单和协议。两组模型及全部适用对照都可访问截止点前的发布综合误差及分量；真实部署若没有现成绩文件，应从历史位置、高程和空速按已核验公式构造。这两条来源须验证一致，不能把未来绩效列混入历史。

生理处理是两组实验共同锁定的数据准备规则，不作为看分后可调的选项：在原生采样上先完成有质量掩码的因果局部波形编码，再映射到历史查询点；降低采样率时先抗混叠。用输入窗内可见历史作传感器基线处理，保留动态幅度、变化与质量，避免把受试者直流偏置当成任务证据。不读取整条记录的未来统计量，不使用评分人员的目标做标定。具体滤波频率、短窗边界和通道质量阈值需依据原生采样和信号带宽，在任何新评分前写入可执行合同；本文件不虚构这些参数已经验收。

首先单独得到强飞机基底，其输入包括历史绩效和飞机历史；采用“过去绩效延续＋飞机动态修正”的预测形式，统一表示中明确保留历史绩效与飞机状态。基底只在拟合人员训练，内层人员选模，之后冻结。

主对照与候选的唯一差别是是否允许生理动态提供修正：

- 对照：冻结基底＋不接收生理的同容量修正分支。
- 候选：同一个冻结基底＋额外接收生理动态的修正分支。新增项以零贡献初始化；飞机基底权重保持冻结，拟合目标是基底尚未解释的误差，不重新学习整个绝对绩效值。

这保护既有飞机表征并把新增任务限定为修正，但零初始化和冻结并不保证最终泛化不退化。两分支监督曝光、选模、参数规模和预算可比；若结构为匹配参数而补零输入，明确记录。基底在拟合样本上的残差可能过于乐观，修正分支的训练目标应使用拟合人员内部交叉生成的基底预测，不拿基底训练内误差假装未见残差。

## 对照与验收

必要控制保留：训练常数、过去5秒持久性、接收历史绩效的强飞机模型、同信息的简单线性/传统融合、同基底的不含生理修正分支，以及候选。原输入版本的成绩单列历史对照，不与新版本拼成同一排名。容量匹配和共享历史信息两项不能省略。

主问题是候选相对**同信息、同基底、同容量**对照的跨人增量，而不只是比旧版0.83144低。沿用至少2%的逐人等权误差下降作为继续投入门槛，且超过持久性、强飞机和全部登记传统控制；报告每名人员方向。统一表示经相同下游的收益与专用残差任务头分别报告：若只有专用任务头改善，只支持该任务模型，不宣称通用融合表示改善。

人员均有开发暴露，不能把再划分称为新的独立确认。未来若授权该试验，应在看新分数前固定人员外层评价与内层交叉残差生成，至少覆盖两个事先指定的开发划分；以完整单元实测核算预算，不许只保留赢的一折。已有末轮三名人员的分数已被审查，只能作为公开标注的内部开发结果。

输入质量或历史隔离不通过则停止；同信息基底本身未形成可靠预测能力则停止增加生理分支；候选没有跨人稳定增量则不再在本任务上扩复杂融合，将该任务保留为预测/诊断证据。只有通过，才考虑将历史交互加入新方法并登记正式比较，不自动展开全矩阵。

## 与导师要求及论文主线的关系

这一步首先回答“生理信息能否带来真实增量”，是冲击全面优于传统基线的必要研究判断；它本身不能完成导师要求。通过后，才对固定方法、所有已确定主任务和全部合理收敛的传统基线进行多划分/种子比较，并与导师认可的先进大模型方案比较。TimeCMA语言增强时序方法、Chronos-2时序基础模型和SensorLLM传感器语言模型现有适配记录保留；原版权重、变体及任务适配边界继续说明，不将旧任务的大模型分数移植到新任务。

若这个有来源的新任务仍只依赖飞机信息，它不适合继续承担“人机融合优势”的主证据，应调整其论文地位；不能为了保住任务一直加复杂度。连续时间与语义融合的贡献仍需另外证明历史查询质量和跨流交互增量，单纯绩效残差修正不能顶替第三、四章的机制论据。允许替换骨干或改写章节，保持真实结果和研究目标。
