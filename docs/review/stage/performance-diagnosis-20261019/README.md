# 新候选为什么落后：任务、输入与训练诊断

2026-10-19。**当前证据同时指向任务偏重飞机短期状态、输入信息不对等和生理分支泛化问题；不能把一次失败归结为“融合方向不可行”。** 最值得继续的不是加大当前模型，而是[信息公平的生理残差增量试验](NEXT_EXPERIMENT.md)：保留强飞机基底，只检验生理动态能否提供跨人修正。本轮仅分析，零编码器更新、零真实数据读出拟合，原结果保留。

## 1. 持久性领先不能全部归于模型学习不足

**持久性直接掌握了神经网络没有获得的历史绩效信息。** 神经模型只有八个飞机字段，没有过去发布综合误差，也没有官方几何误差构造所用的经度、纬度和海拔高程。官方源码根据这些位置字段、固定跑道参考和空速构造综合误差；仪表着陆偏差和离地高度不能不经核验就当作这几个变量的完全等价替代。每名开发受试者第一条登记记录的飞机CSV均包含这三个位置字段，源数据可用，但上一轮输入没有采用。

持久性只用过去5秒绩效，没有未来泄漏，是有效的强预测参照；但它不是与当前神经网络相同信息范围的纯算法对照。上一轮合同已披露该差别，结果不能据此宣称“神经模型学不会相同历史信息”。输入公平性应在下一版本修正，旧成绩不重写。来源为已保存的官方MATLAB脚本与原始CSV表头，见[信息范围](information_contract.json)、[来源采样核查](source_sampling.json)及[此前目标来源核查](../task-anchor-recovery-20261018/COGPILOT_TASK.md)。

**持久性的平均领先主要集中在一名评分人员，不能概括为所有人都不如延续当前值。** 下表复算同一2517个窗口，以每人均方根误差衡量；单位为发布综合飞行误差分。

| 人员 | 飞机单流 | 新候选 | 持久性 | 飞机单流相对持久性 |
| --- | ---: | ---: | ---: | --- |
| 003 | 0.24092 | 0.43000 | 0.24988 | 略好 |
| 011 | 1.42670 | 1.53402 | 0.61731 | 明显落后 |
| 022 | 0.47134 | 0.53032 | 0.51184 | 略好 |

011人员占三人等权平均误差差距的106.51%，另两人的改善抵消了一部分。这是算术贡献，不是因果贡献。该人的目标均值3.856、标准差2.432，高于三名拟合人员各自的均值和标准差；飞机单流平均低估约0.685分，候选低估约0.670分，同时还有较大的动态误差。持久性自然携带当时绩效水平，低估仅约0.061分。分布外推和历史信息差异均是有证据的解释，尚未通过同信息重训分离其因果份额。

**任务具有明显短期延续性，但并非已经证明“只靠持久性就解决了”。** 三人未来目标与过去5秒绩效相关系数约0.868、0.968、0.883。官方目标本身由飞机几何位置和速度定义，5秒短期外推天然偏向飞机状态；生理信息若有价值，必须体现为剩余误差上的条件增量。原资格检查只确认目标来源、覆盖、变化和允许一次试验的最低门槛，没有证明它适合承担融合优势主实验。见[误差分解](error_decomposition.csv)与[偏差/动态误差](scoring_errors.csv)。

## 2. 新候选的生理支路确实带来了可定位的退化

**冻结线性分解发现，生理支路在评分人员中主要贡献人员间偏置。** 候选由两路独立编码器、128到64维线性投影、线性任务头或岭读出组成。固定权重后，最终预测可精确写成“生理分支贡献＋飞机分支贡献＋常数”；它是两路非线性函数的相加，没有输入相关的跨模态交互。此次验证的是同骨干联合训练基底，尚未检验新的历史交互机制。

评分人员003、011、022的生理贡献在各自所有窗口中的标准差仅0.00148、0.01496、0.00608，而飞机贡献标准差为0.50778、1.81524、1.14237。生理分支在三人中的平均贡献却分别约0.779、0.461、0.533，说明其主要差异体现为人员偏置。幅度本身不等于信息量，但结合下述冻结干预可以判断它对已训练候选的作用。

**仅把生理表示替换为拟合人员的加权平均，不更新任何参数，就能降低三名评分人员的误差。** 表中干预使用原投影和原岭回归权重，是诊断，不作为重新训练消融或替代主成绩。

| 人员 | 原候选误差 | 生理固定为拟合均值后的误差 |
| --- | ---: | ---: |
| 003 | 0.43000 | 0.24404 |
| 011 | 1.53402 | 1.52186 |
| 022 | 0.53032 | 0.51929 |
| 三人等权 | 0.83144 | 0.76173 |

整体误差下降8.38%，但仍高于独立飞机单流0.71299。003人员的平均偏差由0.36010降至0.06580，提供了生理人员偏置造成退化的直接冻结模型证据。剩余差距不能仅凭该干预归因为飞机编码器“被破坏”：联合训练的分支、投影、读出和选模都不同，潜在表示存在协同补偿，需要受控训练才能分离。见[全部角色分支干预](branch_interventions.csv)。

## 3. 生理输入不足以检验原始模态的潜力

**历史查询大幅稀疏化原始波形，且没有先提取动态特征。** 按预先固定的抽查规则，七名开发受试者各选路径排序第一条记录，共28份原始文件。正时间间隔中位数对应频率：心电约128—505 Hz，呼吸约128—505 Hz，光电容积脉搏波与皮电所在数据流约128—1025 Hz，飞机约4.5—5.6 Hz。原始采样有间隔变化，这不是宣称所有记录均匀采样。

当前输入对30秒仅作96次查询，即3.2 Hz，每次直接取最新原始值；代码没有先抗混叠、提取波形特征或作原生频率的局部编码。慢变皮电等信息可能仍然存在，但不能据此认为心电和脉搏波的有效波形信息已被充分提供给模型。现有实验因而不能区分“原生生理信息无帮助”和“输入处理没有保留有帮助的信息”。此处未训练新生理编码器，也未以新特征成绩反选处理方式。

**跨人直流基线差异又提供了强干扰。** 呼吸通道在拟合人员004、008、019中的中位数约64.06、61.15、63.31，选模人员025约5.38，评分人员003约463.66。003标准化后的幅度约为145个训练四分位距，而其自身四分位距只有约0.228。全局训练中位数/四分位距变换没有解决这种跨人的偏置；这不等于已证明传感器故障或单位错误。

原生理统计岭回归在003的误差58.394，导致三人平均20.938。对既有线性读出作精确项分解，呼吸均值和末值两项的平均贡献分别约27.10、29.11，解释了大部分异常输出。失败被定位到跨人特征水平外推，不能拿这个失败直接证明生理模态不适合任务。见[输入尺度](input_scale.csv)与[全部线性项贡献](statistics_contributions.csv)。

## 4. 训练不足不是最有力解释，泛化和结构更值得优先处理

**已训练模型能拟合训练人员，但候选并未比飞机单流学得更好。** 下表使用保存的最佳权重重新推理，仍是共同岭读出，角色内先逐人再等权；没有拟合新的参数。

| 方法 | 拟合人员误差 | 选模人员误差 | 开发评分人员误差 |
| --- | ---: | ---: | ---: |
| 飞机单流 | 0.12820 | 0.28235 | 0.71299 |
| 生理单流 | 0.92777 | 1.13750 | 2.12725 |
| 新候选 | 0.15325 | 0.34782 | 0.83144 |

候选在96个epoch后按规则停止，最佳为81；飞机单流完成100个epoch，最佳为86。结果支持跨人泛化和输入信息限制，不能证明增加训练步数必然补齐差距。候选专用头的评分误差0.78851虽然比其岭读出0.83144好，但仍弱于飞机单流专用头0.71678，所以也不只是最后一层岭回归的问题。

拟合只有三名受试者，选模只有一名；5951个窗口不能当成5951名独立人员。单个种子、单个划分不足以确定哪一种训练目标或结构必然失败。见[各人各角色成绩](role_metrics.csv)，原完整学习曲线和停止收据保留在上一轮目录。

## 5. 综合判断和唯一优先方案

**这个任务偏向飞机状态外推，暂不适合作为已经确定能证明融合优势的主战场；但上一轮不足以判它不适合任何融合模型。** 任务来源与时间隔离可靠；相较之下，生理信息保留、传感器基线处理、比较信息范围和强分支保护均有明确缺口。应先通过一次能区分这两类解释的受控试验作去留决定。

唯一推荐是[信息公平的生理残差增量试验](NEXT_EXPERIMENT.md)：所有方法共享合法历史绩效；生理从原生波形得到因果、基线稳健的动态表示；冻结强飞机基底，只学习是否能由生理补充解释剩余误差。主对照具有相同历史信息、相同基底和匹配修正容量。保留持久性、强飞机及传统控制，不只比较新版与失败旧版。

若有稳定增量，再按固定方案推进统一表示和大模型正式比较；如果没有，则停止在本任务上堆模型，将其保留为预测/诊断证据，调整论文任务地位。导师的两项要求仍然是正式阶段目标，本轮不会把一次事后干预降低误差包装成已达成全面领先。第三、四章的连续时间和历史交互贡献须各有机制证据，允许随最终模型改写。
