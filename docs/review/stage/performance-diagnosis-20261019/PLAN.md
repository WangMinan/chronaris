# 新候选误差诊断：零更新范围

2026-10-19。承接已完成的[单个开发比较](../performance-pilot-20261018/README.md)。用户要求区分任务适配与模型训练问题，并只提出一个最值得验证的下一步方案。本轮不训练、不拟合读出、不选择新权重，不修改原结果或论文。

诊断固定为四项：

1. 复算逐人误差、偏差和目标变化，区分候选相对飞机单流的退化与持久性优势；对照官方绩效构造源码和八个飞机输入字段，核对信息范围。
2. 读取既有最佳检查点，在原拟合、选模和评分角色上执行冻结推理。检查训练拟合与跨人误差，以及专用任务头和统一读出的差别；不根据诊断改选其他epoch。
3. 对线性投影和岭读出的候选作精确分支贡献分解；分别把一条分支替换为拟合人员的平均表示，检查原权重如何使用信息。这是冻结模型的干预诊断，不是重新训练消融或新主成绩；分支间允许补偿，不能把贡献幅度当作生理因果证据。
4. 检查生理历史查询的采样保留方式、跨人尺度和统计读出的大误差来源。原始采样率只抽查每名开发受试者按路径排序第一条已登记记录，不根据成绩挑记录；原文件只读并核验散列。

所有新输出位于本目录及对应独立资产目录。计算前登记旧单元全部报告、输入、读出和检查点的保护散列；结束再验证。模型和旧主结果不改写。结论明确分为已确认事实、支持的解释和仍需新实验区分的假设。若固定检查不能唯一归因，保留不确定性，不凭单折负结果宣告原始模态无价值。

下一步方案围绕本轮最关键未决问题设计，必须保留全部适用强基线和大模型比较目标；本轮不执行该训练方案，不以同一批已看过人员再次评分冒充独立确认。
