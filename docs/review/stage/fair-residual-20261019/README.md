**不采用此生理残差候选，不追加第三折、其他种子或整个矩阵。** 当前结果支持继续保留这个有来源的预测任务作为研究候选，但不将它升级为本文残差方法全面领先的证据。MulT的两折较强表现说明不能把失败概括为整个任务不可预测；本轮没有MulT专门的生理输入匹配消融，不能直接把其优势归因于生理模态。旧方案、旧标签、旧不利成绩和论文原件保留。

## 输入处理限制

**工程核验通过不等于生理信息已被完整保留。** 四类通道的限幅比例中位数均为0，但皮电1479个窗口（24.85%）有超过10%的原生点触发限幅；呼吸732个窗口（12.30%）有超过50%的点触发限幅，脉搏波相应为190个窗口（3.19%）。这些窗口没有按成绩剔除或回调处理参数，见[限幅与采样汇总](processing_quality_summary.csv)及[逐窗通道记录](physiology_quality.csv)。

两秒局部标定和固定频带只是本次候选的预登记输入处理，不构成临床生理有效性验收；短标定段与后续波动差异可能影响动态保留。它是解释本轮“未证明生理增量”时应保留的具体限制，不能据此宣告原始生理模态永远无用，也不能把待改进方案写成已完成优势。
