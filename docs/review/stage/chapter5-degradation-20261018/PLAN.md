# 完整方法退化诊断计划

2026-10-18。目标是解释完整方法相对单流与传统方法的差距，并形成可执行的修复和补充实验方案。主要证据使用 CLARE 生理负荷数据与 CogPilot 虚拟飞行数据；鼎新仅保留辅助背景，不据其成绩选择方案。

本轮只读取冻结输入、模型、预测和训练日志。新增文件限于诊断脚本、审查数据和文档；不修改生产算法，不更新编码器或原下游权重，不启动长训练，不回写原结果。若进行短探针，仅使用独立输出及训练、内部验证角色，并记录与正式结果的区别。

1. 核验公开五折的样本、目标、统计单位、汇总与模型间可比性。
2. 分别审查自监督、任务引导与两种共同下游；按受试者配对并保留全部折。
3. 核查实际预算、选模、机制开关及训练曲线；比较完整方法、既有配置、语义消融和强参照。
4. 追踪融合输出、单流旁路、门控、池化和下游标准化；优先使用冻结缓存和无更新前向诊断。
5. 将确定事实、支持性证据与待验证假设分开，提出最小修复及分阶段实验门。

统计区间属于看到正式成绩后的探索性诊断：固定现有模型，在各折内按受试者配对重采样，再按折等权汇总。它不包含训练随机性、折间共享训练集带来的依赖或多重比较校正，不作为预注册的显著性证明。
