**CLARE 的第二生理流信息没有完全丢失；将所有表示维度一起交给同一个线性下游，反而降低了内部验证表现。** CLARE 第一流是四个脑电字段，第二流是皮电和心电；二者都是生理信息。对完整模型导出的冻结表示，保持样本、归一化规则和原有超参数网格，分别拟合完整 64 维、第一流 24 维、第二流 24 维、跨流 16 维及两流分支 48 维的小型线性诊断头。

## 3. 骨干、训练目标与读出并不等价

**独立单流基线不是从本文模型中删除另一路得到的模型。** [单流实现](../../../../src/chronaris/modeling/fusion_encoders/single_stream.py)使用连续时间变换器 ContiFormer，输入包括值、有效标记和观测年龄，再投影到 64 维；本文使用双流常微分方程递归网络（ODE-RNN），输出分为 24＋24＋16 维。因此，“不如单流”包含骨干、观测处理、表示空间与读出差异，尚不能全部归因于融合操作。

这一混杂在 CogPilot 尤其明显：本文第二流分支的难度分类验证 F1 为 0.46911，独立第二流基线为 0.51670；完整融合能升到 0.47627，仍有差距。需要同骨干单流对照与投影前后探针，才能进一步区分骨干学习、投影和跨流训练的贡献。CLARE 的完整模型约 29,866 参数，第二流基线约 30,112；单流优势不能简单归因于参数更多。MulT 约 260,416 参数，则确实属于更大容量对照。

**任务引导的训练和选模目标与最终评分路径不一致。** 神经网络任务头读取未经共同下游标准化的池化表示；微调检查点默认按分类损失和标准化回归损失的平均值选择。正式结果则丢弃这些任务头，使用训练数据拟合的 StandardScaler 标准化，再分别拟合逻辑回归或岭回归，并以受试者 F1/RMSE 评价。源代码见 [微调选模](../../../../src/chronaris/evaluation/application_tasks/application_finetuning.py)、[共同下游](../../../../src/chronaris/evaluation/application_tasks/consumer_model_selection.py)。这是已确认的目标差异；它是否是当前差距的主要原因，仍需同一训练轨迹的检查点对照，不能直接改选旧测试成绩更好的模型。

**更新预算一致不能证明每种方法都已训练充分。** 完整配置十个公开预训练单元均选中了预算末端；CLARE 为 300 次更新，CogPilot 为 351—398 次。当前没有同源更长轨迹的对照，不能据此确认未收敛，也不能用“再多训一些”作为已证实修复。微调后主结果与自监督也有交叉变化，不存在统一增益。[训练轨迹](training/loss_curves.csv)、[内部验证汇总](training/validation_metrics.csv)。

## 4. 可以确认的结构限制与尚待验证的原因

**小跨流门值不保证共同下游忽略跨流信息。** 现有结构将门控后的跨流特征拼接到输出；随后共同线性下游逐维标准化。对于固定正比例门值，标准化会精确抵消其尺度，因此“门较小就能保证安全退回单流”并不成立。实际门值随样本变化，不能把这个数学事实扩大为完全抵消；它说明需要评价读出后的贡献，而不能只看门值。并且现有门仅控制跨流块，不控制脑电等第一流分支，无法防止所有形式的负迁移。

**当前时滞注意力在单个允许时间区间内的选择强度有很紧的上限。** 当前余弦注意力先把查询和键归一化，再除以隐藏维数 32 的平方根。任意两个合法位置的未归一化权重比最多为 `exp(2/sqrt(32)) ≈ 1.424`，因此它更接近各时段内的平滑汇总，而不是尖锐事件匹配。尺度门仍可选择不同时间区间。代码支持学习温度或投影点积的备选方式，但历史温度试验未通过采用门，不能直接推定切换即会提分。[注意力实现](../../../../src/chronaris/modeling/fusion_encoders/safe_lag_fusion.py)。

**公开完整配置没有有效运动学残差关系，不能把公开退化归咎于物理残差过强。** 实际启用的新增目标主要是观测锚定、同时刻连续状态相似性、方向判别和显式时移。连续对齐项约束同一查询时刻两流隐藏状态相似，这与生理响应可以延迟的假设有潜在张力；现有代码已有时滞容忍目标，但该配置没有启用。需要以实际梯度、单因素对照与时间任务共同判断，不能直接删除物理机制。

无更新前向与梯度测量的完整记录见 [原始记录](forward/summary.json)，具体量化结论见 [补充诊断摘要](FORWARD.md)。实测十组配置的归一化注意力熵均接近一；CLARE 分类与回归在 3/4 批次方向相反，CogPilot 分类与公共自监督项在 4/4 批次方向相反。它们使用固定首折，前向抽取 16 个内部验证窗口；梯度只取两个训练受试者的合法任务批次，不代表全数据或完整训练轨迹。

## 5. 修订后的执行顺序

**先补同集简单参照、同维度对照与明确验收矩阵，再考虑有界微调。** 最新完整方案及资源上限见 [复核修订](REVISION.md)，逐项表见 [实验矩阵](revision/experiment_matrix.csv)。

原先相对旧模型的 F1 提高 0.02、回归改善 5% 仅作为开发筛选参考，不能代表导师目标达标。主要比较固定四个公开任务、两种学习路线和共同线性下游；传统、简单及大模型对照完整保留，同等调参资源，不能按结果替换路线。

50 次更新只检查执行和早期趋势；机制结论需要同起点、同阶段、匹配标签曝光的完整对照。梯度冲突和近均匀注意力是待验证线索。同维度、同骨干控制尚未执行，不作已完成陈述。

当前没有已核验的新增未暴露公开确认来源或受试者名单，独立确认保持关闭。原开发名单和已经查看的确认名单已记录，换种子或重新切分不能恢复盲测资格。鼎新继续只作辅助参考。
