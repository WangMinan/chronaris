# 冻结前向与梯度补充诊断

**本轮实际测得近均匀的时滞注意力和局部任务梯度冲突，未发现公开物理残差参与损失。** 使用原检查点完成十组前向诊断、十二个训练批次的梯度分解；优化器更新次数为零。十六份已读取的最佳及末次检查点前后散列一致。实跑文件见 [完整记录](forward/summary.json)、[CLARE 梯度](forward/clare/gradients.json)、[CogPilot 梯度](forward/cogpilot/gradients.json)。

## 前向：跨流块未被简单关闭，但时间位置区分很弱

每种配置、路线固定读取首折中按样本标识散列选出的十六个内部验证窗口，不按模型成绩选择。注意力熵除以相同合法位置数量的均匀分布熵；仅统计至少两个合法位置的查询，值越接近一表示越接近均匀分布。

| 数据与配置 | 路线 | 跨流门中位数 | 归一化注意力熵 |
| --- | --- | ---: | ---: |
| CLARE 既有配置 | 任务引导 | 0.1702 | 0.99999884 |
| CLARE 完整配置 | 自监督 | 0.1053 | 0.99999853 |
| CLARE 完整配置 | 任务引导 | 0.1133 | 0.99999862 |
| CLARE 无事件语义 | 任务引导 | 0.2562 | 0.99999864 |
| CogPilot 既有配置 | 任务引导 | 0.5496 | 0.99999837 |
| CogPilot 完整配置 | 自监督 | 0.2032 | 0.99999678 |
| CogPilot 完整配置 | 任务引导 | 0.1564 | 0.99999725 |

这与代码中归一化余弦再除以隐藏维数平方根的限制一致。现有注意力可以按尺度汇总历史，但本次没有看到明显尖锐的区间内位置选择。不能从门值较小推断跨流块没有参与最终分类：共同下游还会逐维标准化，且冻结读出干预已表明 CogPilot 分类使用了跨流信息。

**协方差能量较集中，但尚不足以宣布表示完全塌缩。** 十六窗口前向中，CLARE 完整任务引导表示的参与率有效秩约 1.06；全部训练缓存按五折计算的均值约 2.25。参与率定义为协方差特征值之和的平方除以特征值平方和，衡量能量集中程度，不等于非零维数或可用信息维数。分支线性探针仍能得到不同成绩；应与标准化后的谱和任务读出共同解释，不单凭秩决定删模块。

## 梯度：冲突有任务差异，物理残差不是当前主因

每个数据域固定取首折的两个训练受试者，按样本标识散列选取任务有有效标签的批次。CLARE 两项任务共享标签窗口，共四批；CogPilot 两项任务位于不同窗口，分别四批，共八批。失效任务标为不可用，不把缺标签得到的零梯度解释为断开。梯度测量复用已有实现，只考察共享连续骨干；任务项沿用诊断的等权定义，属于局部加权梯度，不是完整有效批量优化器更新的精确重放。

下表按有定义的夹角统计，负余弦表示两个损失在当前参数和批次上给出相反更新方向。两个训练受试者不能代表所有受试者和训练阶段。

| 数据与梯度对 | 负余弦批次 | 余弦范围 |
| --- | ---: | --- |
| CLARE 分类与回归 | 3/4 | [−0.625, +0.596] |
| CLARE 分类与观测锚定 | 3/4 | [−0.263, +0.068] |
| CLARE 回归与显式时移 | 3/4 | [−0.302, +0.427] |
| CogPilot 难度分类与公共自监督项 | 4/4 | [−0.806, −0.086] |
| CogPilot 难度分类与同时刻连续对齐项 | 4/4 | [−0.036, −0.006] |
| CogPilot 响应回归与公共自监督项 | 1/4 | [−0.196, +0.081] |

CogPilot 回归任务梯度范数为 0.0188—0.1704，所有测量批次的观测锚定为 0.5527—0.7781，公共自监督项为 0.4775—0.6574。不同项作用方向、样本支持与累计方式不同，范数较大不能直接认定有害；但它说明仅看标量损失很小不能排除辅助项显著影响回归骨干。CogPilot 分类和回归没有同批有效标签，所以本轮不报告两者的同批夹角。

**训练日志与实际配置均显示物理残差为零。** 首折完整任务引导轨迹中，CLARE 观测锚定、显式时移加权损失均值分别为 0.03415、0.08168；CogPilot 分别为 0.14428、0.11075；两域运动学残差均为零。观测锚定与运动学残差是不同目标，不能统称为“物理项过强”。同时刻连续对齐项的加权损失及梯度较小，也不支持把它直接指定为唯一根因。

## 对修复顺序的影响

1. 先处理已有验证支持的任务读出和正则范围问题；该步骤不需要更新编码器。
2. 对需要继续微调的任务，分离分类、回归和辅助目标，做同起点、同预算的有界对照。记录有效标签数，避免把不同任务窗口的无标签梯度误判为冲突。
3. 注意力近均匀属于实际机制限制，但修改它不保证主任务提分。若进入该实验，同时测非零时移识别、因果边界和任务保护；不重复历史已经失败的温度配方而缺少新的对照。
4. 本轮没有执行新的长训练，也没有把诊断结果替换为正式主结果。生产修复和正式补证按 [主报告方案](README.md) 分阶段开展。
