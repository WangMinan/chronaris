# 原固定开发人群的眼动来源可用性检查

2026-10-19。官方示例以眼动聚合量预测累计飞行误差，当前研究单元则使用四类生理信号预测未来五秒均值，二者任务与输入均不同。依据为原数据随附的 `starterCode/assembleFeatureMatrix.py` 与 `starterCode/trainModel.py`；总体研究目的见[数据发布页](https://www.physionet.org/content/virtual-reality-piloting/1.0.0/)。不能把当前短时任务失败推广为全部人机信息无用。

只读检查原七名开发人员84条记录中的眼动数据文件。记录唯一文件身份、行数、时间范围、有效性字段原始取值分布、瞳孔直径和眼睑开合的有限/正值计数；不读取新的人员，不改变5951个模型窗口，不拟合任何模型。源文件前后散列一致。

本检查仅判断是否真的存在观测，不把有效性位非零直接解释为所有字段有效。眼动SDK的逐字段有效性位尚未完成核验，因此即使发现数据，也不启动眼动模型训练。只有一行全零的文件按缺乏实际观测登记，不因字段名齐全而视为可用输入。
