# 眼动来源可用性补查

**原七人并非都有实际眼动观测，不能直接将眼动替换为主生理流。** 84条记录中72份文件具有时间序列结构；003号人员全部12份眼动文件都只有一行全零。其余六人各有12份序列，原始有效性字段和数值分布已登记，但逐字段有效性位尚未解码，不能将这些序列直接称为已合格的生理输入。

**官方示例与本轮任务的区别得到源代码确认。** 数据随附示例提取眼动聚合统计，并预测累计飞行误差；本轮则使用脉搏、皮电、呼吸、心电以及飞机历史，预测随后五秒均值。示例来源散列及目标字段见[source_note.json](source_note.json)，总体数据目的见[官方发布页](https://www.physionet.org/content/virtual-reality-piloting/1.0.0/)。当前结果只评价当前输入和目标，不能外推为所有人因通道均无价值。

**若后续检验眼动增量，必须保留原评分人员并显式处理缺省通道。** 003号人员不能因缺眼动而被删掉；原四类生理信号和飞机输入也不能被占位零替换。下一步先核查逐字段有效性位、无效值、严格过去支持及可用率，再登记一个相同信息条件的候选。此补查没有构造眼动模型输入、没有读出拟合或编码器更新。

证据：[计划](PLAN.md)、[逐人汇总](subject_summary.csv)、[逐记录清单](record_inventory.csv)、[完整来源及标志分布](inventory.json)。第一次汇总在序列化NumPy布尔量时失败，日志保留；修正为标准布尔量后重读并完成，未改原始数据。
