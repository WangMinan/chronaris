# 合格拟合人群扩展结果

**增加拟合覆盖显著改善预测，但保形融合仍未通过稳定优势门。** 两折分别以19和20人拟合，六个同骨干模型全部正常停止，完成136773次更新，用时5666.22秒（约94.4分钟）。原5951个开发窗口保留，合并训练数据18387窗；每种模型使用相同新增人员和停止规则。

下表呈现逐人等权均方根误差，越低越好，区分共同读出和专用预测头。它支持“拟合规模有实际影响”，同时保留同容量飞机对照来判断收益是否属于融合。

| 版本与读出 | 第一折 | 第二折 |
|---|---:|---:|
| 同容量飞机，共同读出 | 0.23106 | 0.16584 |
| 原处理MulT，共同读出 | 0.23492 | 0.17479 |
| 保形MulT，共同读出 | 0.23504 | 0.16712 |
| 同容量飞机，专用头 | 0.27332 | 0.16390 |
| 原处理MulT，专用头 | 0.27323 | 0.16254 |
| 保形MulT，专用头 | 0.27285 | 0.15515 |
| 保形输入统计读出 | 0.29375 | 0.21360 |

**第二折专用头的局部改善尚未构成稳定融合优势。** 候选相对该折最强非候选控制平均改善约4.55%，但只改善两名评分人员中的一名；共同读出两折均未胜过对应强对照。三种同人异记录替换的平均误差恶化仅约0.10%和0.23%，低于2%的预登记门；第一折置训练中心还略优于真实配对。未触发同输入连续时间变换器的条件补训，不扩种子或矩阵。

**全部主结果已独立复算和重放。** 230945条主表预测、16796条配对预测及295项逐人指标复算通过，最大差异4.44×10⁻¹⁶；14条评分路线重放差异不超过1.78×10⁻¹⁵。2082份保护来源保持不变，原模型与历史失败保留。

**读出信息口径仍值得单独核对。** 专用头加回准确的历史五秒均值；原共同岭读出使用64维表示，没有显式接入这项均值。上述旧协议结果不改写，后续冻结模型另做公共历史均值的读出对照，判断这一接口因素的影响，避免把不同读出形式的差异直接当作表示能力差异。
