# 扩展训练后的确认角色边界

**本轮扩展能够提供更大拟合人群的开发证据，但后续新方法不能直接沿用原全部五折作为盲确认。** 追加人员来自旧第一折训练角色；在交叉验证中，同一个人又可能是其他折的留出人员。因此新任务构造和模型训练的开发暴露，需要与原逐折角色同时审计，而不能只检查第一折。

**后续正式比较须先重新冻结确认协议。** 可以在已经保留的新目标留出范围上规划确认，或使用额外独立数据；原其他折需要披露已有开发暴露，不能继续称作未接触的确认人群。新协议不得按本轮评分挑人，也不能把同一组留出的人为分割当作新的独立五折。原五折模型、成绩、样本角色文件及图表全部保留。

当前两折19/20人拟合、静息诊断及原生大模型适配均明确属于开发工作。即使其中候选通过性能门，也还需要同条件强参照、重复训练稳定性和上述正式确认，才可用于导师要求的最终优势论断。
