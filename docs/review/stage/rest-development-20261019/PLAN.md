# 原固定开发人群的飞前静息校准诊断

2026-10-19。扩展23人校准因两名追加拟合人员的静息数据不合格而停止，原因与原失败保留。本单元只使用此前已固定的七名开发人员003、004、008、011、019、022、025，七人全部通过同一60秒静息资格；没有依据预测结果缩减或更换评分人员。

这是原5951窗、两折3/4名拟合人员的小规模输入诊断，与正在进行的19/20人拟合规模比较分开。原窗口、标签、掩码、历史绩效、选模和评分角色逐值不变；静息取段、严格飞前身份、每字段覆盖、静息中位数/四分位距、按拟合人员确定下限及保形变换，完全承接[静息合同](../rest-calibration-20261019/PLAN.md)，不缩短校准段、不放宽缺口或时间顺序条件。

只有当前合格拟合扩展单元完成并未同时通过表示与配对门，且本单元输入转换资格通过，才新增两个种子17的静息MulT（多模态变换器）拟合。共同读出选模、末端监督、架构与优化预算沿用小规模选模一致性单元；不加入历史辅助损失，不重训已有对照。原全部小规模强飞机、原MulT、局部保形MulT、连续时间变换器和预训练时序表示保留；完成中的大样本对照也作为额外实践门槛保留，但训练数据规模差异明示。

两折锁定后评分。验收仍为相对全部适用控制均方根误差至少改善2%，平均绝对误差不恶化2%，第一折至少2/3、第二折2/2人员改善；三种同人异记录替换平均恶化至少2%，真实配对不弱于置训练中心。通过才补相同静息输入的连续时间变换器两折，及已有共同统计读出；失败即停止该候选。没有通过前不扩种子或整矩阵。

静息校准是新增的、推理时可获得的无标签先验条件，必须向论文读者明确；输入处理增益也不单独称作新网络创新。单模型1小时、单元4小时与09:30取早，预算截断另列；所有旧结果、23人资格失败及当前扩展试验保留。
