# 飞行前静息校准的两折开发试验

静息校准没有改善本轮生理融合。原七名开发人员全部通过飞行前连续60秒静息输入核验；仅用早于首个建模窗口的静息中位数和四分位距校准生理幅度，其余窗口、历史绩效、划分和选模规则保持原协议。两个多模态注意力模型完成6453次优化更新，用时296.7秒。

下表展示静息输入候选的逐人等权均方根误差，支持“静息校准本身尚未带来可靠增益”的判断。共同读出是岭回归，专用头是带历史均值的残差预测头。

| 输出 | 第一折 | 第二折 |
|---|---:|---:|
| 静息校准共同读出 | 0.297926 | 0.204374 |
| 静息校准专用头 | 0.414597 | 0.221734 |
| 同一小队列的保形候选共同读出 | 0.292889 | 0.195396 |
| 持久性 | 0.459680 | 0.300840 |

两折均未通过性能门。打乱同人不同记录的生理配对后，误差平均反而降低0.62%和0.70%；置训练中心后的误差为0.288246和0.189172。当前结果不能支持模型利用了有益的生理动态；按预定规则没有启动条件传统模型训练。

独立核验已通过：2179个保护文件保持原哈希，243542条主预测、16796条干预预测及310项逐人指标完成校验，六个输出新鲜重放的最大差异为1.78×10⁻¹⁵。模型与输入资产见 `asset_manifest.json`，判据见 `performance_gates.json`、`pairing_gates.json`，验证见 `verification.json`。该单元是两折单种子的开发诊断，使用额外的飞行前无标签观测条件；不能与没有该观测条件的方法混作严格同输入比较。
