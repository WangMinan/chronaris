# 条件单元：用飞前静息校准保留跨窗口生理水平

2026-10-19。只读目录检查发现公开数据另有 `task-rest` 静息记录。当前保形输入仍用每个30秒窗口前2秒的中位数作为中心，因而可能把跨窗口缓慢变化的生理水平一起消掉；此前波形限幅修复只保住了窗内变化。这是待验证假设，不由目录存在直接推断静息记录一定早于飞行或一定有用。

## 先核验校准信息是否合法

只读取当前合格扩展单元23名人员、同一会话的三份静息生理数据源，不读其他人员。按原生时间筛选整段观测都早于该会话最早模型输入起点的静息记录；若多条满足，固定取时间最早的一条。取四通道共同覆盖终点之前的最后60秒，至少有完整60秒连续支持，各字段有限观测时间严格递增、首尾与内部缺口不超过0.25秒；原始值须有限，皮电仍按1000/电阻换算。不得用飞行后的静息段，也不按预测成绩选择校准段。任何人员没有合格校准，本单元不训练，保留缺失原因。

逐源前后散列核验；保存校准区间、与最早飞行输入的时间间隔、四通道中位数和四分位距。不得读取未来标签拟合校准参数。使用评分人员的飞前无标签静息观测属于本单元明确新增的部署条件，不冒充完全无校准的跨人设定；飞机对照仍获得全部原飞机与历史绩效输入。

## 固定输入变化

复用扩展单元18387窗和未限幅原生汇总。以窗内中心加回原生均值，恢复原始窗口水平，再减该人员飞前静息中位数；均值用asinh压缩，标准差和滤波均方根用log1p压缩，过零率保持。分母为该人员静息四分位距与当前折拟合人员非退化静息四分位距第10百分位及1e-6的最大值。下限按人员而不是重复窗口计算；不使用选模或评分人员来拟合共同下限。滤波动态继续沿用原窗内中心初始化，以免新增不同起始瞬态；只改变水平参照与尺度，不重新过滤、改掩码、改观测龄或目标。

原静息参数、原窗口中心、下限与转换后缓存全部绑定。除生理数值外所有数组必须与已通过的扩展缓存逐值一致；合格原生汇总的未来隔离证据继续适用，因为新静息参数在最早输入前已经可用。每人四个静息通道均须资格通过，不能用训练均值偷偷补缺失校准。

## 条件训练与控制

仅当正在运行的合格扩展单元完成复算且没有同时通过表示优势与配对门，才激活本单元训练；若前一候选已通过，优先验证其同规模必要参照，本方案保留为未启动。输入核验可以先在CPU完成。

激活时只新增两折种子17的静息校准MulT（多模态变换器）拟合，完全沿用前一单元模型、共同读出选模、末端监督、学习率、正则、批次、100轮上限/20轮最少/15轮耐心。前一单元同容量飞机、原处理MulT、局部保形MulT检查点及全部强小规模参照直接作为冻结控制，不再重复训练它们。该比较检验明确额外校准条件下的输入增量，不把输入条件变化单独包装成新网络创新。

两折新模型与读出全部锁定后才评分；逐人等权均方根误差相对全部适用控制至少下降2%，平均绝对误差不恶化超过2%，第一折至少2/3、第二折2/2人员改善；固定三种同人异记录替换平均每折恶化至少2%，真实配对不弱于置训练中心。两门通过后才补相同校准输入的连续时间变换器ContiFormer两折比较，统计读出同步保留。否则停止该候选，不扩大种子或完整矩阵。

单模型最多1小时、单元最多4小时，与北京时间09:30取较早截止。预算截断另列未完成；源身份、时间顺序、非有限或历史隔离失败停止并保存现场。原局部归一化结果和全部失败保留，最终导师要求仍需完整公平比较和独立确认。
