## v3.2.3 历史结论

`main` 已通过拉取请求 [#3](https://github.com/WangMinan/chronaris/pull/3) 集成连续对齐与语义融合研究基线。v3.2.3 受控仿真全部完成，六项机制门通过四项；未来信息隔离与安全单流旁路失败，公开数据与鼎新外层评价保持关闭。

当前证据支持部分时间机制和仿真任务收益，尚未建立严格因果融合及真实任务整体优势。未来依赖已定位到语义事件分数的全窗归一化，后续模型修订需要单独冻结评价范围。[完整实验复核](review/stage/thesis-mainline/frozen-simulation-review-2026-09-04.md)保留有利和不利结果。
