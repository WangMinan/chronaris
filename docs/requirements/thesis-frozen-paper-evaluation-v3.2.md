# 论文级冻结实验执行清单 v3.2

日期：2026-09-03。上位合同为[论文主线连续对齐与语义融合评价协议 v3](thesis-continuous-semantic-fusion-evaluation-v3.md)及其[v3.2 修订](thesis-continuous-semantic-fusion-evaluation-v3.2.md)。

## 1. 冻结模型与预算

训练内 144 个单元完成后，冻结“同时加入时移与语义配对目标”的 Chronaris 候选。机器可读配置见 [thesis-frozen-models-v3.2.json](thesis-frozen-models-v3.2.json)。

- 随机种子：`17/29/43`；表示合同：`[样本,96,64]`。
- 公共预训练最大 50 epoch、patience 8、学习率 `3e-4`、权重衰减 `1e-4`、梯度裁剪 1.0。
- Chronaris 使用安全滞后感知融合、单步 Euler、可学习事件语义查询、显式时移权重 0.1 和事件配对权重 0.1。
- 六方法统一使用训练折归一化、相同下游消费者和 CUDA；设备不可用时直接失败并保留恢复点。
- 仿真与现有固定数据评价继续复用成熟的预训练、表示、消费者、压力和时间机制入口，不建立第二套训练框架。

## 2. 数据与划分

- 受控仿真复用 `2026-07-10_aviation-simulation-formal` 及已经审计的固定压力场景；G1 只用于训练和选择，G2 在全部 checkpoint 与表示完成后一次打开。
- CogPilot 难度使用 30 秒原生时间窗口；每个“受试者×难度”等量保留一个预先确定窗口。事件响应使用 12 秒窗口，每个“受试者×飞行运行”保留时间顺序中点事件。
- CLARE 使用 10 秒原生时间窗口；每个“受试者×实验”在不读取标签的前提下选择时间中点附近首个双流有效窗口。
- CogPilot 与 CLARE 均使用受试者分组 outer 5 折；每个 outer-train 内按 seed 建立受试者分组 validation。
- 鼎新复用三个留一视图折和两个留一架次折、90 个完整未来窗口与既有嵌套目标；称为协议冻结后的分组确认，不声称盲测。

各运行在打开外层数据前写入 Git 提交、源码哈希、runner 哈希、样本 lineage 哈希、fold、消费者和设备记录。已完成外层结果不得用于修改上述配置。

## 3. 执行顺序与停止条件

1. 运行仿真六方法 clean、压力、时间机制和四项结构消融。
2. 先审计连续演化、运动学约束、未来信息隔离和安全单流旁路硬门。
3. 硬门通过后，依次运行 CogPilot、CLARE 和鼎新外层确认。
4. 运行无显式时移、无可学习事件语义、错误配对、错误时移、未来信息安慰剂、完整缺失模态以及运行时和预选案例评价。
5. 汇总折与随机种子明细、中位数、四分位距、最差折和以受试者、架次或潜在轨迹为单位的配对 bootstrap 区间。

若仿真硬门失败，不打开公开数据或鼎新外层指标，并按 v3.2 已用尽改进轮次的规则请求人工处理。应用增量不足不构成阻塞。
