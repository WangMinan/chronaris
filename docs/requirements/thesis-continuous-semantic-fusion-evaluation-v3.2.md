# 论文主线连续对齐与语义融合评价协议 v3.2

日期：2026-09-02。适用分支：`research/thesis-continuous-semantic-fusion-202609`。

本协议是 [评价协议 v3.1](thesis-continuous-semantic-fusion-evaluation-v3.1.md) 后唯一剩余的单原因训练内改进。v3.1 完成 144/144 个训练内单元，仿真五分类时移门和事件—响应配对门通过；但公共数据的物理项达到 `10^16` 至 `10^17`，违反可信训练尺度要求，因此不得进入候选排序或外层实验。

## 1. 单原因修复

异常根因是旧物理审计把高采样率脑电或生理重构的二阶时间导数作为物理一致性项。在 CogPilot 和 CLARE 的毫秒级采样间隔下，该项被时间差平方放大；它也不属于论文已确认的“当前有效运动学字段”口径。

v3.2 将 Chronaris 物理训练目标严格限定为航电字段能够支持的平移、垂向和旋转运动学残差：

- 生理平滑与血氧变化不再作为论文物理项，统一记录为 `outside_motion_kinematics_contract`；
- 存在有效航电速度、加速度、高度、垂向速度、姿态或角速度组合时，只计算对应运动学残差；
- 数据不含对应运动学字段时记录 `unavailable`，不得填零后宣称物理约束成立；
- 模型、四候选、新目标权重、Euler 方案、数据、分组、窗口、seed、batch、消费者和外层隔离均不变。

## 2. 重跑与门禁

v3.1 的 144 个单元保留并统一标记 `superseded_due_to_physics_objective_scale_defect`。v3.2 从新产物根在同一冻结 commit 下完整重跑仿真、鼎新、CogPilot 和 CLARE 的 144 个训练内单元。验收额外要求：

- 所有公共自监督和加权机制损失有限，且不再由超出运动学合同的生理二阶导主导；
- 仿真显式时移与事件配对门继续通过；
- 仿真或鼎新具有有效运动学字段的样本形成非零物理计数；CLARE 无航电运动学字段时物理项必须明确不可用；
- source SHA-256、runner SHA-256、commit 和协议版本全程一致，外层结果继续关闭。

本版本用尽原计划允许的训练内改进轮次。若 v3.2 后协议或机制硬门仍失败，停止外层实验并请求人工处理；应用指标不足仍不构成阻塞。
