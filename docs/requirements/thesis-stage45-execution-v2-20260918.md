# 阶段 4.5 全流程执行修订

2026-09-18。用户明确授权修订执行容差，并要求加速整个阶段 4.5。本修订覆盖预训练、完整验证、任务头预热、联合微调、表示导出、快照诊断及后续开发复核；保持候选、标签、数据角色、选模目标、更新预算、微批量 4、有效批量 16 和单精度不变。研究效果门及阶段 5 的关闭状态不变。

## 执行验收标准

新标准在新增资格测试前固定，以同时约束整体漂移、局部异常和实际任务影响。原纯绝对容差失败记录保留，新判定使用 `stage45_execution_v2` 标识及独立凭证，不改写旧记录。

下表规定每类对象的验收要求。尺度为普通执行参考张量的均方根，下限为 0.001；整数、有效掩码、角色、采样顺序和随机状态保持精确。

| 对象 | 新执行判据 |
| --- | --- |
| 表示张量 | 相对均方根误差不超过 0.0001，最大绝对误差除以上述尺度不超过 0.01 |
| 表示局部差异 | 记录超过 `0.00001 + 0.0001 × 参考绝对值` 的元素比例，作为定位指标，不单独作为通过条件 |
| 参数、梯度、优化器及损失 | 绝对容差 0.00001、相对容差 0.0001；不接受非有限值、形状或类型改变 |
| 固定下游模型 | 分类决定不变；回归预测差的均方根不超过 `0.00001 + 0.0001 × 参考预测均方根`（尺度下限 0.001）；逐任务结果及选模判断另行记录 |
| 同执行方式恢复 | 模型、优化器、随机状态、数据游标和可重放训练记录逐值一致 |

相对均方根上限约束分散漂移，局部上限防止整体平均掩盖异常，固定下游检查约束可见任务影响。不能单独以任一项通过放行；新阈值不是根据某份超差文件的最大值决定。用原生开发样本、不同配方和新增续训检验其适用性，测试失败时保留失败并定位原因。

归档校准曾试用 0.1% 的超差元素比例门。旧 CogPilot 机制短程的一份输出整体相对均方根差仅约 0.0000139，却因超差比例约 0.179% 被拦截；该比例依赖张量维数和近零元素，不能独立表达任务影响。因此在新增资格实跑前取消这一附加门，保留相对均方根、局部最大误差和下游影响三项验收，不根据最大观察值调高相应上限。

回归预测同样采用绝对与相对误差共同约束，避免近零事件响应被纯相对误差放大。归档中 CogPilot 普通参考的固定时序下游最大预测差约 0.0000177、相对均方根差约 0.000111；该校准记录保留，最终混合标准与表示尺度标准一同冻结，再进入新增实跑。

生产批量的新增测试曾在首次联合更新出现一个参数差 0.0000557，超出本合同，原失败保留。其对应梯度约为 0.0000000273 与 0.00000000212，差异经首次 Adam 更新放大；采用上述首次联合更新普通递推的执行调整后，需要重新验收，不以提高参数容差消除此失败。

## 覆盖与恢复

通过资格的 Chronaris 连续递推图执行贯穿训练、验证、导出及后续复核，微调只在第一次联合更新保留普通递推，随后联合更新使用图执行；头预热、验证和导出继续使用图执行。该例外处理 Adam 优化器初次归一化对近零梯度的敏感性，不修改学习率、优化器、研究预算或上述容差。对照模型继续使用已有高效实现；逐阶段记录真实墙钟，不把局部加速当作所有环节相同倍数。

从已停止的 CogPilot 机制组合第 75 次恢复，保留九个完整单元。源码、配置和凭证改变后使用新运行根；检查点迁移保持训练张量、优化器、随机状态及游标不变，记录旧新源码与执行配置。历史图执行失败与已完成研究结果保留原始来源。

训练在完整验证前保存明确标记的待验证状态，恢复时先补做验证，再进入下一次训练。该改动需覆盖预训练与联合微调的真实中断检查，避免重复更新、跳过选模或改变随机序列。

本文件规定实施与验收要求，不表示测试已经通过或生产实验已经恢复。实际结果见[运行复核](../review/stage/thesis-v4/stage45-runtime-assessment-20260918/README.md)。
