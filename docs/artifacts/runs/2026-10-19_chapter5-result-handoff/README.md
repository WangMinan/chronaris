## 3. 最新比较的可引用摘要

**保形融合候选局部超过本次预训练模型适配，但仍未稳定超过同容量飞机模型。** 下表来自四模型目录的完整汇总，使用同一扩展训练人群和评分人员，指标为逐人等权均方根误差，越小越好。前三项为64维共同表示接岭回归，后两项为原生任务预测；训练预算和接口差异同时披露。

| 方法 | 评价方式 | 第一开发划分 | 第二开发划分 |
|---|---|---:|---:|
| 同容量飞机模型 | 64维共同读出 | 0.231049 | 0.165837 |
| 原处理MulT（多模态注意力模型） | 64维共同读出 | 0.234923 | 0.174795 |
| 保形生理融合候选 | 64维共同读出 | 0.235035 | 0.167121 |
| Chronos-2（预训练时序模型）飞机输入 | 原生监督适配 | 0.265171 | 0.189385 |
| Chronos-2联合输入 | 原生监督适配 | 0.264045 | 0.190376 |

保形候选相对本次Chronos-2联合适配的误差低约10.99%和12.22%；相对同容量飞机模型则高约1.72%和0.77%。Chronos-2联合输入相对自身飞机输入仅在第一划分改善约0.425%，第二划分退化约0.523%。这些结果支持当前协议内的局部比较与停止追加投入决定，不支持稳定生理增量或全面领先。
