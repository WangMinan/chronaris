# 连续演化数值方案训练内验证选择

本实验只使用仿真训练集拟合，并以仿真训练内验证（validation）的连续对齐损失选择数值方案；预留样本和应用任务结果均未打开。下表同时检查梯度有限性与相对单步 Euler 不超过 2 倍的运行时间门。

| 数值方案 | 训练内对齐损失 | 训练用时（秒） | 梯度有限 | 运行时间门 |
| --- | ---: | ---: | --- | --- |
| 单步 Euler | 0.278590 | 21.54 | 是 | 通过 |
| 最大 0.5 秒 Euler 子步 | 0.282455 | 24.70 | 是 | 通过 |
| 四阶 Runge-Kutta | 0.282015 | 149.02 | 是 | 未通过 |

冻结选择为 **单步 Euler**。该选择只用于后续训练内候选，不根据公开数据外层折或鼎新确认结果重新选择。
