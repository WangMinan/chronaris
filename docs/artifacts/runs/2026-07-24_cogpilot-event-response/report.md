# CogPilot 事件→生理响应（公开跨模态任务，诚实负向）

状态：completed。日期：2026-07-24。

## 目的

构建“真正需要双流”的公开任务：飞机滚转事件（trigger 在飞机流）触发其后 EDA 变化（response 在生理流）。预测 response 需 trigger（vehicle）+ 基线（physiology）。vehicle_only 有 trigger 无生理基线、physiology_only 有基线无 trigger、融合有两者。

## 设置

20 参与者，每 run 取滚转速率 top-3 事件，共 637 事件（train=469/test=168，LOSO）。输入为事件前 12s 上下文（PPG/EDA/呼吸/HR + 飞机 8 通道，10Hz）；目标为事件后 8s 的 EDA 变化（kOhms，2–98 百分位裁剪）。8 epoch、seed 17，Ridge 消费者。

## 结果

| 方法 | R² | MAE | skill vs 均值 |
| --- | --- | --- | --- |
| chronaris_safe_lag | 0.004 | 17.79 | −0.038 |
| chronaris_multiscale | 0.016 | 17.53 | −0.022 |
| vehicle_only | 0.069 | 17.22 | −0.005 |
| physiology_only | −0.004 | 17.46 | −0.019 |

## 判断

**诚实负向**：六方法（含融合）的预测技能均≈0（skill 低于预测训练均值）。事件后 EDA 变化从事件前上下文表示**不可预测**——目标受受试者特异性 EDA 基线与噪声主导。融合未超单流。这是第 5 种真实任务构造上融合未超最佳单流。

## 综合结论（跨全部真实任务）

已穷尽测试：鼎新未来机动（车辆主导）、鼎新未来生理（近持久）、CogPilot 难度±ECG-HR（飞机主导）、合成时延恢复（异构无事件结构）、CogPilot 事件→EDA 响应（目标不可预测）。**融合未在任一真实任务上稳健超最佳单流**。根因：公共重构预训练偏航电/飞机强信号（审计 Q10），使表示车辆主导，无法捕获跨模态增量。唯一融合胜出在仿真机制任务（事件锁定 G2，旧 Chronaris 已居首）。

## 下一步（真正可能让融合超单流的路径）

不再在车辆主导/不可预测任务上追超单流。需**重构预训练目标**：用跨流对比/事件-响应配对/正确滞后优于错误滞后（评价协议 v2 §6.3）作为预训练目标，使表示编码跨模态结构而非航电重构；再在事件锁定的真实跨模态任务上评价。或接受仿真机制任务（事件锁定）为融合胜出的主证据。
