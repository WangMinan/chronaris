# 鼎新五折冻结表示下游消费者工程冒烟报告

## 结论

- 状态：完成；验收 15/15 通过。
- 五个固定外层折、六种表示方法均使用同一线性模型和 MiniROCKET 配置，形成 30 个方法—折组合、60 个消费者组件。
- 机动强度分类、生理响应回归和高生理响应识别共生成 1680 条 smoke-only 指标；1680 条可计算，0 条按相关系数未定义等原因结构化保留。
- 方向归一的双流增益接口生成 1120 条记录；消费者首次拟合累计 144.34 秒，第二遍恢复 60/60。
- 当前标签阈值仍来自 outer-train，只允许工程冒烟；本报告不比较或选择模型，不更新论文确认指标。
