# 完整开发比较的执行版本迁移与恢复

本轮从已保留的第 200 次更新恢复实验，并将经过真实更新与恢复对照的 CUDA Graph（显卡运算图重放）用于 CogPilot 虚拟飞行数据上的 Chronaris 连续融合模型。CLARE 生理数据上的九个完成模型单元、十五条表示路线继续复用，鼎新和其他方法沿原执行设置，正式确认继续关闭。

迁移在新目录进行，原目录与原检查点保持保留。迁移检查点只调整执行配置、对应的协议散列和来源记录，不改动模型、任务头、优化器、随机状态、采样位置及累计训练耗时；第 200 次以前约 24.55 小时计算继续保留。性能试验中的诊断更新不作为生产恢复起点，停止程序失误期间的六次未落盘更新将正常重算。

计算模块的源码须与保留版本一致；入口只允许已复核的执行开关改动。九个完成单元保持原逐路线结果、比较键及下游文件来源，新回执记录数据合同的对应关系和零额外训练更新。最终成本汇总合并历次成功、失败和主动终止的尝试记录，性能试验及迁移开销单独留据。

当前已完成检查点迁移的只读验证及聚焦测试；完整 CUDA（统一计算设备架构）回归、真实迁移与后台恢复尚待完成。验收入口见[复核记录](../../../review/stage/thesis-v4/stage4-execution-migration-20260913/README.md)。
