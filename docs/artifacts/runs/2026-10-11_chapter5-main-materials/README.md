# 第五章主模型数据与独立绘图包

本包提供已完成主模型训练的内部验证数据、训练记录及成本，服务于论文侧本地素材整理。数据覆盖 279 个单元、477 条表示路线，全部方法与种子保留；这是内部验证材料，正式留出结果需在后续核心模型冻结和外层评价后另行导出。本包不包含论文正文或排版表格。

实际交付含 807 组下游结果、1,443,702 条逐窗口/字段预测、5,406 条分组指标、181,899 条训练历史记录，以及 22 组指标/成本图和三个单元的训练曲线示例，均提供位图与矢量图。完整字段说明见 [data_dictionary.md](data_dictionary.md)，独立重绘检查见 [validation.json](validation.json)。

## 本地运行

将整个目录复制到本地任意位置，进入该目录后运行。需要 Python 3.11 以上和 Matplotlib 绘图库，不需要本仓库、模型、数据库、网络服务或显卡：

```bash
python -m pip install -r requirements.txt
python verify.py
python plot.py
python plot_training.py --unit 0
python plot_training.py --unit 135
python plot_training.py --unit 255
```

默认读取脚本旁的 `data/` 与 `style.json`，生成 `figures/` 下的高清 PNG 位图和 SVG 可编辑矢量图。默认分辨率为每英寸 320 点，SVG 保留文字；本地系统需安装样式文件所列的一种中文字体，或改为本地可用字体。脚本从其他工作目录调用也可运行。

训练曲线通过 `--unit` 选择冻结矩阵单元，可在 `data/training.csv` 查找方法、划分和种子。示例为三个数据域首个连续融合单元。脚本读取已记录的验证选择损失或适配训练损失，逐点绘制，不重新计算损失；零训练更新或没有训练历史的路线不生成虚构曲线。曲线输入固定为 `data/training_curves.csv`，使用同一 `style.json`，输出为 `figures/training_unit_<单元索引>.png` 和同名 SVG。

## 修改数据与图片

`style.json` 集中控制中文名称、字体、字号、配色、面板尺寸、分辨率和脚注。可直接修改样式重绘。原始导出数据保持不变；数值修订请复制到 `revisions/<日期>/data/`，附文件、行键、原值、新值和修改理由，再显式指定版本：

```bash
python plot.py --data-dir revisions/2026-10-18/data --style style.json --output-dir revised_figures
```

绘图入口只渲染预先导出的数值，不训练、不拟合、不重算实验指标或误差条。修改逐设置数据后，如需同步汇总，请在单独统计步骤生成新的 `summary.csv`，不要只改图上显示数字。`verify.py` 检查原始快照散列和汇总关系，有记录的修订不覆盖原始证据清单。

## 文件含义

- `data/setting_metrics.csv`：方法、路线、任务、下游、折和种子的内部验证指标，含单位口径和有效分组数。
- `data/group_metrics.csv`：逐受试者或鼎新记录、逐任务/字段指标，含原生误差、训练尺度、有效数、尾部误差和混淆计数等原记录。
- `data/predictions/*.csv.gz`：按单元、表示路线及下游分开的全部逐窗口逐字段预测，含真实目标、有效性、概率和无观测标志。普通解压工具可还原为 UTF-8 CSV 后修改；无需服务器或模型。
- `data/vehicle_predictions/*.csv`：鼎新共享航电时段多视图聚合后的机动目标与预测，保留原聚合记录。
- `data/training.csv`：模型来源、实际维数、监督条件、更新数和外部预训练信息。
- `data/training_curves.csv`：原训练记录逐行导出，包含训练损失与可用的验证信息；不同方法列不完全相同，空值表示该类记录不适用。
- `data/cost_units.csv`：当前与继承的单元成本、分阶段计时；`data/attempt_costs.csv` 保留各来源运行根的成功和失败尝试，不能将成功尝试再加到单元成本造成重复。
- `data/summary.csv`：绘图使用的均值、描述性标准差、最小/最大值、完整与有效设置数。
- `data/cost_summary.csv`：按数据域与方法导出的单元平均小时、总小时和描述性标准差。
- `evidence.json`：来源散列及随包数据散列；服务器路径只用于追溯，绘图和随包验证均不访问这些路径。
- `figures/figure_inputs.json`：每张图的稳定文件标识、输入文件、脚本和样式对应关系。

## 指标与统计口径

分类使用宏平均 F1 分数，取值越高越好；回归使用均方根误差，取值越低越好。CLARE 生理负荷回归单位为评分点；CogPilot 虚拟飞行数据的离线事件条件响应回归单位为微西门子。鼎新主汇总沿用冻结下游的训练尺度归一化误差，图中明确标注；逐字段原生误差与尺度保留在 `group_metrics.csv`，不能把不同物理单位的误差直接相加。

每个设置先按字段和受试者依冻结规则汇总，再对完整折与种子设置作等权描述。公开方法通常为五折三种子，共 15 个设置；鼎新为三种子。图中误差线是这些设置间的总体标准差，不是置信区间，折和种子不是新增独立受试者。缺失指标保留空值、有效数和原状态，不用零替换。

自监督、任务引导、外部冻结与适配路线分别出图，线性与 MiniROCKET 时序卷积特征补充分别出图。近期模型只有窗口末端表示的路线不提供虚构时序补充结果。训练成本来自完成收据，失败与未完整计时的尝试另附原始记录，不声称所有历史消耗都能精确复原。
