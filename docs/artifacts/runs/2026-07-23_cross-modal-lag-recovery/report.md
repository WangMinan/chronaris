# 跨模态时延恢复诊断（任务确需双流，但当前 checkpoint 未编码时延）

状态：completed（诊断性实验）。日期：2026-07-23。

## 目的

寻找“真正需要跨模态增量”的任务：恢复生理流相对飞机流的时延 τ。单流结构上无法完成（vehicle_only 看不到生理，physiology_only 无飞机参考），因此这是融合本应占优的任务。用波次 A 的仿真 checkpoint（已含公共 lag_discrimination 预训练目标）做诊断。

## 设置

- 数据：G1 仿真 24 条留出轨迹，对每条构造生理信号延迟 τ ∈ {−5,−2,0,2,5} 秒的副本（值域延迟，时间戳保持在合法上下文内），共 120 样本。
- 评价：冻结 64 维窗口表示 → Ridge 预测 τ；按轨迹留一（偶数轨迹训练、奇数测试）。指标：τ 的 MAE（秒）、5 类最近类准确率（随机 0.20）。

## 结果

| 方法 | τ MAE (s) | 类准确率 |
| --- | --- | --- |
| chronaris_safe_lag | 6.628 | 0.233 |
| chronaris_multiscale | 4.480 | 0.217 |
| vehicle_only | 2.800 | 0.200 |

（physiology_only checkpoint 未保存，跳过。）

## 判断

- **单流确在随机水平**：vehicle_only 的表示对生理延迟不变，故对 5 个 τ 副本输出同一向量，Ridge 只能预测 τ 均值；MAE 2.8s 恰为 |τ| 的均值（(5+2+0+2+5)/5），类准确率 0.20=随机。**证明该任务结构上需要双流**。
- **当前融合 checkpoint 未编码时延**：safe_lag/multiscale 的 Ridge 探针 MAE 反而高于“预测均值”（6.6/4.5 > 2.8），即泛化差于常数——波次 A checkpoint 仅 15 epoch、在干净数据上训练，其 lag_discrimination 预训练只做二元“飞机是否被时移”判别，未学习生理时延幅度的回归目标，故表示未编码可线性恢复的时延。
- **不是融合胜出，但定位了胜出条件**：要在该跨模态任务上让 Chronaris 超过单流，需用**显式时延恢复目标训练编码器**（即评价协议 v2 的“正确滞后优于错误滞后 / event-conditioned 对比 / 滞后区间识别”，对应已收口仿真机制线曾显示 Chronaris 在时钟偏移/响应时延恢复上居首的设置），而非仅靠公共 lag_discrimination 预训练。

## 下一步

按评价协议 v2 §6.3，把 `lag_aware_alignment_loss` 与显式时延恢复回归头接入训练（在含已知时延的仿真场景上训练编码器，而非干净 G1），再在该任务上评价；这是让融合在“真正需要跨模态”的任务上稳健超单流的最直接路径。
