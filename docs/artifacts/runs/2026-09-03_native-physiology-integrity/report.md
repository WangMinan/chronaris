# 原生生理预处理完整性修复

## 结论

CogPilot 与 CLARE 公开数据的生理输入已改为严格观测窗内的原生信号。CogPilot 皮电电阻中的非物理值不再进入模型或响应真值，非因果派生心率已由原始心电图（ECG）替代。三类冻结任务保持原样本选择和受试者范围，6/6 项验收通过，公开外层结果仍未打开。

## 皮电修复

CogPilot 的有效正电阻按 `1000 / 电阻千欧` 换算为皮肤电导微西门子，非正电阻结构化标为缺失。事件响应固定为事件后 8 秒皮肤电导中位数减事件前 2 秒中位数。

修复前，225 个冻结事件的电阻均值差范围为 −25,347 至 4,876，两个窗口包含非正电阻，最坏后窗包含 6,207 个非物理点。修复后 225/225 个目标均为有限值，范围为 −1.231 至 1.183 微西门子。

## 心电图修复

CogPilot 与 CLARE 不再从观测窗前后额外读取心电图并以全窗阈值派生心率，而是分别使用 `physiology.ecg` 与 `peripheral.ecg` 保存原始信号。所有实际时间戳均位于 30 秒、12 秒或 10 秒观测窗内。

## 任务与缺失边界

- CogPilot 飞行难度：77 个样本、20 名受试者。4 个样本缺少完整生理流，均来自同一受试者；这些样本保留用于检验航电强模态任务下的安全退化，不用于声称双流增量。
- CogPilot 事件—响应：225 个样本、20 名受试者，全部样本具有双流观测。
- CLARE 认知负荷：60 个样本、16 名受试者，全部样本具有双流观测。

两个数据结构定义分别升级为 `cogpilot_native.v4` 与 `clare_native.v4`，预处理版本进入样本来源哈希。三个任务的来源链（lineage）哈希均相对 v3.2.1 改变，因此旧磁盘缓存不会被新协议复用。

修复前已产生的公开数据训练内应用指标保留原数字和文件哈希，并在 `superseded_evidence.json` 中标记为被原生生理预处理缺陷取代。v3.2 的候选选择由两项机制门唯一确定，因此模型选择结论不受这些应用指标影响。
