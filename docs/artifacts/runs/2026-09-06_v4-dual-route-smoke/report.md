# v4 公共目标与双路线更新闭环

Chronaris（连续对齐与语义融合模型）已完成同初始化的双路线 CUDA（统一计算设备架构）工程冒烟。自监督预训练执行十次完整更新，用时 94.28 秒；任务引导继续执行 50 次任务头预热和十次联合更新，用时 266.71 秒。实际批量为 4、有效批量为 32，任务引导共处理 480 个实际批次、1,920 次样本抽取。峰值张量显存约 162 MiB。

两条路线在训练后均通过历史信息隔离检查。未来值扰动的历史表示变化均为零；改变未来缺失模式后，自监督与任务引导最大差分别为 `4.77e-7`、`4.17e-7`，低于 `1e-6`。检查点和完整配置见 [summary.json](summary.json)。

本次训练使用新的公共目标合同：双流重构先分别按模态计算再等权平均，单流只承担自身模态重构，跨流时移损失仅对两模态有历史观测的样本生效。训练、验证和确认共用同一前向逻辑，验证按全折模态有效计数汇总，避免批次和字段数改变权重。机制目标在自监督前 50 更新关闭；任务头预热只更新任务头，联合阶段保留 0.2 倍公共自监督损失与配置中的机制目标。

任务引导初始化校验源码、数据、归一化、架构、随机种子及自监督来源。检查点分别保存编码器是否经过标签反向传播、选型是否使用验证标签，以及阶段计数和数据游标。导出只载入编码器权重，并复用冻结归一化与真实有效掩码。开发目标入口只允许同初始化的训练和验证样本，继续拒绝监督检查点或确认目标进入自监督来源。

公共目标聚焦测试 20 项通过；双阶段中断恢复与通用任务头在 CPU（中央处理器）和 CUDA 上共五项通过；开发目标访问检查两项通过。本次仍使用历史状态空间观测的少量新起点窗口，仅用于工程闭环。内部任务头损失保留在摘要中，不作为固定消费者成绩或候选选型证据。真实公开数据与鼎新神经网络冒烟、新数据训练诊断和正式确认尚待后续完成。
