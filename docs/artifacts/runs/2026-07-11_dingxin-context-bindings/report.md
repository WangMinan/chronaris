# 鼎新原始双流上下文与目标绑定报告

## 结论

- 状态：完成；验收 12/12 通过。
- 96 个标签上下文中，93 个拥有完整 30 秒原始输入；3 个末端上下文因 snapshot 不足 185 秒而不可用于模型输入。
- 机动分类在五折中绑定 93 个唯一可用上下文；生理响应同时要求完整未来 5 秒，绑定 90 个唯一可用上下文。
- 公共输入 schema 为 12 个生理字段和 955 个航电字段；20 个机动标签源字段在原始映射层即被删除。
- 允许字段稀疏缓存包含 10,255,756 个 float32 值、数组净大小 78.6 MB；完整审计耗时 12.34 秒，峰值内存 767.0 MB。
- 每个可用上下文均通过懒加载从 snapshot 切片，最大相对时间严格小于 30 秒；没有生成 GB 级稠密上下文副本。
- 10 个目标 archive 与阈值文件全部重新校验 SHA-256；外层折 train/test group 无交集。
- 本 run 只闭合输入、目标和外层折 lineage，不训练模型或生成任务指标。

## 存储与训练约束

后续训练按小批次调用懒加载索引；不得把 93 个高频航电上下文一次性稠密化，也不得从目标区间回填输入末端。归一化器和编码器只在当前 fold 的 train context 上拟合。
