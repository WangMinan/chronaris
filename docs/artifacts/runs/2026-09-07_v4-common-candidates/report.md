# 公共缺失增强与多时域预测组件

固定缺失混合与实际秒数预测已接入共享预训练、验证、检查点和任务引导适配接口。两项变化均可供 Chronaris 与四种可训练基线单独选择；本次验证属于工程检查，尚不产生候选收益或正式确认结论。

## 冻结的实现口径

扩大缺失覆盖按窗口独立抽取：40% 清洁、25% 随机缺失、25% 连续缺失、两种整模态缺失各 5%。随机分支每窗口抽取一个 5%–30% 概率，再独立删除两流原生采样点；连续分支分别抽取两流窗口长度 10%–80% 的区间。仅选中的缺失因素生效，不叠加时间抖动或时钟偏移；时间辨别仍由独立时移目标承担。清洁分支逐值保留原始有效采样点及时间戳。

实际秒数预测读取查询时刻后 0.5、2、5 秒处各字段最近一次观测，教师值使用干净训练角色数据。超过原输入窗口末端的目标全部无效，不读取相邻上下文。模型输入仍为原查询处的因果表示；只有训练目标读取后续观测。预测损失对可用的“输入模态—预测时域”分别取有效元素均值，再等权汇总，避免高维模态及短时域的较多目标占主导。默认空时域配置保留原下一参考点目标。

两项配置、实际增强条件、删除概率及时间扰动参数进入来源记录。原始实际批量、梯度累积及配对负例集合不改变。任务引导阶段从自监督检查点继承公共预测头及增强策略，最终表示仍为 64 维，训练头不进入消费者输入。

## 验证与发现

一万个确定性增强计划检查了预定概率、10/12/30 秒区间边界以及单模态删除；原生混合长度样本逐查询核对实际秒数目标。额外检查覆盖模态与时域等权梯度、部分标签掩码、预训练检查点恢复、微调继承及导出。最终测试与源码指纹见同目录 `validation_summary.json`。

第一次恢复检查为 14 项通过、1 项失败。权重、优化器、随机状态、数据游标及增强记录的连续执行与中断重放均相同；失败来自旧断言要求每个参数的 Adam 更新次数始终等于全局更新数。清洁批次没有被遮挡的重构目标，因此重构头可以没有梯度。断言现检查全局实际更新数、参数步数合法范围及连续/恢复状态一致性，保留默认分布的原有严格检查。修正后的公共候选微调闭环为 1 项通过，用时 8.59 秒。

仍待实现单流保真与质量门，再冻结整个候选源码开展扩展至 512 条训练轨迹后的单因素比较。旧 256 条轨迹诊断及其负面结果保持原样。
