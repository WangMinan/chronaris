# 鼎新三随机种子五折锁定下游评估

状态：completed；验收 8/8。
完成 90 个方法—折—随机种子 consumer 和 5040 条指标。
主协议只以三个留一视图折汇总均值、标准差、范围和最差折；不报告窗口级显著性。

## 主要结果

- 高生理响应识别是 Chronaris 在鼎新弱监督任务上的主要正向证据。MiniRocket 宏平均 AUPRC 为 0.8839，高于航电单流 0.8745、MulT 0.8698 和 ContiFormer 0.8593；三 seed 平均最差视图折为 0.6516，也是六方法最高。Chronaris 相对最佳单流的九个主折—种子平均增益为 0.0094。
- 机动强度弱监督分类主要由航电信号驱动。ContiFormer/Naive/MulT/Chronaris 的 MiniRocket Macro-F1 分别为 0.9409/0.9407/0.8781/0.7394；Chronaris 仅略高于生理单流 0.7327，相对最佳单流的平均增益为 -0.1904。该任务不支持 Chronaris 优势。
- 未来生理响应回归中，MulT 以 RMSE 0.2912 居首，航电单流为 0.3028、ContiFormer 为 0.3114、Chronaris 为 0.3365。Chronaris 虽显著优于生理单流 0.8011，但低于最佳深度基线，相对最佳单流的方向归一平均增益为 -0.0337。

## 结论边界

本 run 支持“Chronaris 表示在高生理响应弱监督识别上提供了稳定且超过最佳单流的小幅增益”。它不支持 Chronaris 在鼎新三项任务全面领先；机动强度分类与连续响应回归应当如实报告为基线领先。该结果来自现有两架次、三视图弱监督数据，不等同于人工工作负荷或专家机动科目真值。
