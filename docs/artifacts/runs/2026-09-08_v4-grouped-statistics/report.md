## 统计实现与缺失覆盖

宏平均 F1 先按档案累积混淆矩阵，回归先累积平方误差与窗口数，抽样时按档案重复次数汇总，再计算指标。片段和边界 F1 沿用现有逐窗口平均定义，档案内保留全部窗口；最后对三个训练种子的指标等权平均，避免把种子当作额外数据档案。

检测延迟沿用现有定义：真实边界之后存在预测边界时计算等待时间。因此接口同时报告真实边界数、可匹配边界数及缺少支持的抽样次数。没有匹配支持时返回区间不可用，不删除抽样或把延迟记为零；该指标需要与边界 F1 共同解读。

公开统计要求同一受试者拥有相同的比较方法和训练种子，拒绝重复受试者记录、跨折重复、缺失配对及非有限指标。字段指标须先按既定任务合同归并到受试者；任务有效窗口的数量不作为受试者权重。鼎新数据域不会进入这一公开统计接口。

## 实跑与复现

48 项比较的 96 个方法点估计与原始归档表一致，最大差约 `1.1e-16`，见[点估计检查](point_audit.json)。逐值测试还覆盖不等长参数档案、重复抽取档案、缺失延迟支持，以及复制相同训练种子后区间不能缩窄；完整 CPU 回归为 570 项通过、30 项跳过。

单项分类重采样的三次 CPU 对照中，逐次展开窗口的中位耗时为 2.245 秒，档案计数汇总为 0.00434 秒，区间差不超过 `1e-12`，见[性能记录](benchmark.json)。这项测量仅覆盖统计阶段。完整验证见[验收摘要](validation_summary.json)。
