# 功能与接口验收表

**功能测试按使用者的完整处理路径组织，并单独覆盖输入错误和任务恢复。** 下表给出测试条件、预期行为及对应证据，最终实际结果以验收报告和机器记录为准。构造边界用例验证接口规则，实测观测及冻结权重验证完整链路，两类证据各有职责。

| 功能 | 测试条件 | 预期行为 | 实际结果来源 |
| --- | --- | --- | --- |
| 归档时段接入 | 已登记模型允许的实测观测范围 | 读取真实时段，生成15窗口记录 | `browser-check.json`，归档接入操作 |
| 标准观测导入 | 同字段顺序的真实观测JSON文件 | 1窗口接入，后续追加至3窗口 | `browser-check.json` |
| 重复与冲突 | 重复上传同标识同内容；随后改变内容 | 原窗口去重；冲突返回400且原记录不变 | `http-errors.json`；浏览器追加与定向测试 |
| 字段顺序 | 实测输入生理字段逆序 | 拒绝不兼容输入 | `http-errors.json` |
| 时间、掩码、数值 | 窗口外时间、整数掩码、非有限值 | 返回400；拒绝持久化无效记录 | `http-errors.json`；倒序及超界时间定向测试 |
| 空数据与越界选择 | 全无效观测、非法起止索引 | 拒绝任务；前端禁用已知无效范围 | 定向测试日志、`browser-check.json` |
| 模型登记 | 完成训练的真实权重／训练中权重 | 严格加载完成权重；拒绝训练中权重 | `mechanisms.json`、`unfinished-model-check.json` |
| 模型和源码变化 | 完成一次增量任务后更换模型或实现指纹 | 重新计算，复用数为0 | 定向测试日志 |
| 实际语义参与 | 完成权重处理实测三窗口 | 事件可用、语义输出有贡献、语义查询参数已更新 | `mechanisms.json` |
| 历史信息边界 | 固定窗口及权重，扰动15秒后有效观测 | 15秒及以前表示在原容差内相同 | `mechanisms.json` |
| 批量和逐窗口 | 同一真实三窗口分别以单窗口和批大小2运行 | 序列、有效性和汇总一致 | `acceptance.json` |
| 服务中断恢复 | 真实15窗口任务保存至少1片段后中断本轮服务 | 重启显示失败；关联重试复用片段；原失败记录保留 | `recovery.json` |
| 输入变化与恢复缓存 | 修改原观测包内容 | 校验失败，不使用旧缓存 | 定向测试日志 |
| 窗口增量 | 先处理10窗口，再选择全部15窗口 | 第二任务仅处理其余5窗口 | `browser-check.json` |
| 历史与当前任务 | 新任务完成后查看旧结果，再点击本次结果 | 恢复正确任务，刷新后身份保持 | `browser-check.json` |
| 时间与维度联动 | 切换窗口、游标、维度及键盘定位 | 色阶一致、读数与观测时间联动 | `browser-check.json`、同任务截图和显示输入 |
| 网络短暂断连 | 中止一次状态查询 | 浏览器重试并观察到实际完成 | `browser-check.json` |
| 标准交付 | 下载真实特征包并按标准接口读取 | 3×96×64，CSV逐值相同，汇总与掩码一致 | `acceptance.json`、`feature-example/`、`read_features.py` |
| 字段人工复核 | 已有解释记录与独立复核状态 | 可读解释；保存结论按字段及来源隔离 | 浏览器解释展示；复核持久化定向测试 |
| 本机访问与下载 | 异源请求、路径逃逸、非白名单下载 | 拒绝越界访问 | 定向测试日志 |
| 界面可用性 | 1366×768及390×844视口 | 主操作可见；窄屏无横向溢出、曲线刻度可读 | `browser-check.json`、截图目视复核 |

字段人工复核的保存路径通过构造用例检验，真实案例展示已有解释记录；本轮自动化检查不冒充专家对字段语义作出的正式确认。错误路径和恢复检查使用独立产物目录，冻结源数据及原模型保持只读。
