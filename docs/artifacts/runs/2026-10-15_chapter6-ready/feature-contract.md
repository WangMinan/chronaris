# 标准特征合同与下游读取

**标准特征包保留时间、有效性和模型来源，供下游程序直接读取。** 序列表示维度固定为每窗口96个参考时刻、每时刻64维；这些维度由模型学习得到，不能直接命名为负荷等级或机动类别。下表说明示例文件和数组含义。

| 文件或对象 | 形状／内容 | 含义 |
| --- | --- | --- |
| `fusion_stream.npz` | 序列、时间、掩码、汇总及标识数组 | 标准表示数据 |
| `representation_manifest.json` | 模型散列、折标识、输入散列、导出角色等 | 与数组放在同一目录，提供来源与完整性校验 |
| `sequence_embedding` | B×96×64 | 按参考时刻组织的融合特征；无效位置为零 |
| `timestamps_s` | B×96 | 相对窗口起点的秒数；30秒窗口使用0至29.6875秒网格 |
| `valid_mask` | B×96，布尔值 | 当前参考位置有有效历史支持；它不表示业务预测正确性 |
| `pooled_embedding` | B×64 | 有效时刻序列特征的算术平均；全无效时为零 |
| `features.csv` | 每个窗口96行 | 时间、有效性和64维序列特征，可逐值核对数组 |
| `pooled_features.csv` | 每个窗口1行 | 下游标准读取后生成的64维汇总特征 |
| `delivery.json` | 任务、窗口数、有效位置数、维数 | 汇总接口执行回执 |

示例中的机器标识保留原来源，论文截图使用脱密后的可读名称。运行以下命令实际读取本包示例并检查形状、有效性、池化及序列表逐值一致；调用的读取接口与服务端相同。

```bash
PYTHONNOUSERSITE=1 PYTHONPATH=src \
/home/wangminan/env/anaconda3/envs/chronaris/bin/python \
  docs/artifacts/runs/2026-10-15_chapter6-ready/read_features.py
```

标准输出可作为分类、回归或检索算法的输入。本包执行的是标准表示读取与汇总，不引入新的业务风险预测模型。窗口之间的时间范围和来源标识随任务记录保存，使用者根据下游任务合同进行分组与拟合。
