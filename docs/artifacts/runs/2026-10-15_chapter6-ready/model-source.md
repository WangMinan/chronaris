# 模型来源与选择依据

**本轮为系统最终展示固定独立的实测语义应用模型。** 资产盘点先核对现有权重的训练角色、实际结构、输入字段及训练完成状态，再决定应用所需的补充训练。原模型和第五章结果保持原值，新增模型服务于第六章的流程实现与案例验收。

## 资产盘点

下表概括本轮实际读取的检查点类型。完整路径、散列、格式、训练更新数和来源关系见 `model-inventory.json`，统计对象为可用模型文件，和页面登记模型数分别记录。

| 资产 | 实际情况 | 本轮使用方式 |
| --- | --- | --- |
| 实测三组自监督编码器 | 训练完成，事件语义关闭；种子17、29、43 | 复用种子17编码器、字段合同、训练划分及归一化 |
| 对应实测任务引导权重 | 训练完成，使用任务标签，初始化来源指向上述基础结构 | 保留任务监督角色，不改写成自监督权重 |
| 最新公开数据完整语义权重 | 存在训练完成的语义配置及对应任务引导产物；输入字段属于各自数据域 | 证明资产状态已更新，记录为其他域模型，不套用实测观测 |
| 本轮实测应用编码器 | 在独立目录按既有完整语义配方补充训练 | 冻结后严格加载，作为最终应用验收配置 |

盘点覆盖实测域融合模型的全部可用最佳检查点，以及最新公开数据子集训练的融合模型最佳检查点，共36份。模型保存格式和角色分开核对；本次选择已训练、自监督的特征编码器，因此继续使用既有严格加载接口，无须新增任务引导权重格式适配。

## 训练与来源

**补充训练复用已有投入，并真实训练新增语义参数。** 固定种子17，保留12个训练时间块的两个生理视图，共24个训练窗口；内部验证为3个时间块的两个视图，共6个窗口。外层留出观测及任务标签不进入本次训练。训练前按原训练成员重新计算归一化，并与原检查点逐项核对一致。

模型由既有 `training_recipe('thesis_reference')` 构造，使用安全滞后融合、事件语义和可学习语义查询；连续对齐、观测重构与显式时间偏移目标沿用该配方。既有编码器形状兼容参数通过既有迁移初始化接口复制，新增语义查询参数参与真实梯度更新。学习率、批大小、目标权重、训练来源散列及参数复制清单随检查点和训练记录保留。训练上限预先固定为300次更新，内部验证选择保存模型，新增训练不形成第五章的新比较成绩。

当前快照的运动学残差关系集合为空，因为可用字段尚无完整核定的单位、方向和导数配对。该条件依照第三章3.4节处理；观测重构锚定和连续对齐仍参与优化。模型配置中的物理权重与“实际存在有效运动学残差”分别记录，不能按权重非零推断物理关系已启用。

## 验收判据

**模型身份由保存权重及其实际计算共同确认。** 验收保留训练完成状态、总更新次数、所选更新、训练归一化散列、参数严格加载及原来源散列。真实三窗口上记录可学习语义查询的非零参数、实际事件摘要、语义分支对输出的差异；暂时关闭该分支只用于同一权重的诊断对照，之后恢复，诊断输出不冒充正常应用结果。

历史信息检查固定模型、时间网格和归一化，仅扰动15秒之后的有效观测值，对比15秒及此前的表示。批量与逐窗口一致性、标准下载回读和序列表逐值核对保持绝对与相对容差各10⁻⁵。实际结果见 `mechanisms.json` 和 `acceptance.json`；这些检查证明本章配置的运行参与及接口一致性，下游效果比较继续由第五章负责。
