# 可学习事件语义与训练目标实现

## 阶段结论

Chronaris safe-lag 主干已接入真正可学习的事件语义查询，并保持旧 checkpoint 默认关闭时的确定性行为。三种查询角色固定为飞行事件、生理响应和人机协调；每种查询在规则上下文上叠加一个与连续状态同维的可学习残差，再归一化参与事件 token 归因。

语义上下文只进入原有 16 维门控跨模态支路，两个 24 维单流旁路不变。为满足严格因果边界，每个查询时刻只使用该时刻及之前的连续状态、滞后注意力和事件分数；未来观测扰动对历史输出的最大影响不超过 `1e-6`。

## 新训练目标

- 显式时移分类使用 `-10/-5/0/+5/+10` 秒五类，独立任务头只在权重大于零时创建并进入 checkpoint。
- 事件—响应配对使用同一样本正例和不同 group 的确定性循环错配负例；无合法负例时记录 `unavailable`，不构造同 group 负例。
- 连续对齐、运动学一致性、方向约束、滞后对齐、显式时移和事件配对从第 1 个 epoch 线性 warm-up，第 5 个 epoch 达到完整权重。
- 每项损失记录原始值、加权值、有效样本数、状态、相关参数梯度范数和适用的机制指标。
- validation 记录五分类准确率、正确/错配相似度、R@1 以及各机制损失；checkpoint 选择仍只使用训练内自监督 validation，不打开应用标签或外层结果。

candidate、common 和 locked 三个入口现复用同一个 validation candidate trainer；locked 只保留兼容包装，不再维护第二套训练循环。

## 验证结果

- 可学习 query 残差具有有限且非零梯度，并能从 v2 checkpoint 严格恢复。
- 构造的正确事件—响应配对相似度高于跨 group 错配，R@1 为 1.0；同 group 批次结构化不可用。
- 显式时移权重从 0 改为 0.1 后，损失、任务头梯度和最终编码器参数均发生变化。
- 启用语义模块后，48 维单流旁路与关闭语义模块时严格一致。
- 聚焦子系统测试：`85 passed`；完整测试：`447 passed, 8 skipped`，用时 137.92 秒。
- RTX 4090 上完成包含机制损失、显式时移和事件配对的单 epoch 前后向，v2 canonical state hash 成功写入。
- Ruff、Python 编译和 `git diff --check` 通过。

详细判据见 [acceptance_checks.csv](acceptance_checks.csv)。本轮是实现与工程冒烟，不形成机制门通过结论；多随机种子 validation 仍需后续实验确认。
