**离线快照把显示数据与渲染资源一并交付。** [preview-data.json](preview-data.json) 保存本次截图所用的完整显示数据、中文标签及表示数值；[preview.html](preview.html) 内嵌这些数据、样式和绘制代码，复制到仓库外即可用浏览器查看三个页面和回放。它只展示保存结果，推理与下载入口隐藏；实际操作使用本机服务。

**纯渲染脚本已经在独立导出目录实跑。** [render_preview.py](render_preview.py) 仅读取随包 JSON、HTML、样式及浏览器绘制脚本，不导入算法模块、加载模型、计算实验指标或请求外部数据。以下命令生成可编辑的独立包，包含 `ui/` 样式与源码、输入 JSON、渲染脚本和成品 HTML；将该包复制到仓库外，使用 Python 标准库再次执行 `render_preview.py` 即可重绘，浏览器截图另由界面捕获完成。

```bash
/home/wangminan/env/anaconda3/envs/chronaris/bin/python \
```

**异常与恢复检查覆盖应用边界。** 请求中的非法窗口、重复或逆序选择、未知案例、跨源请求与未允许下载被拒绝；输入和检查点篡改、模型字段顺序不符被拒绝。服务进程锁和单任务锁限制重复运行；重启保留完成历史，并将中断任务标记为失败。失败结果不会成为可下载的成功产物。
