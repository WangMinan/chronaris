# 公开数据与鼎新分组消费者闭环

公开数据的固定消费者已支持按受试者选参和汇总，鼎新已支持共享航电上下文加权及逐字段有效标签。已有真实数据的六个“数据域—表示路线”组合完成读写闭环，共保存十组消费者、44 个任务或字段模型。该轮复用工程冒烟表示，验证统计与导出合同，不进入候选排名或正式主表。

## 实现与实跑范围

公共线性模型继续复用标准化、逻辑回归和岭回归实现，参数网格不变；验证标准改为受试者指标的等权平均。MiniROCKET（随机时序卷积特征方法）复用现有训练角色变换，支持不同任务的标签掩码；全窗无观测样本保留为零表示并参与预测，变换与通道筛选只拟合有观测的训练样本。压力评价入口只调用已拟合模型，不重新拟合变换或消费者。

鼎新每个生理字段独立使用其有效训练标签，避免完整行筛选删除其他可用字段。标准化与回归均使用多视图权重；分类的类别平衡也按这些权重计算。机动任务先平均同一航电上下文的预测或类别概率，再计算指标；生理字段按训练尺度归一化，分别报告误差和相对持久性的技能。持久性缺失仅减少技能比较的配对数，不删除模型误差中的有效目标。
