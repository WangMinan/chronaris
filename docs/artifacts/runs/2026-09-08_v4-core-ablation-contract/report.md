# 核心消融与完整执行顺序

核心消融已复用共享预训练、联合适配、模型冻结和消费者评价，不再单独实现训练循环。连续演化和单流旁路使用已有模型变体；物理消融仅把残差权重设为零，观测锚定保持启用。显式时移与独立配对按各自损失关闭，质量门和扩大缺失增强按最终配置移除。

最终未采用的独立配对、质量门或扩大缺失增强明确标为不适用，不重复训练相同模型。例如两条路线都选择修复参考时，四项有效消融形成 24 个路线—种子评价单元，共用 12 次自监督初始化。各路线的实际配置不同则分别训练。核心消融只评价干净确认输入，不额外扩大为全部压力网格。

确认数据现在同时等待主模型和核心消融模型完成训练并冻结文件。主模型清单绑定所有消融检查点，任何文件变化都阻止生成 G2（事件样条生成族）确认数据。配置冻结还绑定鼎新原始来源清单和仿真生成清单，避免后续悄然换用另一份数据。

实际工程测试使用种子 17、29、43 完成短预训练与联合适配，并确认移除的组件正确继承到适配初始化。物理残差权重为零时，观测锚定仍为正且梯度连通；不适用的消融被拒绝。模型清单缺少消融时不能生成确认观测，真实消费者的干净评价、压力范围限制和恢复均通过检查。

[全量 CPU 验证](validation_summary.json)为 615 项通过、30 项跳过，144.59 秒；随后一个独立队列目录检查通过。当前尚未产生正式消融成绩，当前源码完整 CUDA（统一计算设备架构）检查等待显卡空闲。

入口为 `run_thesis_v4.py` 的 `core-ablation-train-cohort`、`core-ablation-model-freeze`、`core-ablation-evaluate-cohort`，仍使用同一冻结配置哈希。自动链已接入这三个阶段；时间偏差和生理响应时延的分开机制评价、跨域统计与论文图表仍属后续工作。
