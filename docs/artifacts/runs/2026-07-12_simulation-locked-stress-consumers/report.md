# G2 锁定压力场景下游评估

状态：completed；验收 6/6。
完成 630 个冻结 consumer 评估、20160 条指标和 4032 条退化斜率。
所有 consumer 与负荷阈值均冻结自 G1 clean train/validation，压力场景不重训、不调参。

## 主要观察

- 在三项预声明主指标与七个压力因素的 21 个“任务—因素”组合中，Chronaris 在最高单因素压力下的绝对表现有 15 个位于六方法前二。机动状态分段在时间戳抖动、时钟偏移、时钟漂移、连续缺失、生理额外时延和信噪比退化下均保持第一。
- Chronaris 并非退化最慢的方法。三项主指标平均后，随机缺失和连续缺失的方向归一退化斜率分别为 -0.0733 和 -0.1264，均为六方法第六；时钟偏移和信噪比退化斜率为 0.0039 和 -0.0383，均为第二。
- 混合重压下的 48 轨迹配对结果具有种子差异。Chronaris 相对 MulT 的三 seed 平均差异为：机动分段准确率 -0.0696、负荷分类正确率 -0.0903、回归绝对误差优势 0.0239。因此混合重压不写成 Chronaris 的统一优势。

## 结论边界

本 run 支持“Chronaris 在多数单因素最高压力下仍保持有竞争力的绝对任务质量”，但不支持“Chronaris 在所有异步、缺失和混合压力下都退化最慢”。随机缺失与连续缺失是后续模态失活和缺失感知训练的主要改进点。
