# 阶段 4：完整开发比较与成本实测

本轮固定首个开发折和随机种子 17，执行 25 个模型单元、43 条表征路线。原有六种方法在三个数据域分别完成自监督表示和任务引导表示比较，其中时间同步基线只运行无需任务标签的一条路线。TimeCMA 语言模型增强方法提供三个任务适配路线；Chronos-2 预训练时序模型提供三个冻结及三个历史内部预测适配路线；SensorLLM 传感器—语言对齐模型的本地 DeepSeek Llama 蒸馏骨干变体仅在 CLARE 生理数据运行分类适配。

本阶段扩大到完整开发角色，并保留共同下游合同。鼎新使用去重后单记录的 24 个训练视图和 6 个验证视图，对应 12/3 个航电时段；公开数据使用登记的完整首折，不沿用阶段 3 的小样本子集。任务含义、有效掩码、历史截止点、训练角色归一化和分组计算均由合同校验。SensorLLM 的分类监督与其他方法的多任务监督分层列出，外部预训练来源另行披露。

以下预算在查看本轮结果前固定，用于取得一轮完整开发训练、导出和独立下游拟合的成本。它们是有界开发预算，不预先断言各模型已经收敛，也不声称不同规模模型拥有相同计算量。

| 方法范围 | 固定预算与选择规则 |
| --- | --- |
| 五种原有可训练编码器 | 自监督至少 300 次更新；任务头预热 50 次、联合适配至少 200 次；有效批量 16，实际批量 4；每 50 次及末次验证，关闭提前停止；选开发验证最佳检查点 |
| 时间同步基线 | 仅在训练角色拟合归一化与投影，直接冻结导出 |
| TimeCMA | 至少 200 次适配，且循环批量 4 覆盖全部训练窗口；按任务有效性补充批次成员；使用末次检查点 |
| Chronos-2 | 冻结路线与历史内部后 16 点预测适配路线；适配至少 200 次且覆盖全部训练窗口，批量 1；使用末次检查点 |
| SensorLLM 开放骨干变体 | 历史趋势文本对齐和分类适配分别至少 200 次，且各覆盖全部训练窗口，批量 1；使用末次检查点 |

共同下游沿用阶段 2：鼎新固定逻辑回归参数 C=1、逐字段岭回归参数 alpha=1，并报告持久性参照；公开数据按原网格和验证受试者均值选择参数。真实逐时刻序列额外运行 MiniROCKET 时序卷积特征方法，窗口末端向量只运行线性算法。保留原维数与既有求解器回退行为，高维病态矩阵警告原样进入日志。
