压力入口已复用现有冻结消费者评价器，并支持显式开发验证角色；消费者模型缓存每次访问均核对清单和文件哈希，避免缓存掩盖文件损坏。原确认评价调用保留默认角色，历史结果文件不回写。

新入口 `run_thesis_v4.py development-pressure --domain simulation --method chronaris --route self_supervised --update 500` 读取已完成的干净阶段消费者和对应编码器快照。两条路线分别移除训练任务头后导出，固定使用开发身份和训练归一化；首次干净条件须重现已保存的表示及消费者预测，之后才逐条件评价。

每种条件保留全部窗口预测，复用现有逐点、片段、边界及检测延迟指标。新增统计按参数档案组织，并记录回归误差第 95 百分位、最大五个窗口的平方误差贡献及无观测覆盖。Chronaris 另输出全部有效查询与观测状态范数、注意力熵、门值、逐字段观测拟合和物理残差；无有效状态明确记为不可用，不将全窗缺失后的零表示写成稳定演化证据。

CPU（中央处理器）聚焦检查为 11 项通过、2 项图形处理器用例跳过。集成检查使用真实共享训练器、两条路线、八条件及三类消费者，并禁止压力阶段重新拟合；同时验证缓存损坏拦截和全空窗口保留。完整 CUDA（统一计算设备架构）环境测试与实际压力运行的状态将追加到本目录；当前不据接口验收声称压力效果已经成立。
