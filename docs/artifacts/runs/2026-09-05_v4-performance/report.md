# v4 语义事件计算剖析与严格时间边界

向量化事件提取使同权重、同输入的四窗口前向中位耗时从 0.873 秒降至 0.106 秒，约为原来的 1/8.27。七次计时均在 CUDA（统一计算设备架构）执行后同步，设备为 RTX 4090；模型输出最大差为 `1.12e-8`。该结果仅描述推理热路径，完整训练成本另行实测。

原实现三个前向共 2.685 秒，其中语义前缀为 2.326 秒，约占 86.6%。主要成本为逐样本事件分段、分位数、排序与数千次主机同步。新实现按张量选择同一阈值、连续片段和稳定排序，保留原加权池化与梯度；三个前向剖析降至 0.353 秒，连续状态主干成为主要成本。

峰值张量显存从 30,068,224 字节增至 47,076,352 字节。CPU（中央处理器）与 CUDA 的标量参考对照覆盖 2、17、96 点、空观测、填充、并列事件及输出梯度，连同因果与主干测试共 17 项通过。

严格时间边界测试发现，原 `1e-6` 因果容差及时间戳提前转为单精度可能把紧邻查询的未来点算入历史。现保留原生时间精度作可见性判断，仅在连续数值计算所需位置转换；`15 + 1e-7` 秒未来点的回归测试先失败后通过，相关对齐与因果测试为 27 项通过、2 项跳过。

可复核计时与窗口清单见 [comparison.json](comparison.json)。完整剖析在 `artifacts/application_evaluation/2026-09-05_v4-performance/`，输出与梯度标量参考在 `tests/modeling/fusion_encoders/event_extraction_reference.py`。使用 v4 工程冒烟检查点，不产生任务成绩，也不更改旧实验文件。
