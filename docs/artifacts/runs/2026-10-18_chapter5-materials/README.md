# 第五章首批写作素材

**使用入口：[论文侧文件清单](USE_IN_THESIS.md)。** 本包供论文侧编写第五章初稿与修改图形使用。公开数据采用种子 17 的五折结果；鼎新采用单记录的固定时间块划分；受控仿真采用种子 17 的完整参照、基线及组件消融。种子 29、43 的补充复核不计入本批完成量。

## 本地重绘

复制整个目录，在新环境安装 `requirements.txt` 后执行：

```bash
python plot.py
python verify.py
```

`plot.py` 仅读取随包 CSV/JSON 并绘图，不导入实验仓库，不访问检查点、数据库或网络，不重新计算指标。输出为高分辨率 PNG 与可编辑 SVG。字体、中文名称、颜色和图形参数见 `style.json`；优先安装文泉驿正黑或思源黑体。图片与输入对应关系由 `figures/figure_inputs.json` 给出。

## 使用顺序

1. 先读 `protocol.json`，确定种子、折、统计单位和数据角色。
2. 5.1—5.2 使用 `data/inventory.csv`、`training_contracts.csv.gz` 和 `data/protocol/`，分别核对数据量、划分、训练与下游合同。
3. 5.3 使用 `native_summary.csv`、`simulation_summary.csv` 的干净观测结果，并按需读取逐样本、逐字段和逐点预测。公开数据按字段、受试者、折依次等权；不能把窗口当作独立受试者。
4. 5.4 使用相同折/路线的完整配置与组件消融；`sensitivity.csv` 仅含开发验证数据，权重固定为 0、0.025、0.05、0.1。
5. 5.5 使用时间探针、逐查询历史差异、配对缺失条件和尾部数据。探针结果支持表示的线性可解码性，不能直接解释为模型估计出了真实时钟或生理时延。
6. 5.6 使用记录训练成本、失败尝试、原始推理计时及显存。继承与失败计时分别列出，避免重复相加；训练成本可能是记录下界。

5.7 可按这些来源组织阶段判断。本包不代写论文正文。负面结果、不可用指标和跨设备严格重放未通过项均保留；`device_replay.csv` 不能解释为全部数值逐值一致。

## 数据与修改

`.csv.gz` 是可无损解压和编辑的 CSV；部分列用 JSON 数组存储完整概率或逐时刻机动状态，保持样本原顺序。96 个查询点的间隔为 30/96 秒，具体上下文起点见原清单。模型运行的绝对路径仅用于追溯，重绘不依赖它们。

`evidence.json` 记录原始来源及数据散列，`verify.py` 检查数据完整性与聚合结果。手动修订请复制到 `revisions/` 新版本，注明原因，再明确修改绘图输入；不要覆盖原始导出数据或冻结实验。

最终交付须结合 `validation.json` 检查独立重绘、关键图片人工抽查和 Git 纳管状态。本目录为种子 17 的正式交付副本，含 1,205 个数据文件和 35 组 PNG/SVG 图形；验收记录见 `delivery_acceptance.json`。原始导出清单保存在 `source_evidence.json`，仅对约 1 GB 的训练合同 CSV 作无损 gzip 压缩，解压后散列与冻结导出逐字节一致，见 `packaging.json`。
